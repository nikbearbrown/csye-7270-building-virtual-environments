# CSYE 7270 — Building Virtual Environments with Walker and Godot

A course and companion book about Conducting AI through game and virtual-environment development. Begin with [Conducting AI Through Games and Virtual Worlds](chapters/preface-conducting-ai.md), then Module 0 and Modules 1–15. Each module maps to one chapter; the preface is unnumbered.

The human chooses the experience, directs technical work, questions the evidence, plays the result and accepts responsibility. Games make this relationship tangible because engineering meets art, fun and opinion. AI assists with implementation and testing; actual human experience and a defensible acceptance decision remain central. [The teaching foundation](teaching-foundation.md) carries Conducting AI, Computational Skepticism and Irreducibly Human through every module.

Godot is the core engine because code and text scenes support a direct coding-agent workflow with engine checks, without requiring an MCP bridge. Each module ends with Unity and Unreal similarities, differences and further-reading pointers.

The preface and all sixteen numbered module/chapter drafts are written. Lessons, practice assessments, ten graded assignments and a local Canvas package are present. Human review, practical verification and Canvas import readiness remain recorded in [STATUS.md](STATUS.md); writing completion does not imply release approval. The Word syllabus predates the preface; the course map and generated Canvas syllabus include the added orientation.
