# CSYE 7270 — Building Virtual Environments with Walker and Godot

An incrementally released course and companion book about directing, inspecting, and improving AI-assisted game development. Each teaching module becomes one book chapter. Students start with the working walker-jumpman prototype, change its main character, and extend its level before moving into generated art, Blender-assisted modeling, and Godot's real-time systems.

The human specifies the experience, predicts failures, plays the result, judges adequacy, and accepts responsibility. The agent assists with implementation and evidence gathering. A successful command is not a successful game.

Requested first delivery: revised syllabus, complete Module 1 / Chapter 1, and a Canvas-importable IMS Common Cartridge. Later modules are planned, not prewritten, and will be added one or two at a time.
