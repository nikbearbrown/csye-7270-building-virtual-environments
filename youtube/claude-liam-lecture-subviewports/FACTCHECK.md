# Fact check: SubViewports

**What this is.** Every factual claim the film makes, in the order it makes them, with a verdict, the source or the run that settles it, and what changed if it was wrong. Verdicts: PASS (checked and true as stated), CORRECTED (the brief, the source or an earlier draft said something else; the film says the corrected thing), EXEMPT (framing or a definition of the film's own, with the reason), OPEN (not settled).
**Why.** The film is for people who will paste its code into Godot. A wrong number or a wrong label costs them an hour, so each claim carries a quote from the Godot 4.7 documentation or a measurement from the installed Godot 4.7.2, and nothing rests on memory.
**Found.** 74 rows, no OPEN. Four corrections: the source's fade written as `COLOR.a = UV.x` turns the empty parts of a transparent picture into a dark haze (the film multiplies the whole color instead); the brief's opening line about one shader per node reads wrongly once the film has corrected it (replaced); "Transparent BG keeps the original alpha" needs one more sentence (it also decides what the empty parts hold); and the Texture slot's menu has the heading New and the entry ViewportTexture, not an entry called New ViewportTexture as the docs put it (B04 now says so). One finding is in neither the brief nor the source and is run, not quoted: a transparent picture stores half-transparent pixels premultiplied (the documentation is silent about viewports), which is why the default blend darkens soft edges. The source's claim that a negative height fixes the upside-down Quad Mesh is confirmed, with the mechanism. Runs are named as in `evidence/planning-checks/RESULTS.md` (for example run-5 P2); every pixel value is Forward+ unless it says otherwise, and the Compatibility renderer agreed within one level of 255.

Documentation quoted: Godot 4.7, docs.godotengine.org/en/stable, read 2026-10-13: Using Viewports (tutorials/rendering/viewports.html), SubViewport, ViewportTexture, Viewport, MeshInstance2D, QuadMesh, PlaneMesh, Sprite2D, CanvasItem, CanvasItemMaterial, Color (classes/class_*.html), the canvas_item shader reference, shader functions, Introduction to shaders, Introduction to 3D.
