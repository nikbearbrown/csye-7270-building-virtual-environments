Reading. A window that is hidden behind another is, to macOS, occluded, and Godot then stops drawing it for stretches. Movie Maker writes one file per main-loop step whether or not that step was drawn,
so the movie holds repeated frames and the recording looks frozen. This is consistent with everything above but not proven: the one test that placed a cover window on purpose worked twice and then stopped working.
What is safe: --always-on-top (or --position 0,0) for every Movie Maker or editor recording, and one force_draw(false) per step in any script that reads pixels.
