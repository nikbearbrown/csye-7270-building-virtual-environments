# Shot list: SubViewports

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 40 body beats. Lane histogram: capture 22, manim 16, editor 2. Every Godot render shown is a capture of one verified scene from `evidence/planning-checks/capture_scene.gd` or a real editor frame of the scratch project; every shader shown is a tested file in `lab-shaders/`. Seven things must exist or be recorded first (below).

## Must exist before the build

1. **`ShaderLab`** Remotion component (spec: `../_godot-shaders-series/COMPONENT-SPECS.md`; this film uses `layout` side and video, cue `label`, `readouts`, `rings`, `ramp`, `caption`, a PNG still). 2. **`shader_kit.py`** Manim helpers (same file: ramp strip, plot, UV square, vertex quad, code card). 3. **Capture harness** (same file; the scene-script route, with the adapter this film's CAPTURE-PLAN describes: all 21 scenes on the SubViewport native-size route, window kept on top, one frame of pre-roll). 4. **New Manim kit objects this film needs** (build them into `shader_kit.py` and list them in `BUILD-LOG.md`): `viewport_box(label)`, `picture_card`, `blob_sprite`, `screen_frame`, `shader_tag(text)`, `hue_wheel`, `plateau_plot`, `mesh_grid(n)`, `cursor_arrow`. 5. **Editor frames E1, E2, E2b, E4, E4b, E4c/E4d** (the scratch project and driver plugin are in `evidence/planning-checks/editor-scratch/`; CAPTURE-PLAN section E). 6. **Capture scenes C01 to C21** (CAPTURE-PLAN). 7. **ffmpeg** to cut each capture's PNG sequence to an MP4 and to join frames into `e1-setup.mp4` and `e4-materials.mp4`.
