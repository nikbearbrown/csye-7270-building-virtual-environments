# Shot list: Outlines

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 41 body beats. Lane histogram: capture 27, manim 11, remotion 3. Every Godot picture is a render of a tested file in `lab-shaders/`, played from a spec in `evidence/planning-checks/scenes/` (27 captures, none needs the editor). The build must create `ShaderLab` and `shader_kit.py` first (below) and extend the capture harness with the scene player.

## Must exist before the build

1. **`ShaderLab`** Remotion component (spec: `../_godot-shaders-series/COMPONENT-SPECS.md`). 2. **`shader_kit.py`** Manim helpers (same file): ramp strip, pixel grid, uv square, code card, ghost copies as plain circles. 3. **Capture harness with the scene player**: `evidence/planning-checks/scene_player.gd`, `ol_lib.gd`, `padding_snippet.gd`, `select_snippet.gd` and the 27 JSON specs in `scenes/` (contract in `CAPTURE-PLAN.md`). 4. **Docs screenshot** for B12 via Playwright. No editor frames are needed.
