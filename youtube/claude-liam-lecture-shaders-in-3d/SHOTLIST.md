# Shot list: Shaders in 3D

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 44 body beats. Lane histogram: capture 24, manim 14, remotion 5, editor 1. Every Godot render shown is a Shader Lab render or a scripted scene capture of a tested file in `lab-shaders/`; six small scene scripts (S1 to S6, in `CAPTURE-PLAN.md`) and two docs screenshots must be produced before the build. One beat (B43) shows Godot's own editor: four frames already recorded by script, to be copied (no click, no recording by hand).

## Must exist before the build

1. **`ShaderLab`** Remotion component (spec: `../_godot-shaders-series/COMPONENT-SPECS.md`; shared with every shader film, so check whether an earlier film's build already made it). 2. **`shader_kit.py`** Manim helpers (same file). 3. **Capture harness** `lab/capture.gd` + `capture_shader.sh` (same file), with a scene-script option for S1 to S6. 4. **Docs screenshots** D1 and D2 via Playwright. 5. **Two-renderer composites** C15 to C17 (ffmpeg hstack of two harness runs). 6. **Editor frames** for B43 (E1): already recorded by script, copy them (`CAPTURE-PLAN.md`).
