# Fact-check (Gate F): Shaders in 3D

**What this is.** Every checkable claim in the narration and on screen, with its verdict and where the verdict comes from. Verdicts: PASS (checked), CORRECTED (the brief or an earlier note said something looser or wrong and the film says the corrected thing), EXEMPT (a definition, an analogy or advice, labelled as such), OPEN (cannot be verified yet; says why).

**Why.** A shader is where "it compiles" and "it looks right" are furthest apart, and in three-D a color number is not the color on screen: lighting, the mesh and the renderer all move it. Nothing here is trusted because it was said confidently, and every pixel value was read from a real Godot window.

**Found.** 104 rows: 84 PASS, 2 CORRECTED, 18 EXEMPT, 0 OPEN. Four statements of the brief were corrected: a 3D fragment does have a COLOR, read-only (row 22, CORRECTED); the pad shader is ten lines, not eight; the game's pad is a thin box, not a quad; and the suggested stripe probes both land on a dark stripe; two more were worked around (the Lab's quad3d cannot show lit against unshaded, and the brief's BIDEA trigger was split by a line break; ACTS.md lists all six). Nothing is OPEN. One beat (B43) shows Godot's own editor, from frames recorded by script on 2026-10-13, and they corrected the first plan: the docs say the renderer's name always sits in the editor's upper right corner, the shipped 4.7.2 editor hides it by default (row 97, CORRECTED, docs versus run), so the film now speaks and shows the Project Settings path (row 104, added at the end so no row number moved). No other beat shows an Inspector label or widget. Eight facts were learned by running rather than reading: the box keeps its map in six cells, six stripes cross its top against sixteen on a flat square, an empty light() silences the lamp, a back face is not drawn, a two-D shader is ignored on a mesh with no error, a tween on a never-set uniform fails, Forward+ draws an unshaded half as 0.74, and Compatibility's endpoints read a few steps off the typed numbers. Three more runs back definitions and one claim that appear on screen: alpha 0 is the stage color and alpha 1 the solid color, a lamp that does not reach a surface does not run light() for it, and a three-D fragment's COLOR is the vertex color.

Machine: Apple M4 Pro, macOS (Darwin 25.5.0), Godot **4.7.2 stable (official)**, Forward+ unless stated. Docs: the Godot 4.7 documentation (docs.godotengine.org/en/stable; the page sidebar's newest upgrade guide is "Upgrading from Godot 4.6 to Godot 4.7"), fetched and read 2026-10-13. Editor frames (B43 only): `P` = `_godot-shaders-series/editor-capture/png/1920x1080` (folder renderer-path; native-size twins in `png/3456x1944`), recorded by script in the real 4.7.2 editor on 2026-10-13, labels read from the live UI (`_godot-shaders-series/editor-capture/README.md`).
