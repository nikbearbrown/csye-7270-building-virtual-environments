# Fact-check (Gate F): Godot Shader Language

**What this is.** Every checkable claim in the narration and on screen, with its verdict and where the verdict comes from. Verdicts: PASS (checked), CORRECTED (a source or the documentation said something looser or wrong and the film says the corrected thing), EXEMPT (a definition, an opinion or a boundary that is not claimed, stated as such), OPEN (cannot be verified yet; says why).
**Why.** A shader is where "it compiles" and "it looks right" are furthest apart, and the material this film follows (a long third-party course) is loose in places. Nothing here is trusted because it was said confidently.
**Found.** 125 rows: 104 PASS, 5 CORRECTED, 16 EXEMPT, 0 OPEN. Four things changed the script: the documentation's own operator example (`vec3 + 2`) does not compile; only four built-ins (TIME, PI, TAU, E) are visible inside your own functions; the documentation does discuss branching cost (the brief said it did not); and `0.1 + 0.2 == 0.3` came out true on this Mac, so the film demonstrates float equality with a pixel address instead.

Machine: Apple M4 Pro, macOS, Godot **4.7.2 stable (official)**, Forward+ unless stated; every engine message is quoted exactly as printed (`evidence/planning-checks/logs/`, trailing spaces trimmed). Docs: Godot 4.7 (`https://docs.godotengine.org/en/stable/`), read 2026-10-13: `tutorials/shaders/introduction_to_shaders.html`, `shader_reference/shading_language.html`, `shader_reference/canvas_item_shader.html`, `shader_reference/shader_functions.html`, `shader_reference/shader_preprocessor.html`, `converting_glsl_to_godot_shaders.html`, `shaders_style_guide.html`. Scripts, logs and renders: `evidence/planning-checks/` (`lab-batch.sh` → `lab-results.jsonl`, `lab-summary.txt`, `png/`; `run-error-logs.sh` → `logs/`; `png-analysis.py` → `png-analysis.txt`; `pulse-range.sh` → `pulse-range.txt`; `run-builtins.sh` → `builtins-results.txt`; `verify1.gd` → `run-1-verify1.log`). Pixel values are quoted with their renderer (Forward+).
