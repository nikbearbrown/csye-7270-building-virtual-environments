# Planning checks: results

**What this is.** The runs behind every number and claim in `FACTCHECK.md`, in the order they were done, with the command, the result and what it means. All on Bear's Mac: Apple M4 Pro, Godot 4.7.2 stable (official), Forward+ unless stated, 2026-10-13.
**Why.** So any figure on screen can be re-run, and so the runs that did not give an answer first time are kept and labelled.
**Found.** Seven GDScript checks, three Lab runners (51 formula probes, 21 whole-picture checks, 13 shaders compiled), and ten Movie Maker scene recordings decoded frame by frame. Two things went wrong and taught something: an undrawn window freezes `TIME` (the first clock run was inconclusive for that reason), and a tween on a uniform that was never set from code fails. One side finding stays out of the film: `TIME` advances only on drawn frames.

## How to re-run

- GDScript checks and Movie Maker scenes: `./run-all.sh [out_dir]` (copies `gd/` and `scene-project/` to a scratch folder, so no `.godot` cache lands in the film folder; it takes about a minute and a half and was tested on 2026-10-13: its logs are in `rerun-logs/`).
- Lab: `python3 run_twins.py` (probes), `python3 run_images.py` (whole pictures), `./run-lab-compile.sh` (compile and render every shown shader in both renderers); `TWIN_RENDERER=gl_compatibility python3 run_twins.py` runs the Compatibility renderer. A twin is the shown shader with `TIME` replaced by a uniform `tv` (`twin_lib.py`), because the Lab cannot set `TIME`.
- Every Godot window must keep being drawn: use `--always-on-top` and leave the machine alone (see the first rows).

## What the numbers mean for the film

- `TIME` is one clock (B01, B02), scaled by the time scale and not by a pause (B03), wrapping at a limit that only some pulses survive (B04).
- The tick counter has its own zero and its own speed (B05, B06), so an age is counted from delta (B07) and an offset per node is an instance uniform (B17, B18).
- Every formula in Acts II to V draws what it says: probes and whole pictures match to one 8-bit step or one pixel, in both renderers.
- Docs passages: `docs-quotes.md`.
