# Shot list: Trigonometry for Shaders

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 40 body beats. Lane histogram: manim 23, capture 13, remotion 4. Every Godot picture is a Shader Lab render of a tested file in `lab-shaders/` (13 captures, no editor frames needed), plus two Godot-docs screenshots. Four things must exist before the build (below).

## Must exist before the build

1. **`ShaderLab`** Remotion component (spec: `../_godot-shaders-series/COMPONENT-SPECS.md`; layouts used here: `side`, `stack`, `video`, `code`; props used: `cues` with labels, `readouts`, `rings`, `ramp`, `caption`, `title`). Check `./brutalist.art/art scenes --check ShaderLab`; if it is not renderable the build starts there.
2. **`shader_kit.py`** Manim helpers (same spec file: `ramp_strip`, `pixel_grid`, `plot`, `uv_square`, `code_card`) **plus these film-local objects**, written into this film's scenes file, not the shared kit: `right_triangle(angle, hyp)` with side highlight and a thick terracotta angle arc; `unit_circle(radius, orientation)` with a terracotta dot, axes and a screen/paper flag (paper = y up, screen = y down); `wave_plot` (the shared `plot` with a travelling dashed link from a circle's dot); `radius_tape` (a bar copied end to end round a circle's edge); `vector_chain` (arrows tip to tail with a riding small ring); `compass_readout` (a live number box beside a walking dot); `knob_slider` (an outlined slider with a turning knob).
3. **Capture harness** `lab/capture.gd` + `capture_shader.sh` (same spec file): options `--animate name:from:to` (a piecewise schedule is needed for C06, C11 and C12), `--size` for a square 480 x 480 and a wide 640 x 360 logical canvas, live `TIME`, PNG sequence then ffmpeg to MP4, still PNG.
4. **Two docs screenshots** (B08, B33) with Playwright at 1600 x 900, device scale 2.4: see `CAPTURE-PLAN.md`.
