# Original 3D particle teaching stage

Blank construction starter for the native Godot editor lecture. The floor, one-meter reference, original procedural assets, camera and labeled scripted-action plugin support visible construction of GPUParticles3D resources. It is not a prior version of a shipped game. Native editor capture is required; no generated editor imagery is used.

The separate diagnostic fixture tests mesh/quad choices, material ownership, billboard/vertex color/alpha settings and real-renderer collision bounds. Those checks do not establish visual readability. Native capture is blocked by the locked Mac session. Capture permission preflight is granted; no security settings are changed.
