**Side findings, not used in the film.** With the smooth filter a middle-of-the-cell lookup lands exactly on the border between two picture pixels (for even block sizes) and averages them: the pixelated edge picks up in-between colors. Pixel-art users set the nearest filter; the Lab's sprites already use it. The docs warn that `UV` spans the whole texture when a Sprite2D draws only a region, so cells on a sprite sheet are counted over the whole sheet unless `REGION_RECT` is used (not tested).
