# Shot list: Patterns and Pixelation

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 43 body beats. Lane histogram: capture 22, manim 18, remotion 3. Every Godot render shown is a Shader Lab or scene-script capture of a tested file in `lab-shaders/`; no editor frames are needed. Each `show` time is when a motion starts; the build must finish it before 45 % of the beat or start it after 55 % (the midpoint frame is a settled still), and the `visual_intent` of each Manim beat ends with the state that midpoint frame must show. Four things must exist before the build (below).

## Must exist before the build

1. **`ShaderLab`** Remotion component (spec: `../_godot-shaders-series/COMPONENT-SPECS.md`; props used here: `layout` video and side, `code`, `cues`, `readouts`, `rings`, `ramp`, `caption`, `title`). 2. **`shader_kit.py`** Manim helpers (same file): this film uses `ramp_strip`, `pixel_grid`, `plot`, and `code_card`; it also needs three small objects that the spec does not list, each a few lines on top of those: a numbered `cell_grid` (outline cells with a number in each), a `block_row` (a strip of blocks of given widths with rings and labels), and `lookup_lines` (curved lines from pixel dots to one point). 3. **Capture harness** `lab/capture.gd` + `capture_shader.sh` (same file) with these options: `--animate` (linear sweep), a stepped sweep (values held for a time each), `--material-at SECONDS`, and four small scene scripts (C12 sprite scale tween, C18 rectangle widening, C19 and C21 shader swaps). 4. **Docs screenshot D1** for B21 via Playwright. There are no editor frames in this film.
