# Shot list: UV Space

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 42 body beats. Lane histogram: capture 19, manim 17, remotion 6. Every Godot render shown is a Shader Lab render of a tested file in `lab-shaders/`; no editor frames are needed. Seventeen Manim scenes, nineteen ShaderLab captures and one docs screenshot must be built or recorded (below).

## Must exist before the build

1. **`ShaderLab`** Remotion component (spec: `../_godot-shaders-series/COMPONENT-SPECS.md`). Props used here: `layout` side and video, `code`, `codeFile`, `cues` with `label`, `video` (MP4 or PNG), `videoLabel`, `readouts`, `rings`, `title`, and `caption`, which carries GLOSSARY definition lines here (B06, B17, B40) as one static line under the result window.
2. **`shader_kit.py`** Manim helpers (same file): `ramp_strip`, `pixel_grid`, `plot`, `uv_square`, `code_card`; this film also needs two scene-local drawings: a labelled **ruler** (ticks, brackets, a marker) and a **window over a picture** (an outline sliding over a card with a clipped copy beside it).
3. **Capture harness** `lab/capture.gd` + `capture_shader.sh` with `--animate` float keyframes, `--material-at` (C07 and C13), `--tex`, `--sprite-tex`, `--set`, `--size`; see `CAPTURE-PLAN.md`.
4. **Docs screenshot D1** for B16 via Playwright.
5. **Manim classes** (one per Manim beat): B02_AddressSquare, B03_AnySize, B05_Lookup, B07_Window, B10_WorkedNumbers, B11_Reversal, B14_WhySmaller, B20_Pivot, B22_Centered, B26_Fold, B29_AddressCell, B30_OvalMeasured, B31_SquareCells, B32_CellToSquare, B37_EdgeSmear, B38_StepFunction, B39_Gate.
