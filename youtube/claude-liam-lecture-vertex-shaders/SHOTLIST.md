# Shot list: Vertex Shaders

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 40 body beats. Lane histogram: capture 27, manim 12, terminal 1. Every Godot picture shown is a Shader Lab render or a capture of a custom scene built in `evidence/planning-checks/scratch-project/capture_scenes.gd`, using a tested file in `lab-shaders/`. Nothing needs the Godot editor. Three things must be built or recorded first (below).

## Must exist before the build

1. **`ShaderLab`** Remotion component (spec: `../_godot-shaders-series/COMPONENT-SPECS.md`). 2. **`shader_kit.py`** Manim helpers (same file; this film also needs a vertex dot, a polyline through dots, a dot grid with a counter and a screen frame: see below). 3. **Capture harness** (`lab/capture.gd` + `capture_shader.sh`, same file) with a scene-script option that can load `evidence/planning-checks/scratch-project/capture_scenes.gd` (`build(id, parent, shader_dir, duration)` and `tick(ctx, t)`).

**This film's `shader_kit` additions:** `vertex_dot(label)` (terracotta dot with a monospace label), `polyline_through(points)`, `dot_grid(cols, rows)` with `count_up(grid)`, `screen_frame(w, h)` (an outlined 16:9 frame with a node square inside), `sine_curve(samples)`. All in the Claude palette; terracotta only as dots and rings.
