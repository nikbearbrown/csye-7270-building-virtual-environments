## Description

Start Assignment 1 with a working Godot game you can understand, extend, and defend. Liam, in for Professor Bear, combines Godot setup, a Walker Jumpman walkthrough, and source-to-result game-development explanations in one course film.

Every code excerpt is followed by what it does visually: the character's procedural art, collision rectangle, movement, level geometry, hazards, camera, progress bar, and pause/recovery. Then connect those mechanisms to your new character, two new jump landings, relocated finish, test evidence, Frictional log, and matching GitHub/Canvas submission.
