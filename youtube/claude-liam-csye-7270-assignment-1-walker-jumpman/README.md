## What this film changes

Eight exact source excerpts are each immediately followed by their visual consequence: procedural character art, collision box, movement, level geometry, hazards, camera, progress bar, and pause/recovery. Setup is followed by the actual Assignment 1 requirements, the 60/10/10/20 rubric, honest effort logging, and matching GitHub/Canvas submission versions.

The visual evidence shows the **unchanged starter**, not a finished student assignment. Gameplay is archived actual Godot output driven by scripted normal input. Art views are newly rendered, staged Godot previews. No human playtest of a student extension is claimed.

## Setup caveat

The public [Walker repository](https://github.com/nikbearbrown/walker) still describes its older Unity-oriented workflow. The film discloses this rather than inventing an installed Godot Walker command. The [Jumpman starter](https://github.com/nikbearbrown/walker-jumpman) is a standalone Godot project: import `godot/project.godot` and run it. Course Walker context and Claude Code are distinct from the Godot engine.
