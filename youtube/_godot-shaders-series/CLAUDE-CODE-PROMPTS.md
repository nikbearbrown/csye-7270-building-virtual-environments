# Claude Code prompts: build the Godot shader films

**What this is.** One ready-to-paste prompt per film, in the order I recommend building them (the order of the list below). Each points a medium-effort Claude Code session, launched from `/Users/bear/Documents/CoWork/bear-textbooks/books`, at that film's `BUILD-PROMPT.md`.
**Why.** Your two-stage rule: a higher-effort session lays the film out; a medium-effort Claude Code session builds it. The layouts are finished and checked; these start the builds.
**Found.** Build **Godot Shaders** first. Its build also creates the three shared pieces every other film reuses (the `ShaderLab` Remotion component, the Manim helper kit `shader_kit.py` and the capture harness). Each build is audio-first (the film is voiced before anything is recorded) and resumable (it keeps `BUILD-LOG.md` and marks each phase DONE), so if a session ends early, paste the same prompt again. Nothing is published or staged by any of them. Nobody needs to record a screen by hand: the editor frames are recorded by script.

Switch the session to medium effort, launch it from `books/`, paste one prompt, and let it run.
