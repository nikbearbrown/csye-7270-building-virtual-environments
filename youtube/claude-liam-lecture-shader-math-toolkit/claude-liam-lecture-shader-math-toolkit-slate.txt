People think shaders need advanced math. They need about a dozen small functions, and each one reshapes a smooth run of numbers. Learn what each does, and you can predict what a shader will draw. Five terms, a shader is a small program the graphics card runs to decide how something is drawn. A pixel is one dot of the picture. UV is a point's address on a shape, 0 to 1 across, 0 to 1 down. A function takes numbers in and gives one number out, and a vector is a bundle of 2 to 4 numbers. This ring is not an image. Three small functions draw it. One measures distance. One softens an edge. One blends two colors. By the end, you will be able to read every line of it. Start with a ramp, a smooth run of values from 0 up to 1. Clamp pins a number inside a range. Below the low end, you get the low end. Above the high end, you get the high end. In between nothing changes. It is max first and min. Smooth step is a switch that eases in and out. Give it two edges and a ramp. Below the first edge, zero. Above the second one, between them a smooth S with no corners.
