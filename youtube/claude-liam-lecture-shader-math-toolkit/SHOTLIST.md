# Shot list: The Shader Math Toolkit

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 41 body beats. Lane histogram: manim 23, capture 16, remotion 2. Every Godot render shown is a Shader Lab capture of a tested file in `lab-shaders/`; every curve drawn in Manim is the same formula the shader computes (`evidence/planning-checks/plot_data.py`, compared pixel for pixel with Godot's renders in `dense-compare.md`).

## The standard plot (defined once; B04 teaches it, every later plot reuses it)

Square axes about 4.4 Manim units wide on the cream stage; `input` along the bottom with the ticks 0 and 1, `output` up the side with 0 and 1 (or the range the beat needs); the curve in ink-grey stroke; a terracotta dot travelling the curve; a thin dashed drop line from the dot to the **ramp strip** under the axes, at the same x scale; the strip drawn as a row of 64 narrow tiles with thin cream gaps in true grays (value v drawn as gray v: 0 black, 1 white; each tile is taller than wide, so GATE T cannot read a run of mid-dark tiles as one text blob; if it still does, fall back to a lifted scale, gray 0.50 + 0.50 v, and say so in BUILD-LOG), end labels 0 and 1; the formula in mono at least 32 on the top right. Terracotta only as the dot and as grey-backed rings; never as text. Midpoint rule: the 45 to 55 % frame is a settled still with its labels.

## Must exist before the build

1. **`ShaderLab`** Remotion component (shared; spec `../_godot-shaders-series/COMPONENT-SPECS.md`). 2. **`shader_kit.py`** Manim helpers (same file): `plot`, `ramp_strip`, `ramp_marker`, `uv_square`. This film also needs, if the shared kit does not have them, a `plot_with_strip` (the standard plot above), a `number_line`, a `vec_arrow` and a `chip` (function-name chip); write them in `_kit_extra.py` beside the film and say so in `BUILD-LOG.md`. 3. **Capture harness** `lab/capture.gd` + `capture_shader.sh` (same file): this film uses only `--animate` sequences on one uniform and still PNGs (no scene scripts, no key events). 4. **Docs screenshot D1** for B12 via Playwright (`CAPTURE-PLAN.md`). 5. **No editor frames** are needed. The curves' numpy formulas are in `evidence/planning-checks/plot_data.py`.
