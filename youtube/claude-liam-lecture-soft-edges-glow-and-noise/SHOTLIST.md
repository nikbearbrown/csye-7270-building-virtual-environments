# Shot list: Soft Edges, Glow and Noise

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 42 body beats. Lane histogram: capture 23, manim 15, editor 2, remotion 2. Every Godot render shown is a Shader Lab, custom-scene or editor capture of a tested file in `lab-shaders/`. The build must first create the shared pieces below (they are specified, not yet built), then record the 23 captures and the two documentation screenshots listed in `CAPTURE-PLAN.md` and copy the editor frames, which are already recorded by script.

## Must exist before the build

1. **`ShaderLab`** Remotion component (spec: `../_godot-shaders-series/COMPONENT-SPECS.md`). 2. **`shader_kit.py`** Manim helpers (same file): `ramp_strip`, `pixel_grid`, `plot` are used here; this film also needs a **plot with a travelling dot and dashed guides**, a **distance-ring spot on a pixel grid** and a **bar-through-gate** drawing, all built on the same kit. 3. **Capture harness** `lab/capture.gd` + `capture_shader.sh` (same file) with `--material-at`, `--animate` (piecewise), `--scene`, `--call-at`, `--time-origin`; the scene scripts do the scripted switches (root `use_hdr_2d`, a WorldEnvironment appearing, a clear-colour change, the vec2 orbit) and set the stage colour. 4. **Editor frames E1, E3**: already recorded by script (B19: this film's own frames; B24: two frames reused from the Textures and Color recording), copy them (`CAPTURE-PLAN.md`). 5. **Documentation screenshots D1, D2** via Playwright (`BrowserCapture` convention).
