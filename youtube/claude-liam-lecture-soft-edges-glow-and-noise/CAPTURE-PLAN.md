# Capture plan: Soft Edges, Glow and Noise

**What this is.** Every Godot render, editor frame and documentation screenshot the build session must record for this film, with the exact shader file, target, values over time, duration, renderer and the result already verified. Nothing for the film is recorded yet except the editor frames (section E, recorded by script on 2026-10-13); every number below comes from planning runs in `evidence/planning-checks/`.
**Why.** Films show only what was really done and recorded. This is the list of things to really do, written so a medium-effort session can do them without further judgment.
**Found.** 23 Godot renders (5 stills and 18 clips, 14 of them needing a scene script), 2 editor captures (E1 reused from the Textures and Color recording, E3 recorded for this film by script on 2026-10-13: no click, no recording by hand, no render fallback needed), 2 documentation screenshots. All 15 shaders compile and every probe value below was read in a real Godot 4.7.2 window on Forward+ (Apple M4 Pro). Three things the Lab cannot do were checked in scratch scripts that double as the node recipes for the scene scripts: a real `NoiseTexture2D`, HDR 2D and a WorldEnvironment, and run-time switches.

Conventions for all captures: 30 fps; render at 3840 x 2160 using the Signal Garden SubViewport native-size route (`../_godot-shaders-series/COMPONENT-SPECS.md`); the **square target** is a 576 x 576 logical-pixel ColorRect centred on the 1280 x 720 logical canvas, so `UV` is square and a circle stays a circle (the shader's `UV` (u, v) sits at frame x = 0.275 + 0.45 u, y = 0.1 + 0.8 v, which is how the lanes place rings and readouts); Acts I to IV use the Lab stage `#D9D5CA`, Act V the slate `#5F7A96` (set by the scene script, 79 RGB from the type gate's MUTE grey and 131 from ink, so GATE T cannot read it as text); Forward+ unless stated; offline fixed tick rate, so nothing here says anything about real-time frame rate; every scripted switch is labelled "scripted" on screen and in `videoLabel`. Output to `runtime/remotion/public/soft-edges-glow-and-noise/` with the names the lanes use. **Timing:** the planned lengths below are estimates of the beats; if the measured audio of a beat differs from the planned clip length by more than a second, re-record with the same schedule expressed as fractions (`--length <audio seconds>`), never by editing a shader or a narration line.

Harness features this list needs (all specified in `../_godot-shaders-series/COMPONENT-SPECS.md`): `--material-at SECONDS`, `--animate name:t0:v0,t1:v1,...` (piecewise), `--scene PATH.gd`, `--call-at SECONDS:method`, `--time-origin SECONDS`, stills as PNG, PNG-sequence output then `ffmpeg` to MP4. Scene scripts needed: a two-panel script (C10, C15), a NoiseTexture2D script (C11 to C16, C23), a vec2 orbit script (C08), an HDR 2D / environment / stage-colour switch script (C18 to C23). The node recipes are in `evidence/planning-checks/noise_check.gd` (`make_noise`, `make_rect`), `glow_check.gd`, `toggle_check.gd` (the switches) and `finale_check.gd`.
