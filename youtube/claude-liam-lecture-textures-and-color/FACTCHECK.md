# Fact-check (Gate F): Textures and Color

**What this is.** Every checkable claim in the narration and on screen, with its verdict and where the verdict comes from. Verdicts: PASS (checked), CORRECTED (the source said something looser or missed it, and the film says the corrected thing), EXEMPT (a definition, an example or design advice, labelled as such), OPEN (cannot be verified yet; says why).
**Why.** Color is where "it runs" and "it looks right" are furthest apart, and the one third-party source for this film never mentions color spaces at all. Nothing here is trusted because it was said confidently: the central claims were run on three renderers.
**Found.** 119 rows: 102 PASS, 4 CORRECTED, 13 EXEMPT, 0 OPEN. The film's main finding is a matrix, measured on Godot 4.7.2: whether `source_color` changes a pixel depends on the renderer (Forward+, Mobile, Compatibility), on 2D against 3D, and on the HDR 2D setting, and the docs say exactly the same in one sentence (row 89). The three rows that were OPEN (52, 94, 107) were closed on 2026-10-13 by real editor frames recorded by script (editor-capture README): the Inspector's resource menus have a heading New over bare class names, so the earlier "New NoiseTexture2D" line was wrong (row 52, CORRECTED); the Inspector draws the hinted color as a swatch that opens a picker and the plain vec4 as four boxes (row 94); and the renderer's name is hidden in the editor's upper right corner by default, so the docs sentence the first plan relied on is a docs-versus-run CORRECTED row (106) and the film now gives the Project Settings path (row 107). Three earlier results were replaced and are labelled in RESULTS.md: the first plus-check batch (a shell array reached the runner as one word, so its probes were dropped), the first swatch picture (a coral patch too near the accent color of the type gate, replaced by a rose) and the first burn ramp (its middle stop too near the same accent, replaced). Not tested, and not claimed: lit 3D surfaces, other GPUs and platforms, real-time frame rate.

Machine: Apple M4 Pro, macOS, Godot **4.7.2 stable (official)**. Compatibility runs through OpenGL 4.1 on Metal. Pixel values are 0..1 floats from 8-bit screenshots, so they carry plus or minus one step (0.004); with HDR 2D on the value is converted from linear to what the screen shows. Docs: Godot 4.7 (docs.godotengine.org/en/stable), read 2026-10-13. Editor frames: `P` = `_godot-shaders-series/editor-capture/png/1920x1080` (folders textures-and-color, renderer-path, godot-shaders, soft-edges-glow-and-noise; native-size twins in `png/3456x1944`), recorded by script in the real 4.7.2 editor on 2026-10-13, labels read from the live UI (`_godot-shaders-series/editor-capture/README.md`).
