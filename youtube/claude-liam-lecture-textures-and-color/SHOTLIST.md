# Shot list: Textures and Color

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 41 body beats. Lane histogram: capture 27, manim 7, remotion 4, editor 3. Every Godot render shown is a Shader Lab, harness or editor capture of a tested file in `lab-shaders/`; three beats show the real editor, one a real docs page. What must be built or recorded first is listed below; every capture is specified in `CAPTURE-PLAN.md`.

## Must exist before the build

1. **`ShaderLab`** Remotion component, **`shader_kit.py`** Manim helpers and the **capture harness** (`lab/capture.gd` + `capture_shader.sh`): shared with the other shader films, specified in `../_godot-shaders-series/COMPONENT-SPECS.md`. Build them once; if another film's build already made them, reuse them.
2. **Harness additions this film needs** (listed in `CAPTURE-PLAN.md` section H): the extra texture kinds (a 6 by 6 F table, a four-patch swatch picture, a burn-ramp GradientTexture1D, a grey ramp, NoiseTexture2D), a ColorRect node color, a switch-on time for a material, HDR 2D, a modulate, composites of two or four renders, and three small custom scenes. A reference implementation (`evidence/planning-checks/runner_plus.gd`, `verify-patches.gd`) is already verified.
3. **Editor frames** E1, E2 and the renderer-path frames for B40 are already recorded by script (`CAPTURE-PLAN.md` section E): copy them, no clicks. Then the **docs screenshot D1**.
