# Planning checks: results

**What this is.** The runs behind the numbers in `FACTCHECK.md`, in the order they were done, with the script, the log and what each run showed. All on Bear's Mac: Apple M4 Pro, Godot 4.7.2 stable (official), 2026-10-13. Forward+ unless a row names another renderer; Compatibility ran as "OpenGL API 4.1 Metal".
**Why.** So any figure on screen can be re-run. Failed, inconclusive and superseded runs are kept and labelled.
**Found.** Seventeen numbered runs, two batches over every shader the film shows (34 Lab renders, about 65 harness renders), one measurement script for the dissolve. The central result is a matrix: whether `source_color` changes a pixel depends on the renderer, on 2D against 3D, and on the HDR 2D setting (runs 1, 2, 3, 6), and it agrees with the one sentence in the docs that says so. Two batches were superseded and are labelled below.

**How to re-run.** The Lab batch needs nothing but the Lab: `./run-lab-checks.sh`. The harness batches and the numbered scripts use a scratch Godot project: make an empty folder, copy `project.godot` and `runner_plus.gd` into it, point `PLUS_PROJECT` at it (`plus.sh`) and run `./run-plus-checks.sh`, `./run-plus-extras.sh`, `./run-6-sampler-hint-matrix.sh`, `./run-15-alpha-untouched.sh`, `./run-16-filter-repeat-defaults.sh`, `./run-17-step-equality.sh`; the `verify-*.gd` scripts run with `godot --path <that folder> [--rendering-method forward_plus|mobile|gl_compatibility] --script res://<file>.gd`. All of them take the Lab's lock (`/private/tmp/claude-501/shaderlab.lock`) when they open a window through `check_shader.sh` or `plus.sh`. `runner_plus.gd` is the Lab's `runner.gd` plus the extra texture kinds (`tiny_f`, `swatches`, `ramp_grey`, `burn_ramp`, `burn_ramp_tex`, `noise2d`), `--rect-color`, `--modulate`, `--hdr2d`; the Lab itself is unchanged.

## Superseded and failed runs, kept or labelled

- **First plus-check batch (not kept).** Its shell arrays were passed to the runner as one word, so the probe positions and the square window size were dropped; every number in the film comes from the re-run (probes present, `size [360, 360]` for the square renders).
- **First swatch picture (not kept).** The four-patch picture first had a coral patch, which sits within 17 RGB of the terracotta accent (#D97757); a rose (#E6598C) replaced it and the swatch, gray and mix numbers were re-measured (runs 6 and 8 and the plus batch).
- **First burn ramp (not kept).** Its middle stop `#E8742F` put rim pixels inside the accent tolerance of the type gate; it became `#F08A2C`. The pixel counts did not change.
- **Not run on purpose.** Lit 3D surfaces, other GPUs and platforms, Mobile in the pictures (it matches Forward+ in every measured cell), real-time frame rate.
