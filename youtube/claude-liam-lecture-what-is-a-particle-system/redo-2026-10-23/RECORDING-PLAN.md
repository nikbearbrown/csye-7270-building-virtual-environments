# Genuine editor recording

Window-only macOS screencapture records the actual Godot editor. A project-local EditorPlugin selects real nodes/resources, applies undoable properties and opens the actual GDScript editor. Every scripted operation is labeled in the native toolbar and logged. Native media is retained without retiming; editorial crops only remove window shadow or focus genuine pixels. No reconstructed editor is used.

Capture actions and offsets are in beat_sheet.json. Body narration begins after a measured 1.2 second lead so the visible operation leads the explanation. The source clips are cut at original speed to the measured narration clock.


Supplemental source and single-particle beats: BREF shows the actual Nature of Code page captured by local Chromium; BONE isolates one complete particle life with velocity/acceleration vectors in the real editor. Native source-text inserts use a later formatting-only source version, with original equations unchanged; exact editorial cuts are retained in captures/code-insert-edit.json. Parameter beats use labeled synchronized crops of the original viewport and Inspector; original full-window source remains available.
