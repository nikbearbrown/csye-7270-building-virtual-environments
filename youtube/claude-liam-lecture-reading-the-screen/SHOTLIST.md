# Shot list: Reading the Screen

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 38 body beats. Lane histogram: capture 25, manim 11, remotion 2. The 23 Godot captures (C01 to C23) are all small scene scripts that already run: `evidence/planning-checks/scene_c*.gd`, tested through `scene_runner.gd`. Every shader shown is a tested file in `lab-shaders/`. Eleven Manim scenes and the shared components below must be built.

## Must exist before the build

1. **`ShaderLab`** Remotion component (spec: `../_godot-shaders-series/COMPONENT-SPECS.md`). 2. **`shader_kit.py`** Manim helpers (same file). 3. **Capture driver**: this film brings its own, already tested: `evidence/planning-checks/scene_capture.gd` (see `CAPTURE-PLAN.md`: the scene contract). The shared `lab/capture.gd` is not needed for this film. 4. Eleven Manim scenes (the rows below with a `manim` lane): `B02_TheCopy`, `B04_ThePieces`, `B05_FilledEveryFrame`, `B06_AddressToColor`, `B07_TwoAddresses`, `B11_FullRect`, `B12_LayerStack`, `B13_ClicksStop`, `B14_WeightedSum`, `B18_StretchedAddresses`, `B30_OnceBeforeTheFirstReader`.
