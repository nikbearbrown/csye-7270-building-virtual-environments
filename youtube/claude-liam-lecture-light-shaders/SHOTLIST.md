# Shot list: Light Shaders

**What this is.** One row per body beat: what the sentence is about, the picture chosen, the lane that came second, and why this one won. Every beat was auditioned against at least one other lane.

**Why.** The lecture skill's BEST-BEAT LAW: no lane is the default and none has a quota; the picture whose motion is the claim wins. A reviewer can disagree with any row without reading code.

**Found.** 40 body beats. Lane histogram: capture 25, manim 12, remotion 3. Every Godot render shown is a capture of a scene in `evidence/planning-checks/light_scene.gd` (data: `captures.json`) running a tested file in `lab-shaders/`; there is no editor frame. Six things must exist before the build (below).

## Must exist before the build

1. **`ShaderLab`** Remotion component (spec: `../_godot-shaders-series/COMPONENT-SPECS.md`; shared with every shader film). 2. **`shader_kit.py`** Manim helpers (same file). 3. **Film-local Manim helpers** in the scene file: `lamp_dot`, `unit_arrow(from, to)`, `swatch(value)`, `window_frame(w, h)` with an origin dot and a DOWN-pointing y axis. 4. **Capture loop**: `evidence/planning-checks/record_capture.gd` (PNG sequence from `light_scene.gd`; see `CAPTURE-PLAN.md`), then ffmpeg to MP4 at 30 fps. 5. **Docs screenshot** for B04 via Playwright (D1). 6. Nothing else: no editor action and no generated media.
