## 2. Hard laws for Manim scenes (the costly traps, already learned)
- Scene classes: literally `class B45_Name(Scene):`; the name starts with its beat id; never subclass a helper (run.sh's scene discovery is textual and would slate it).
- End every scene with `done(self)`. Pace with `until(self, "exact phrase from the narration", lead=...)`. `[pace] ... OVER` in a render means the clip outruns its audio and compile will centre-cut it: shorten. Leave >= 0.1 s slack.
- MIDPOINT RULE: GATE T and Gate V sample each clip at 50%. `self.play` is guarded automatically, `self.wait` is not: the 45-55% frame must be a still that already contains the labels that matter, nothing half-faded, mid-sweep, mid-draw or empty.
- Gate A (static stub): every scene must add >= 1 NEW non-text, non-Rectangle shape (Line/Dot/Arrow/Circle/Polygon/Create/GrowFromCenter...) AFTER its first frame, and the shape set must change; moves/fills/Transform of existing shapes do not count. Never do arithmetic on `c2p()/n2p()` results; never position with `Text.get_left()/get_right()` or `mob.get_right()` (the stub returns off-frame values): use explicit coordinates; wrap group slices as `VGroup(*...)`; wrap `get_center()` in `np.array(...)` before subtracting.
- Forbidden: `rate_functions.ease_in_quad`, `ease_out_cubic` (use kit `ease_in`); `.animate(path_arc=...)` (use `MoveAlongPath(obj, ArcBetweenPoints(a, b))`); `MoveAlongPath` and `.animate` on one object in one `play`; `FadeOut` of a NEW copy of a label (keep references).
- Type: EB Garamond LABELS via `T(...)`, size >= 32 (titles 40, hero numbers bigger). **Real code and logs in Menlo are different** (measured on this Mac, Manim 0.20.1): size 24 = 0.20 units per character, x-height 49 px at 4K (max ~58 characters in one column of 12.4 units); size 20 = 0.15 units per character, x-height 41 px = exactly GATE T's floor (max ~78 characters; borderline: PROVE it with the real 4K gate); sizes 28 and 32 = 0.25 units per character (max ~46 characters). GATE T's machine floor is 41 px of text-run height at 2160; the house floor of 32 is for serif labels. Real code is never reflowed and never shrunk below 20: pick the size your longest REAL line needs (`signal.gdshader` has two 70-character lines: that block needs size 20; show fewer lines, or one line at a time at size 24, when you want it bigger). Use `code_block(...)` (outline-only frame, real line numbers via `first=`) rather than boxing text yourself. Terracotta (`TERRA`) is NEVER text and never a thin/short stroke or underline: use a terracotta DOT, a ring over a grey backing (`ring()`), or a small spark. Numerals are ink. No fill behind text (Gate B fails highlighter rectangles): outline-only cells with >= 0.25 padding. No line, outline or arrow touching or crossing text; >= 0.3 gap between a leader line and its label. Labels sit BESIDE objects.
- Frame: stay inside +-6.2 x +-3.3 (the audit warns past +-6.3 x +-3.4, measured on text edges).
- Dark ink-coloured shapes packed together fuse into one "text blob" under GATE T: draw bars/blocks in the greys (`BAR1/BAR2/BAR3`, `DIM`, `GHOST`); a large near-black field fails (use `DIM`). Real engine captures on the DARK ENGINE GROUND (RGB 20,38,45), the dark teal texture and Godot's dark editor read as low-contrast text blobs: crop to the subject, give them a light border (`framed`), and land them AFTER the clip midpoint (A3's lesson: "a real capture with a dark interface landing at the 50% mark fails Gate B/T"). Test with a real 4K frame (below). Ink-coloured rings around text fail overlap: use grey or terracotta-over-grey rings.
- Pango drops some single spaces in `Text()` on this Mac (words fuse: "fingerprintsin"): LOOK at the rendered still; if words fuse, double the space at that boundary. A `Paragraph` line must not START with a lowercase `w`.
- `Transform` of different polygons crumples mid-flight; morph like-for-like or fade/replace. `Indicate` the whole group.
- Manim caches partial movie files by animation hash: after replacing an image file behind the same path, change the file NAME, or the old pixels replay. (`crop_img()` gives a new name per crop.)
- Do not shrink the laws to fit a layout: split the beat's picture, or tighten the text. A beat past ~15 s of speech is two pictures in time.

## 6. Pacing (no audio exists yet)
`beat_sheet.json` holds `estimated_duration_s` = words / 3.2 (the measured pace of the sibling films); `kit.py` reads it as the beat's `_TARGET`. Real audio will differ by up to ~15%. Therefore: finish every FIXED-TIME sequence by about 75% of the estimate; cue the rest with `until(...)` (character share of the narration x the target) so cues scale with the real audio; never end an animation after 90% of the estimate. `done(self)` pads the rest. Your preflight shows `[pace] B30 content=...s target=...s`; keep `content` <= target - 0.1 and, ideally, <= 0.9 x target.
