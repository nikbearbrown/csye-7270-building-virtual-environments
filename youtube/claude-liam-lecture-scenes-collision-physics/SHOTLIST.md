## Tool evidence rungs

- BrowserCapture: real official public documentation and native Godot viewport output (rung 1). Camera targets the relevant property or result, with transitions outside 45–55%.
- ClaudeCodeBeat: executed GDScript and actual saved scene excerpts (rung 2); conventions are an authored document, not executed code. No invented compiler output. Exact excerpt source ranges are in evidence/excerpt-map.json.
- CCPlainShell: real local logs, no fictional shell or agent conversation.
- Manim: deliberately labeled conceptual geometry or plots of actual JSON measurements. Show Tell isometric handoffs were auditioned for B01/B07; precise scene relationships and callback direction teach more directly here. There is no isometric quota.
- No Claude Code or Codex session is claimed; the learner composer prompt is explicitly a prompt to paste.
