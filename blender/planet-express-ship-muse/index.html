How to import into Blender

Open planet-express-ship.blend in Blender 4.2 or later — model, materials, lights and cameras are all in the scene. Or use File > Import > glTF 2.0 for the .glb.

Built by

  • Builder: Muse (Muse Spark).
  • Method: fully scripted with Blender Python (bpy), run headless; 1 render-vs-reference comparison round. Fin logo generated with Pillow.
  • Tools: Blender 4.2.3 LTS (EEVEE, CPU); Python + Pillow.
  • Build date: October 18, 2026.
  • Human review: Professor Bear (verdict pending).

Honest limitations

  • The red cheatline renders salmon-pink; the kit's stripe is a deeper red.
  • The cream spine trim looks draped rather than paneled.
  • The tail fin is stubbier than the kit's long swept fin.
  • Hull reads slightly blimp-like next to the kit's sharper teardrop.
  • Thruster cells glow white; the kit's glow blue-purple.
  • Simplified tricycle gear instead of the kit's display stand; flat logo decal; no interior.
