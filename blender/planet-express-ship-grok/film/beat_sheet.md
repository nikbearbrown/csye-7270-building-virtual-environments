## Hand-build steps (Blender UI reconstruction, hypothetical)

**B04, The Brief.** 1. Add the photos as camera Background Images (Camera properties → Background Images → Add Image). 2. One camera per photo; keep the photo's aspect ratio in Output properties. 3. Keep the photos visible at about 50% opacity while you model.

**B06, Blockout By Hand.** 1. Add → Mesh → Cylinder (32 vertices); R Y 90 to lay it along X. 2. S X to stretch it to the hull length; Tab into Edit Mode. 3. Ctrl+R to add 10 to 20 loop cuts along the length. 4. Select each ring (Alt+click) and S, S Y, S Z to match the side and top photos. 5. O for proportional editing; G X on the nose ring to draw it to a point. 6. Object → Shade Smooth; Ctrl+2 for a Subdivision Surface.

**B07, Proportions From Measurements.** 1. Scene properties → Units: Metric, Length: Millimetres (or keep one unit and write down the scale). 2. Import the STL parts (File → Import → STL) as a measuring guide, on their own collection. 3. N panel → Item → Dimensions: read the hull's length, width and height; scale your hull to match. 4. Hide the guide collection before rendering.

**B08, The Order Of The Parts.** 1. Model the hull and freeze it before details (save a copy: File → Save Copy). 2. Snapping: Face Project, with Align Rotation to Target, to set parts flush on the hull. 3. Or add a Shrinkwrap modifier to thin parts (lip, strips) targeting the hull. 4. Keep each part a separate object named for what it is.

**B10, Modifiers By Hand.** 1. Modifier tab → Add Modifier → Generate → Mirror; axis Y, Clipping on. 2. Bevel modifier: Limit Method Angle, 3 segments, small width. 3. Solidify on thin panels and the fin; check Even Thickness. 4. Optional: Boolean (Difference) with a cylinder cutter per porthole, then tidy the topology. 5. Subdivision Surface last in the stack.

**B11, Materials.** 1. Material tab → New; Base Color → Hex (for example 1A9A8A); Roughness about 0.3. 2. Coat Weight 0.25 on the teal for the toy gloss. 3. Fin logo: Shader Editor → Image Texture into Base Color; UV-unwrap the fin (U → Project From View). 4. Assign materials per part, or per face in Edit Mode.

**B12, Lighting And Cameras.** 1. Render properties → Render Engine: Cycles; Denoise on. 2. Add → Light → Area, four times: key, fill, top, rim; point each with a Track To constraint or by hand. 3. World colour pale grey, strength about 0.8. 4. Add → Camera; Numpad 0; N panel → View → Lock Camera to View; move until the photo lines up. 5. Camera properties → Focal Length to match the photo's look (try 50, 85, 100 mm).

**B14, Export To G L B.** 1. File → Export → glTF 2.0 (.glb/.gltf). 2. Format: glTF Binary (.glb). 3. Include: Selected Objects if needed; Data → Mesh → Apply Modifiers on. 4. Re-import the .glb into an empty scene to check it.


## What the AI script did (evidence)

- **B04:** Twelve cameras in params.json, one per reference photo (target, azimuth, elevation, distance, lens); every round renders all twelve. (`../scripts/params.json`, `../scripts/build_pe.py`)
- **B05:** Hull = one lofted quad mesh: nx 200 stations by nth 128 points, superellipse sections from the w / lip / top / bot profile tables. (`../scripts/build_pe.py`, `../scripts/params.json`)
- **B07:** Round 15 refit the hull profile tables to the STL kit envelope (178.6 x 49.4 x 48.3 mm, bell ~25 mm) at 0.066 units/mm, measured with stl/measure.py. (`../BUILD_NOTES.md`, `../scripts/stl/parts.md`, `../scripts/stl/measure.py`)
- **B08:** build_pe.py sections run materials → hull → lip band → portholes → cockpit → turret → fin and logo → vents and hatches → wings → engine → studio; details are placed with surface functions of the hull. (`../scripts/build_pe.py`)
- **B09:** Modifiers in build_pe.py: SOLIDIFY (patches, fin), BEVEL (fin, angle-limited, 3 segments), SUBSURF level 2 (wings). Sides built with `for side in (1,-1)`; no MIRROR, no BOOLEAN. (`../scripts/build_pe.py`)
- **B11:** mat() builds a Principled BSDF per params colour (base colour from hex, roughness 0.12 to 0.7); teal coat 0.25; logo.png / logo_m.png image textures. (`../scripts/build_pe.py`, `../scripts/params.json`, `../scripts/make_logo.py`)
- **B12:** Cycles CPU, OpenImageDenoise, 24 samples; area lights Key/Fill/Top/Rim; world #D9DADB; cameras from (target, azimuth, elevation, distance, lens 50/70/85/100 mm). (`../scripts/build_pe.py`, `../scripts/params.json`, `../scripts/final.py`)
- **B13:** compare.py stacks render under photo per camera; overlay.py draws silhouette overlays; round 14 height x1.20 overshot, backed off to x1.08. (`../scripts/compare.py`, `../scripts/overlay.py`, `../BUILD_NOTES.md`)
- **B14:** final.py: bpy.ops.export_scene.gltf(export_format='GLB', export_apply=True) after the gallery renders. (`../scripts/final.py`)

## What the evidence does not establish

- Whether the toy's taller-looking upper hull in the side photos is the model or the photos' close wide-angle lenses: the cameras are matched by eye.
- The STL kit's small-part names are best guesses from shape and size.
- The hand-build steps are reconstructed teaching steps; nobody has built this ship by hand from them.
