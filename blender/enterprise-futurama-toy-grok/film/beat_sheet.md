## Hand-build steps (Blender UI reconstruction, hypothetical)

**B04, The Brief.** 1. Add the blueprint views as Reference images (Add → Image → Reference) in the front, side and top orthographic views. 2. Put the concept image on a camera as a Background Image for the hero view. 3. Lock the reference objects so they can't be selected while you model.

**B06, Blockout By Hand.** 1. Front orthographic view (Numpad 1); Add → Mesh → Plane, merge to one vertex (M → At Center). 2. Tab into Edit Mode; Ctrl+right-click to place vertices along half the saucer's outline over the blueprint. 3. Modifier tab → Add Modifier → Generate → Screw; Axis Z, Steps 64 to 128, Merge on. 4. Repeat for the secondary hull and one nacelle with Axis X. 5. Object → Shade Smooth (or Shade Auto Smooth).

**B07, Proportions: Blueprint, Then Concept.** 1. Scale the saucer to exactly 2 units across (N panel → Dimensions) and measure everything as a ratio of it. 2. Place the nacelles and hull from those ratios with G and typed values (G X -1.0). 3. Switch to the hero camera and adjust against the concept; write the new numbers down.

**B08, The Order Of The Parts.** 1. Big shapes first, then the parts that join them (neck, pylons), then small details. 2. Neck and pylons: Add → Mesh → Cube, scale into a beam, bevel the edges, rotate to connect hull and nacelle. 3. Parent each detail to its main shape (Ctrl+P) so moving the hull moves its parts.

**B10, Modifiers By Hand.** 1. Nacelle and pylon: Add Modifier → Mirror, axis Y, mirror object the saucer (centred at the origin). 2. Subdivision Surface (Ctrl+2) on the saucer, hull and nacelles; add support loops (Ctrl+R) at the rims. 3. Bumper lights: Shrinkwrap modifier targeting the bumper, or Boolean Union then remesh. 4. Bevel last on hard-edged parts.

**B11, Materials And Colour.** 1. Material tab → New → Principled BSDF; Base Color hex 8797A6; Roughness about 0.24. 2. Render properties → Color Management → View Transform: Standard, Look: None. 3. Glass: Transmission Weight 1.0, low roughness, for the bridge dome.

**B12, Lighting And Cameras.** 1. Add a plane under the ship; Object properties → Visibility → Shadow Catcher. 2. Render properties → Film → Transparent. 3. Camera properties → Type: Orthographic for the blueprint views; set Orthographic Scale to frame them. 4. Hero camera: Focal Length 45 mm, low and about 60° off the nose.

**B14, Export To G L B.** 1. File → Export → glTF 2.0 (.glb/.gltf); Format glTF Binary. 2. Data → Mesh → Apply Modifiers on. 3. Re-import the .glb into a new scene and check the colours.


## What the AI script did (evidence)

- **B04:** Concept image as style target; blueprint ratios as the starting layout (BUILD_NOTES Sources and Measurements). (`../BUILD_NOTES.md`)
- **B05:** lathe(): saucer from a 121-point superellipse profile (R 1.0, Ht 0.32, Hb 0.24, exponents 1.9 / 2.1), 128 segments; secondary hull from hull_prof (8 points) around X; nacelles lathed around X. (`../scripts/build.py`, `../scripts/params.json`)
- **B07:** Blueprint ratios (saucer 1.0, nacelles ~1.26 long at ±0.38); round 5 re-measured off the concept: nacelle front x ≈ -1.0, spacing ±0.7, hull front x ≈ -0.5. (`../BUILD_NOTES.md`, `../scripts/params.json`)
- **B08:** build.py sections: SAUCER (bumper, lights, portholes, bridge, sensor hub) → SECONDARY HULL (deflector, end cap, stripe panels) → beams (neck, pylons) → NACELLES → staging. (`../scripts/build.py`)
- **B09:** Only BEVEL modifiers (bumper lights: width 0.012, 3 segments; hull lights: width 0.014). new_obj/lathe have a sub parameter but every call leaves it 0. Nacelles built in `for side,tag in ((1,'P'),(-1,'S'))`. (`../scripts/build.py`)
- **B11:** mat() per params colour: body #8797A6, cream #DCC594, red #CF4F37, dark #45545F, white #E9E7E0; view_transform 'Standard' from round 2 (round 1 was the default AgX). (`../scripts/build.py`, `../scripts/params.json`, `../BUILD_NOTES.md`)
- **B12:** Area lights Key/Fill/Top/Rim/Front; Cycles CPU, OIDN, 64 samples; film_transparent + is_shadow_catcher ground; comp.py gradient; hero (az 60, el 6, d 5.5, 45 mm); side/top/front ORTHO in render.py. (`../scripts/build.py`, `../scripts/params.json`, `../scripts/render.py`, `../scripts/comp.py`)
- **B13:** compare.py builds render-vs-reference sheets: hero vs concept, side/top/front vs blueprint; round 9 narrowed the pylons after the top view. (`../scripts/compare.py`, `../BUILD_NOTES.md`)
- **B14:** export.py: export_scene.gltf(export_format='GLB', export_apply=True); writes stats; does not save the .blend. (`../scripts/export.py`)

## What the evidence does not establish

- The concept measurements assume a camera about 62 degrees off the nose; the true angle of a generated image is unknown.
- The blueprints are a non-toy style, so the side, top and front scores judge layout only, not the look.
- The hand-build steps are reconstructed teaching steps; nobody has built this toy by hand from them.
