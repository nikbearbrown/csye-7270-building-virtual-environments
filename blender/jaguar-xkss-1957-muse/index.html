How to import into Blender

  1. Native scene: install Blender 4.2 or later and open the .blend with File → Open.
  2. GLB: File → Import → glTF 2.0 (.glb/.gltf). Flat colours only — no textures.

Built by

  • Builder: Muse (Muse Spark).
  • Method: fully scripted with the Blender Python API (bpy); 5 render-vs-reference comparison rounds.
  • Tools: Blender 4.5.9 LTS headless (EEVEE-Next), Python/bpy, PIL for composites.

Honest limitations

  • Stylized, subdivision-smoothed lofted body — not true XKSS surfacing; proportions approximate, not built to real scale.
  • Seats, dashboard and interior are box-built; no bonnet louvers; no wire wheels (Dunlop-style solid disc wheels instead, which matches the real car's solid discs, but simplified with no perforations or tread).
  • Simplified brightwork: bumpers, luggage rack and heat shield are plain chrome/steel shapes.
  • Colours approximate; glass and trim simplified; no badges, wipers or mirrors detail beyond a simple stalk mirror.
  • Judged harshly on overall look and feel: recognisably an XKSS from the side, weakest at the front where the lamps read flat.
