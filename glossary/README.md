# glossary

Terminology slide decks for CSYE 7270, and a markdown glossary of every term in them.

- `decks/`: one self-contained HTML deck per topic ("Terms - ....html"). Open in a browser; arrow keys or clicks step through animations. Same look as the review decks in the other courses.
- `GLOSSARY.md`: every term in every deck with its meaning and a tag (in the book text, in the glossary, editor or docs, outside source, video only). Generated from the decks.
- `notes/`: the build plan and template (`TERMS-TEMPLATE.md`), source lists for the game design decks, and the term list from Riot's "So You Wanna Make Games??" series.

More decks are added as they are built.
