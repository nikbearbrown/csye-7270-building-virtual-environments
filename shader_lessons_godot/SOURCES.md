# Sources and provenance

**What this is.** Where every file in this project came from: the third-party CgFX lessons it converts, the code-authored textures that stand in for the DVD's missing ones, and the Godot documentation and runs behind the notes. Written 2026-10-16.
**Why.** The originals are third-party teaching material whose redistribution terms nobody here knows, and the converted shaders are derived from them. This file records exactly what is whose, so nobody has to guess later.
**Found.** The source is the Eat 3D "Shader Production DVD" lesson set (author credit "Luiz" in every header). No licence or readme was in the source folder. **Rights are not confirmed by Bear.** The textures here are all code-authored; none of the DVD's textures (`default_color.dds`, `default_cube.dds`, normal and spec maps) were available, so none were used or imitated.

## The originals (third-party; not modified, not moved)

- Folder: `../shader_lessons/` (course repo root, untracked in git; see "Where the originals are now" below). 16 files: `00_superSimple.cgfx`, `01_base.cgfx`, `02_lambert.cgfx`, `03_lambert_ambient.cgfx`, `04_fresnel.cgfx`, `05_phong.cgfx`, `06_diffuse_mapped.cgfx`, `07_spec_mapped.cgfx`, `08_normal_mapped.cgfx`, `09_cube_mapped.cgfx`, `10_vertexAnim.cgfx`, `11_uv_manip.cgfx`, `12_techniques.cgfx`, `13_blended.cgfx`, `14_carShader.cgfx`, `15_uber.cgfx`.
- As named in the file headers: "Eat 3D - Shader Production DVD", and the sign-off "- Luiz". The headers carry no year; the files' modification dates are 31 January 2012 (the folder's is 2 November 2013).
- Licence: none found in the folder (it holds only the sixteen `.cgfx` files). **Rights not confirmed by Bear.**
- What was taken: the arithmetic and structure of each shader, converted by hand from Cg/CgFX to the Godot shading language by AI (Claude) under Bear's direction. What was not taken: the headers' lecture text is not copied; the comments in `shaders/*.gdshader` are written fresh and describe each lesson in new words.
- The originals' own wording is not stored anywhere in this project.

### Where the originals are now, and their fingerprints

When this work started, the folder was `shader_lessons/` in the course repo root. **By the end of the session it was no longer there: the whole folder had been moved to the macOS Trash (`~/.Trash/shader_lessons`) at about 21:23 on 2026-10-16.** This work never moved, edited or deleted it (the only deletions were this project's own scratch files). All 16 files are in the Trash copy with the same sizes and dates as at the start. Whoever trashed it may have meant to (rights, or the git concern below); nobody has been asked. Until it is restored, the relative path `../shader_lessons/` used in this project's files points at nothing.

## Textures: code-authored, no outside art

Generated by `tools/make_textures.py` (Python, numpy, Pillow); re-running it reproduces every file. Provenance of each:

| File | What it is | How it was made |
|---|---|---|
| `textures/diffuse_checker.png` | 512 by 512 sRGB, 8 by 8 checker (sand and steel blue) with four marker cells on the camera-facing side of the test sphere | two flat colours by cell parity; four cells overwritten by hand-picked colours |
| `textures/spec_rg.png` | R = rim mask (bright and dim rows), G = highlight mask (sand cells shine), B = 0 | computed from the cell grid |
| `textures/spec_uber.png` | R = highlight mask (odd rows), B = reflection mask (even columns) | computed from the cell grid |
| `textures/normal_gl.png` | tangent-space normal map, OpenGL / Maya convention (green = up the image) | a round dome per 64 px cell, 20 px high; normals from the analytic slope of the height field; rounded to the 8-bit file value |
| `textures/normal_dx.png` | the same map with green inverted (DirectX convention) | 255 minus the green byte of `normal_gl.png` |
| `textures/blend_map.png` | red band, green and blue regions for the blend lesson | two soft joins in u, plus a blue disc and a green disc |
| `textures/cube_px.png` ... `cube_nz.png` | six 256 by 256 faces of a reflection cube map (blue sky, checker floor, four coloured wall markers on the horizon, one white sun disc) | each face pixel's direction from the OpenGL cube-map face table, colour from a simple function of the direction |

No photographs, no scans, no generated images, no files from any outside source.

## Godot facts and where they came from

- Every statement about Godot behaviour in `CONVERSION-NOTES.md` was measured by running Godot 4.7.2 (`tools/traps.gd`, `tools/verify.gd`, `tools/cg_isms.sh`; logs in `evidence/`). The Godot 4.7 documentation page for the shading language (`docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/shading_language.html`, fetched 2026-10-16) lists the hints `source_color` ("Used as color" for vec3 and vec4, "Used as albedo color" for sampler2D), `hint_normal` ("Used as normalmap") and `repeat[_enable, _disable]` ("Enabled texture repeating") but does not say which repeat setting is the default; the default was therefore measured (it wraps), not quoted.
- The test harness reuses the series Lab's lock and conventions (`../youtube/_godot-shaders-series/lab/`, `BUILDER-BRIEF-COMMON.md`, `MORNING-REPORT.md`); nothing in that folder was edited.
