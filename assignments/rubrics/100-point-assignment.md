# Assignment framework — 100 points

CSYE 7270 · Fall 2026 · One graded assignment every 10 days

**Required viewing:** [AI Policy for Professor Bear's Courses | Using AI Responsibly in Class](https://youtu.be/8Ut0Cdl6vMw?si=9w3aEpt1ZyAR4Kiz). Read the [course AI policy](../../prerequisites/ai-policy.md).

| Component | Points |
|---|---:|
| Assignment-specific implementation and explanation, including the required Brutalist Godot explainer | 60 |
| Frictional — honest log | 10 |
| GitHub version posting matching Canvas | 10 |
| Relative Quartile | 20 |
| **Total** | **100** |

## Implementation and explanation — 60 points

Each assignment supplies the concrete requirements and point breakdown within this category. Implement the requested feature or project change, demonstrate its mechanism, explain its design and behavior, support claims with reproducible evidence, and identify a limitation.

Include the rendered explainer made with the assigned [Brutalist Godot skill](../../prerequisites/brutalist-godot-explainers.md). The video is required evidence and explanation of your work, not a substitute for the implementation. There is no fifth category for producing a video.

## Frictional — 10 points

Provide an honest, traceable account of attempts, expectations, difficulties or checks, responses, learning, and human/AI contributions. Do not fabricate struggle or reward yourself for log length. See [Frictional](../../prerequisites/assessment-policy.md#frictional--honest-log).

## GitHub version posting matching Canvas — 10 points

Post the required source and documentation, identify the submitted revision, and provide accessible, version-matched media links. Canvas and GitHub must identify the same work. See [version posting](../../prerequisites/assessment-policy.md#github-version-posting-matching-canvas).

## Relative Quartile — 20 points

The instructor and TAs review the full comparison group before assigning these points. They compare specificity, substantive improvement, demonstrated understanding, evidence, honesty about verification, usability, and professional communication. Meeting the criterion-based requirements earns those 80 points; it does not guarantee these 20. See [Relative Quartile](../../prerequisites/assessment-policy.md#relative-quartile).

Production polish is considered only as professional communication. It cannot replace a correct implementation or explanation. A plain, precise film outranks a beautiful one that misrepresents the work. Using the required tool earns no automatic relative-score bonus.

## You must be able to explain it

You may use Claude throughout—for the GDD, code, script, beat sheet, and build. Name what it contributed in `SOURCES.md`. You remain responsible for every submitted component and must be able to explain it to the instructor or a TA. Inability to explain reduces points under the relevant criteria; misrepresenting verification is an academic-integrity matter under the course AI policy.

This is the shared grading framework, not a complete assignment brief. A released assignment must also name its task, covered modules, required skill/film coverage, acceptance criteria, deadline, and 60-point task-specific breakdown.
