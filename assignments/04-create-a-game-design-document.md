# Assignment 4 - Create a Game Design Document or GDD

Create a Game Design Document (GDD) either for a game that you like or a game that you think you would like to make in this class.

## Requirements

The GDD must include:

- The Name of the Game
- Concept
- Game Flow
- Game Elements/Assets
- Main Character(s)
- Story
- Gameplay
  - Goal – Why the player is playing your game?
  - Game Mechanics - What actions does the player take?
  - Abilities and power-ups – Further elaborate on the game mechanics.
  - Levels and challenges – List levels.
  - Losing or restarting - What are the losing conditions for the game?
  - Define player skills – What would a good player be good at?
- Graphics and Styling
  - Make it visual with examples.
- Music and Sound Effects
- Technical Description

## Grading

**Total Points: 5**
