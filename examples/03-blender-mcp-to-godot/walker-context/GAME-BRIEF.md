# Game brief

Adapt the existing 3D Platformer as a small, inspectable Walker example. Preserve
its controls, movement, scenes, art and sound initially. First establish what it
actually implements and verify that behavior; do not invent new mechanics for
the film. The teaching loop is Game brief → Build → Playtest → Inspect → Revise
→ Export. Human playtest and enjoyment remain pending.

Deliver two independent native 4K Liam films: a played walkthrough and a
development teardown alternating exact code with actual visible output.
