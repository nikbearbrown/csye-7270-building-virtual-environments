# Assignment grading — 60 / 10 / 10 / 20

CSYE 7270 · Fall 2026 · Instructor-specified proportions

Graded assignments are **due every 10 days and worth 100 points each**. Canvas supplies the actual deadlines; a teaching module is not automatically a separate graded assignment. Each assignment identifies the modules and project work it covers. Ungraded practice assessments do not receive these points.

Every assignment reserves **exactly 20 points for Relative Quartile**. This is part of the 100-point total, not a bonus added afterward. The other 80 points are criterion-based.

| Component | Points |
|---|---:|
| Assignment-specific implementation and explanation, including the required Godot explainer | 60 |
| Frictional — honest log | 10 |
| GitHub version posting matching Canvas | 10 |
| Relative Quartile | 20 |
| **Total** | **100** |

**Every assignment includes an explainer video made with Brutalist's Godot skills.** The assignment specifies the appropriate skill and coverage. Its 60-point rubric evaluates the requested work and how accurately it is demonstrated and explained; video production is not a fifth point category. Rendering a film does not replace implementing the required feature. See [Required Brutalist Godot explainers](brutalist-godot-explainers.md).

The instructor's 25-point example illustrates the same proportions; it is not a separate scheduled assignment or the point value for this course's regular assignments.

## Frictional — honest log

Keep a dated `FRICTIONAL.md` recording what you actually tried, expected, encountered, checked, and learned. State your contribution and the AI's contribution, including what you accepted, modified, rejected, or still do not understand. Connect useful entries to commits, prompt excerpts, outputs, or tests.

An unsuccessful attempt can earn full Frictional credit. More hours, more commits, a longer log, or invented struggle do not earn extra points. If work was straightforward, say so and explain what you checked. Label retrospective entries honestly. AI can help organize notes; it cannot supply a lived experience that did not occur.

## GitHub version posting matching Canvas

Post the required source and documentation to the instructor-designated GitHub location, with access for the instructor and TAs. Include a usable `README.md`, `FRICTIONAL.md`, `SOURCES.md`, and the assignment's required implementation or film source. Provide the repository/folder URL and the submitted commit hash in Canvas, together with the matching required files.

Use meaningful commit messages identifying a change and, when useful, the reason or check performed. Commit count is not evidence of learning by itself. A local-only commit is not a GitHub posting. Later changes must be identified as a new revision, not silently represented as the version already submitted to Canvas.

GitHub holds source and documentation. Video, audio, and files over 25 MB belong in the designated media storage, linked from the README. Identify the submitted media version, for example with a filename and checksum, so replacing a Drive file cannot silently change the evidence for an old source revision. Do not upload credentials, restricted data, or private conversations. Public posting is not permission to redistribute another person's assets.

## Relative Quartile

The instructor and TAs review the **full comparison group** before assigning this component. They compare specificity, substantive improvement, demonstrated understanding, evidence, honesty about verification, usability, and professional communication. These are comparative considerations, not additional point buckets.

Meeting the stated requirements earns the criterion-based points; it does not guarantee the relative points. For each 100-point assignment, the criterion-based subtotal is 80 and the relative allocation is 20.

Production polish is considered only as professional communication. It does not substitute for correctness. A plain video that teaches a concept precisely will outrank a beautiful one that does not. This course requires Brutalist's Godot workflow, but use of that tool earns no automatic comparative bonus. Paid-tool access and animation volume are not comparative grading criteria. A simulation must be labeled as a simulation and cannot replace a required real implementation.

Frictional evaluates honest process evidence; Relative Quartile compares the resulting work. Honest unresolved difficulty can earn full Frictional credit without making a submission top-quartile. Quartile placement alone is not a finding of academic misconduct.

The comparison group and the handling of ties, uneven group sizes, late work, and resubmissions must be communicated before comparative grading. The 20% allocation does not itself define those administrative rules.

## You must be able to explain it

You may use Claude throughout—for a script, beat sheet, code, or build. Name the tool, the portions it contributed, and how you used or modified those contributions in `SOURCES.md`. Credit starting code, assets, other tools, and collaborators as well. Do not claim AI-produced work as entirely your own.

You remain responsible for the submission. The instructor or a TA may ask you to explain any part of the video, beat sheet, code, or build. Being unable to explain your own submission reduces points under the relevant criteria. Misrepresenting what was verified is an academic integrity matter under the course AI policy, not merely a production-quality issue.

Watch [AI Policy for Professor Bear's Courses | Using AI Responsibly in Class](https://youtu.be/8Ut0Cdl6vMw?si=9w3aEpt1ZyAR4Kiz). Read the [CSYE 7270 adaptation](ai-policy.md) and follow the university academic-integrity policy as well.

## Term and late work

The course term is **Fall 2026**. The instructor has specified a **10% daily late-work penalty**, superseding the conflicting 5% daily provision in the supplied syllabus. Relative Quartile remains 20% of the assignment's stated maximum; it is not recalculated as a share of a late-adjusted grade.
