## 二、逐个游戏

### 2.1 Grim Dawn（恐怖黎明）——重点

**装备栏布局（纸娃娃）**
- 槽位：头、肩、胸、手、腿、脚、腰带、项链、戒指×2、勋章（Medal）、圣物（Relic）、主手、副手，共 14 个“装备位”；另有武器切换（第二套主/副手，默认 W 键切换，见 [GD10] 中玩家描述“press w to switch weapons”）。槽位列表来自搜索摘要汇总，官方页 [GD1] 未逐一列出 →「部分未核对」。
- 布局：经典“人形剪影居中、两侧竖排防具、底部武器”的纸娃娃；左侧为头/项链/胸/腿/脚一列，右侧为肩/手/腰/戒指/勋章，武器位于下方（具体位置未核对，依据游戏截图记忆）。
- 除圣物外，每件装备都有 **1 个组件（Component）槽 + 1 个增强（Augment）槽**（搜索摘要汇总，「未核对」细节）。组件用法：右键组件，再左键目标装备，弹出确认框 [GD2]；移除组件需找发明家（Inventor），“物品与组件只能保留其一” [GD2]。

**背包形态**
- 主背包为格子背包 **8×12**（通常描述为 12 列 × 8 行，方向「未核对」）[GD4]。
- 额外背包：最多 **5 个，每个 8×8**，作为背包右侧的分页按钮切换；4 个来自普通难度主线任务（Act1 And Not a Drop to Drink、Act2 Clearing the Way、Act3 Culling the Swarm、Act4 Precious Resources），第 5 个在精英难度重刷其中之一获得 [GD4]。→ 典型的“扩容作为任务奖励”。
- 物品有不同占格（如戒指/项链 1×1，单手武器约 1×3 或 2×3，胸甲 2×3 等），**不能旋转**（尺寸数值「未核对」）。

**仓库与转移**
- 走私者（Smuggler）提供个人仓库 + 账号共享仓库（Shared/Transfer），全世界所有走私者互通 [GD3]；硬核与普通角色的共享仓库隔离 [GD3]。
- 尺寸演变：每页从 **8×16 扩到 10×18**（Ashes of Malmouth 资料片），个人仓库 5 页、共享仓库可买到 5 页（用 Iron Bits）[GD5]。
- v1.3.0（配合 Fangs of Asterkarn，2026 年初）：每页 **+5% 空间**；新增两页专用共享页（组件 / 制作材料）；基础版每角色 +3 个私人页；拥有资料片者转移页达 **10 页**；所有页可自定义标签；背包里新增一个按钮，**在世界任何地方一键把所有组件与材料送进共享页** [GD6][GD7][GD12]。
- 个人与转移仓库带“Auto Sort（自动整理）”与“Auto-Complete（自动合成组件）”按钮，引入于 Build 22（2014-11）[GD9]（搜索摘要，「未核对」正文）。

**物品信息呈现**
- 稀有度颜色 [GD1]：普通 白｜魔法（Magic）黄｜稀有（Rare）绿｜怪物稀有掉落（Monster Infrequent）绿｜史诗（Epic）蓝｜传奇（Legendary）紫｜套装（Set）蓝/紫（按套装档次）。注意 GD 的颜色序列与 Diablo 系不同（黄在绿之下）。
- 词缀：前缀 + 后缀两段，各分魔法/稀有档；“双稀有”（稀有前缀 + 稀有后缀）是高价值标志 [GD1]。Monster Infrequent 有固定基础属性再叠随机词缀 [GD1]。
- 对比：悬停地面或背包物品时自动显示对比；双持时 tooltip 分别列出“(If Equipped)”与“(Off-hand)”两种对比；按住 Ctrl 可查看“不含已镶组件”的武器 DPS 对比 [GD11]。社区反映对比面板列出“生命、伤害”等汇总变化 [GD10]，但切换武器后对比不会实时刷新（bug 反馈）[GD10]。玩家仍普遍以“装上后看技能 tooltip 的伤害数字”做最终判断 [GD11] → 说明**单纯的 DPS 差值不足以支撑构筑型游戏的决策**。
- 角色面板：属性页按“攻击 / 防御 / 抗性”分栏，悬停显示明细（「未核对」细节）。

**整理与快捷操作**
- Shift+左键：背包 ↔ 仓库快速转移 [GD9 搜索摘要]；拖拽为主要交互（「未核对」细节）。
- 仓库 Auto Sort 按钮 [GD9]；v1.3.0 一键收纳材料 [GD6]。
- 拆解：发明家可分解装备（需炸药 Dynamite）、套装转换（Transmute，Forgotten Gods）、改造重洗（Alteration，Fangs of Asterkarn）[GD3]。

**拾取与过滤**
- HUD 生命条左侧有一个戒指图标的小按钮，可循环“全部 / 魔法以上 / 稀有以上 / 仅史诗与传奇”；设置中按 Common / Magic / Rare / Monster Infrequent / Epic / Legendary / Set 分行勾选，且有热键临时覆盖过滤以查看全部物品 [GD8]。**只按稀有度过滤**，无规则编辑器 [GD8]。
- 按住 Alt 显示地面物品名牌（「未核对」）。

**死亡 / 保全**：无物品丢失（软核），无保全容器设计。

### 2.2 Diablo II: Resurrected

- **装备栏**：头、项链、胸、主手、副手、手套、腰带、靴子、戒指×2，共 10 槽；另有武器切换（W，第二套双手位）（「未核对」——依据游戏通识）。
- **背包**：格子 **10×4**；赫拉迪克方块（Horadric Cube）**3×4**，本身占 2×2 但可当扩展收纳 [D2a 及搜索摘要]。物品尺寸差异大（戒指 1×1、护符 1×1~1×3、胸甲 2×3、长柄 2×4），**不可旋转**。
- **仓库**：D2R 个人仓库 **10×10**，另有 3 个共享页（原版 LoD 为 6×8）；后续资料片 Reign of the Warlock 把共享页增至 5 页并提供符文/宝石/材料堆叠页、方块整合进仓库界面 [D2a，及搜索摘要「部分未核对」]。
- **信息呈现**：颜色 白/灰（普通/有孔或无形）｜蓝 魔法｜黄 稀有｜金 暗金（Unique）｜绿 套装｜橙 手工（「未核对」——通识）。D2R 新增按住 **Shift 并排显示已装备物品**，但**不计算差值、不给推荐** [D2b]，可在 UI 设置中关闭提示 [D2b]。
- **快捷**：Ctrl+左键 在仓库/商店/方块与背包间快速转移；Shift+右键 把物品放进方块（「未核对」）。D2R 加入金币自动拾取、共享仓库等便利功能 [D2c]。
- **过滤**：原版与 D2R 均无官方掉落过滤（D2R 仅可开关物品名显示，「未核对」）。
- **保全**：死亡会在尸体上留下装备（软核可捡回），硬核永久死亡。

### 2.3 Diablo IV（以及 D3 的转变）

- **装备栏**：头、胸、手、裤、靴、项链、戒指×2、主手（及按职业的双持/副手/双手）——约 9~11 槽（「未核对」细节，按职业不同）。
- **背包**：**统一格子**，每类页 **11 列×3 行 = 33 格**，所有装备都占 1 格 [D4b]；开发期由 36 格缩为 33 格 [D4c]。背包分页：装备 / 消耗品 / 任务 / 宝石等可插入物（宝石后来被移出装备页，单独存放）（「部分未核对」）。
- **仓库**：每页 **50 格**，起始 1 页，额外页 10 万金币/页 [D4a]；发售时上限 4 页（200 格）[D4b]，后续赛季增至 6 页（「未核对」）。
- **为何改统一格**：D3 起把物品统一为 1×1 / 1×2，D4 进一步统一为 1×1。官方未见明确访谈原文（「未核对」）；可归纳的理由：①手柄/主机首发，统一格适合摇杆逐格导航；②物品数量与掉率大幅提高后，“俄罗斯方块”变成纯摩擦而非决策；③取舍的焦点转移到“词缀价值判断”而非“形状”；④实现与 UI 测试成本更低（社区分析）。
- **信息呈现**：赛季 4「Loot Reborn」重做：词缀条数减少、同类属性合并显示、对比 tooltip 更直观（开发者明确目标是“让玩家一眼判断是否为升级”）[D4e]；**传奇特效 / Greater Affix 用星标**，背包内也有星标图标，掉落有专属音效 [D4d][D4e]。Item Power（物品强度）大数字写在 tooltip 顶部，作为第一眼的粗筛指标；对比时每条属性旁有上/下箭头与差值（「未核对」细节）。
- **快捷**：标记为垃圾（Mark as Junk）、在铁匠处一键分解全部垃圾、一键出售（「未核对」）。
- **保全**：无。

### 2.4 Path of Exile 1 / 2

- **装备栏**：PoE1：头、胸、手、靴、腰、项链、戒指×2、主手、副手、武器切换第二套，加 **5 个药剂槽**（腰带下方横排）——纸娃娃居中、背包在下（「未核对」细节）。PoE2 药剂改为生命/魔力 2 个 + 护符（Charm）槽（「未核对」）。
- **背包**：格子 **12×5（60 格）**，所有玩家固定不可扩 [PoE1 关联页/搜索摘要]。物品尺寸 1×1 到 2×4，**不可旋转**。
- **仓库**：普通页 **12×12（144 格）**，新账号 4 个免费页；Quad 页 **24×24（576 格）**常用作“倾倒页”；专用页：通货（每种 5000 堆叠）、碎片、地图（按阶自动整理）、命运卡、精华、宝石、药剂、独特收藏页等 [PoE1]。**Affinity（亲和）**：Ctrl+点击时按类型自动路由到指定页 [PoE1]；支持文件夹分组 [PoE1]。
- **信息呈现**：普通 白｜魔法 蓝｜稀有 黄｜传奇 橙褐（「未核对」通识）。开启“高级词缀描述”后按住 **Alt**：把词缀拆分为前缀/后缀、显示数值范围与 Tier [PoE4]；Tier 以“全部底材”统计，所以戒指上最高也可能显示为 T5 [PoE4]。PoE 默认不做“装备差值”对比，比较依赖玩家与第三方工具（「未核对」，PoE2 已加入按住 Alt/悬停比较已装备物品）。
- **快捷**：Ctrl+左键 在仓库/商店/背包间转移；Shift+左键 拆分堆叠；Ctrl+Shift+左键 买入整堆；右键通货后按住 Shift 连续使用 [PoE3]；3.24 加入 Ctrl+Shift 点击把背包内同类堆叠全部移入交易窗（搜索摘要）。
- **过滤**：文本过滤器（Show/Hide 块 + 条件：Rarity、BaseType、ItemLevel、Sockets、Corrupted 等；动作：文字/边框/背景色、字号、提示音、小地图图标、光柱 PlayEffect）；被 Hide 的物品完全无提示 [PoE2]。社区网站 FilterBlade 提供图形编辑并同步至账号（「未核对」）。
- **保全**：无（死亡只扣经验）。

### 2.5 Last Epoch

- **装备栏**：头、项链、武器、胸、副手、戒指×2、腰带、手套、靴子、圣物（Relic）[LE2]；另有独立的 **神像（Idol）网格**，神像有 1×1 / 1×2 / 1×3 / 1×4 等形状 [LE4 及搜索摘要]。
- **背包**：格子 **8×12** 存储区（维基描述，方向「未核对」），背包界面自带 **排序按钮** [LE2]。物品有不同尺寸，不可旋转。
- **仓库**：可创建“类别（Category）”分组并命名上色；新版带存入时**自动归类**；全仓库**搜索框** [LE4 及搜索摘要]。
- **信息呈现**：稀有度 普通/魔法/稀有/**Exalted（含 T6–T7 词缀，粉紫色）**/传奇（Unique）/套装/Legendary [LE1][LE3]。词缀阶 T1–T7，**制作最多升到 T5，T6/T7 只能掉落** [LE3 搜索摘要]，tooltip 每条词缀旁显示阶级标记（「未核对」样式）。
- **锻造 UI**：物品放入锻造台，显示 **Forging Potential（锻造潜能）**，每次操作随机消耗一个范围内的潜能（如 1–14），高阶操作消耗更多 [LE3 搜索摘要]。透明的“剩余次数资源”是 LE 制作 UI 的核心。
- **过滤**：**游戏内图形化规则编辑器**，每个过滤器最多 **75 条规则**，规则可拖拽排序、上方优先；动作 Show/Hide/Recolor（改名牌颜色）/Emphasize（放大名牌）；条件：词缀（可限定单词缀阶与总阶数，最高 28）、职业需求、等级、稀有度、物品类型；可随角色等级生效；可导出 XML 或剪贴板分享 [LE1]。
- **保全**：无。

### 2.6 Escape from Tarkov（及 Dark and Darker）

- **装备栏（装备位）**：头盔、耳机、面罩、眼镜、护甲、胸挂（Rig）、背包、主武器×2、手枪、近战、袖标、口袋（4 个 1×1）、安全箱（「未核对」通识）。核心是**容器即装备**：胸挂、背包本身有内部网格，容量随装备而变。
- **背包**：网格 + **旋转**：拖动物品时按 **R** 旋转 90°，仅在旋转后能放下时生效 [EFT5]。**嵌套容器**：弹药盒、医疗箱、物品箱（Item case）等可放进背包，形成“容器套容器”，内部空间常大于外部占格（「未核对」细节）。
- **未知物品 / 检视**：新物品在被检视前显示为灰色问号；**中键**快速检视 [EFT5 搜索摘要] → 拾取后还需一步“认识”，强化搜刮节奏。
- **仓库**：按版本 **10×30（标准）/ 10×40 / 10×50 / 10×68（EoD）**，可在藏身处升级至 10×68 [EFT6 搜索摘要]（旧资料曾写 10×28，以当前为准）。
- **安全箱（Secure container）**：死亡不丢。Alpha **2×2**、Beta **3×2**、Epsilon **4×2**、Gamma **3×3**、Kappa **4×3**，按版本或任务解锁 [EFT1][EFT2]。只能放入白名单物品类型（「未核对」细节）。
- **保险**：Prapor 12–20 小时、Therapist 6–10 小时返还，需在限期内（7 天 / 10 天）领取；死亡后**未被他人拾取**的投保物品才返还 [EFT3]。**已投保物品在仓库与局内都有黄色边框 + 盾牌图标** [EFT3]。
- **Found in Raid（FIR）**：图标角上的小勾 + tooltip“Item found in raid”；只有“Survived”撤离才保留 FIR，死亡时连安全箱里的物品也会失去 FIR；很多任务要求 FIR 物品 [EFT4]。→ 一个“状态标记”就把“这件东西是怎么来的”可视化。
- **Dark and Darker**：格子背包但**不可旋转**，玩家长期要求加入旋转；仓库空间受限且缺少扩展途径（玩家反馈）[DaD1]。说明“搜打撤 + 格子”并不一定要旋转，但容量稀缺时玩家会强烈要求。

### 2.7 简述：Torchlight: Infinite / Lost Ark / Titan Quest

- **Torchlight: Infinite（火炬之光：无限）**：移动端同源，背包为**统一格 + 分页**（装备 / 技能 / 商品材料 / 其他），装备页与材料页扩容为全角色全赛季共享，背包内有一键排序 [TLI1 及搜索摘要]。装备栏为左右两列围绕人物（「未核对」细节）。适合手柄/触屏的统一格范式。
- **Lost Ark**：6 件主装备（武器、头、胸、肩、裤、手）+ 饰品；**角色物品等级 = 6 件装备等级的平均值**，作为全局强度单值 [LA1 搜索摘要]；角色页左装备右属性面板，背包为统一格、带排序和一键分解（「未核对」细节）。
- **Titan Quest（Anniversary Edition）**：主背包 + 3 个额外背包（与 NPC 对话获得），原版背包总计 180 格（含背包）；车夫（Caravan Driver）仓库有个人区和较小的“转移区”；右键物品可快速存入仓库 [TQ1 及搜索摘要]。Grim Dawn 由同一团队（Crate，原 Iron Lore 成员）制作，“额外背包分页 + 共享转移仓”的结构即继承于此。

## 四、设计规律总结

1. **为什么格子背包仍在刷宝/搜打撤游戏里流行**
   - 把“背包容量”变成一种**空间决策**：大件 = 高成本，玩家需要在“带一件大甲 vs 三个小饰品”间取舍（Tarkov、D2）。
   - 在**撤离游戏**里，格子容量直接决定“这一局能带走多少价值”，是风险/收益天平的一端；安全箱的价值也完全依赖格子（Tarkov 2×2 → 4×3 是长线目标）[EFT1]。
   - 鼠标优先的 PC 游戏，拖拽放置天然顺手；物品图标尺寸差异也让视觉更有“实物感”。
   - 扩容可以作为进度奖励（GD 任务背包 [GD4]、Tarkov 藏身处升级 [EFT6]）。

2. **什么时候改成统一格**
   - 物品数量极大、单件价值低时，形状不再提供有意义的决策，只剩摩擦（D3/D4、TLI）。
   - 手柄 / 移动端首发：统一格适合逐格导航。
   - 以“数值筛选”为核心乐趣、而非“搜刮装包”时。
   - **Downfall 是“撤离 + 局内搜刮”，物品总量远小于 D4**，格子背包与安全袋形成闭环，建议**保留格子**。

3. **Tooltip 信息层级的常见做法**（自上而下）
   1) 名称（稀有度着色）+ 类别/底材；2) 单值强度（D4 Item Power、Lost Ark 物品等级）；3) 基础属性（伤害/护甲）；4) 词缀（前缀→后缀，或按阶排序；高阶用星标/特殊色）；5) 特效/套装；6) 需求与来源标记（FIR、投保）；7) 操作提示（右键装备 / Shift 对比）。
   - **按住修饰键展开详细层**：PoE Alt 显示阶与范围 [PoE4]、GD Ctrl 显示无组件 DPS [GD11]、D2R Shift 并排 [D2b]。默认简洁、按需深入。

4. **对比显示的常见做法**
   - A. **并排双 tooltip**（D2R、GD）：最便宜，但玩家要自己算。
   - B. **逐项差值 + 绿/红箭头**（D4）：最直观；D4 S4 专门为“一眼看出是否升级”做了属性合并 [D4e]。
   - C. **汇总差值**（GD “If Equipped” 的生命/伤害变化 [GD10]）：适合属性少的游戏。
   - 坑：对比要随装备切换实时刷新 [GD10]；多槽位（双戒指、双持）要对每个可能替换位都给出对比 [GD11]。

5. **快捷键约定（事实标准）**
   - **Ctrl+左键**：在当前打开的两个容器之间快速转移（PoE、D2）[PoE3]；GD 用 **Shift+左键** [GD9]。
   - **右键**：装备/使用；**Shift+左键**：拆分堆叠（PoE）[PoE3]。
   - **Alt**：显示地面物品名牌 / 详细词缀 [PoE4]。
   - **R（拖拽中）**：旋转（Tarkov）[EFT5]。
   - 一键“全部存入材料/整理”按钮（GD v1.3 [GD6]、LE、TLI）。

6. **保全与状态标记**：搜打撤游戏用**容器（安全箱）+ 物品状态标记（投保盾牌、FIR 勾）**两层来表达“死了会怎样”。标记必须在**背包、仓库、局内 HUD** 三处一致可见 [EFT3][EFT4]。

## 五、对 Downfall 的具体建议

> 按优先级排序；成本：小（≤1 天）/ 中（2–4 天）/ 大（≥1 周），以 Godot 单人开发估算。

**P0（立刻能显著提升体验）**

1. **悬停 tooltip + 装备对比差值**
   - 做什么：鼠标悬停（或键盘选中）背包物品即弹出 tooltip；同槽位已装备时并排显示，并在新物品下方列出“装备后变化”：ATK +12（绿）、HP −30（红）、法术攻击 ±0（灰）。只有 3 个槽位，每件只对比 1 件，实现简单。
   - 为什么：D4 S4 以“一眼判断升级”为目标重做对比 [D4e]；GD 的“If Equipped”汇总 [GD10]；D2R 仅并排、不算差值，被视为过于简陋 [D2b]。
   - 成本：中。

2. **稀有度边框 + 名称颜色 + 格子底色**
   - 做什么：普通 灰白、精良 蓝/绿、稀有 金/紫（建议与明日方舟星级色系对齐：3★ 蓝、4★ 紫、5★ 金）；格子用 2px 边框 + 淡底色，Tooltip 标题同色。
   - 为什么：所有调研游戏都以颜色作为第一层信息 [GD1][PoE2]；LE 的 Exalted 用专色标出高阶词缀物品 [LE3]。
   - 成本：小。

3. **点金 / 保险 / 安全袋 的统一状态标记**
   - 做什么：保险 = 格子左上角盾牌角标 + 黄色描边（直接借 Tarkov 惯例）[EFT3]；点金 = 右上角金色小锭 + 缓慢流光；在安全袋内的物品 = 锁形角标。Tooltip 底部用一行文字说明“死亡时：保留 / 返还 / 丢失”。
   - 为什么：Tarkov 的投保盾牌与 FIR 勾证明“状态标记”能让风险一眼可读 [EFT3][EFT4]；三种保全方式并存时更需要视觉区分。
   - 成本：小。

4. **拖拽放置（保留现有点击-按钮作为后备）**
   - 做什么：左键按住拖动；悬停在目标格时显示绿色（可放）/红色（冲突）落点预览；拖到装备槽 = 装备，拖到安全袋 = 移入，拖出面板 = 丢弃（弹确认）。手柄/键盘仍可用“选中 + 按钮”。
   - 为什么：GD、PoE、Tarkov、D2 均以拖拽为基础交互；格子背包没有拖拽会让空间决策变成菜单操作。
   - 成本：中（Godot 有 `_get_drag_data / _can_drop_data / _drop_data`）。

5. **快捷键约定**
   - 做什么：右键 = 装备/卸下；**Ctrl+左键 = 背包 ↔ 安全袋**（安全袋满则提示）；仓库打开时 Ctrl+左键 = 背包 ↔ 仓库；Shift+悬停 = 强制显示对比；Alt（按住）= 显示词缀数值范围；Del/X = 丢弃（二次确认）。
   - 为什么：Ctrl+点击转移是 PoE/D2 的事实标准 [PoE3]，GD 用 Shift [GD9]；PoE 用 Alt 展开词缀细节 [PoE4]。
   - 成本：小。

**P1（显著减负、强化撤离闭环）**

6. **自动整理按钮（背包与仓库）**
   - 做什么：一键按“类别 → 稀有度 → 尺寸”重新装箱（简单的首次适应递减算法即可）；安全袋不参与整理。
   - 为什么：LE 背包排序按钮 [LE2]、GD 仓库 Auto Sort [GD9]、TLI 一键排序 [TLI1]。
   - 成本：小–中。

7. **词缀展示规范**
   - 做什么：Tooltip 内按“基础属性 → 随机词缀 → 剑气触发词缀（特殊色 + 图标，单独分隔线）”排序；每条词缀后标阶（如 Ⅰ/Ⅱ/Ⅲ 或小点数），按住 Alt 显示数值范围。
   - 为什么：PoE 高级词缀描述 [PoE4]、LE 词缀阶 [LE3]、D4 星标 Greater Affix [D4d]；把“触发类”与“数值类”分开有助于识别构筑核心。
   - 成本：小。

8. **局内背包不完全暂停：改为“减速 / 安全时暂停”二选一的设置**（设计取舍）
   - 做什么：保留当前暂停作为默认（单人游戏），但在撤离合约中可考虑“开背包时时间流速 ×0.3”或“附近有敌人时禁止开背包”，让整理背包本身成为风险。
   - 为什么：Tarkov 与 Dark and Darker 的局内整理都在实时中进行，背包管理即紧张感来源；GD/PoE 这类非撤离游戏则不在乎。需要策划拍板。
   - 成本：小（实现）/ 需玩法决策。

9. **撤离结算前的“价值预览”**
   - 做什么：背包顶部显示“已携带价值 / 安全袋价值 / 点金保底价值 / 投保价值”四个数字；死亡预演 tooltip：“若此刻死亡，你将保留：……”。
   - 为什么：Tarkov 依赖玩家心算风险，新手门槛高 [EFT3][EFT4]；把撤离规则可视化是对其的改进。
   - 成本：中。

10. **拾取过滤（简版）**
    - 做什么：先做 GD 式“按稀有度阈值”的循环按钮（全部 / 精良以上 / 仅稀有），以及按住 Alt 显示地面物品名牌；后期再考虑 LE 式规则编辑器。
    - 为什么：GD 只按稀有度过滤也已满足多数玩家 [GD8]；LE 的 75 条规则编辑器 [LE1] 和 PoE 文本过滤器 [PoE2] 对我们体量过重。
    - 成本：小（简版）/ 大（规则编辑器）。

11. **背包扩容作为进度奖励**
    - 做什么：初始 10×6 可考虑缩为 8×5，通过基地设施升级扩至 10×6、10×8；安全袋 2×2 → 3×2 → 3×3 由合约/基地解锁。
    - 为什么：GD 任务奖励背包 [GD4]、Tarkov 安全箱 Alpha→Kappa 成长线 [EFT1]、藏身处扩仓 [EFT6]。
    - 成本：小（数据）/ 需与基地玩法规范对齐。

**P2（锦上添花 / 视需求）**

12. **旋转：暂不加，或仅对 1×N 长条物品开放**
    - 做什么：先不做旋转；若物品尺寸种类增多（出现 1×3、2×3 等长条），再加“拖拽中按 R 旋转 90°”。
    - 为什么：Tarkov 有旋转 [EFT5]，但 GD/PoE/D2/Dark and Darker 都没有 [DaD1]；我们只有 3 类装备 + 少量材料，旋转收益小、会增加存档/碰撞逻辑。
    - 成本：中。

13. **仓库：分类页 + 搜索 + “一键存入材料”**
    - 做什么：基地仓库保留货架分类，额外加搜索框与“全部材料存入”按钮；从撤离结算界面直接“全部入库”。
    - 为什么：GD v1.3 一键送材料入共享页 [GD6]、PoE Affinity 自动路由 [PoE1]、LE 自动归类 [LE4]。
    - 成本：中。

14. **装备单值强度**
    - 做什么：在 Tooltip 顶部和角色属性面板展示“战力”（power 已存在），对比时首行给出战力差值，下面再列分项。
    - 为什么：D4 Item Power、Lost Ark 平均物品等级 [LA1] 作为第一眼的粗筛；GD 的经验表明单值不能替代细项 [GD11]，所以两层都要。
    - 成本：小。
