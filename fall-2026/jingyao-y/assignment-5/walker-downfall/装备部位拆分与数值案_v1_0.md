# 装备部位拆分与数值案 v1.0

2026-10-21。用户：改成 8 装备槽纸娃娃，重新设计装备的数值。

槽位已经定了（`界面美术与布局策划案_v2_0.md` §4.1）：**武器、头、胸、手、腿、脚、项链、戒指**，没有护肩、腰带、副手和第二枚戒指。
本案只管装备系统和数值；界面排法沿用 v2 §4.1。
数值规则沿用 `复利数值改造清单.md`：每 10 层一档、白蓝金三段波动、固定值词条每档 ×1.30、K = 600。

## 一、现状

| 项 | 现在 |
|---|---|
| 槽位 | 武器、防具、饰品 3 个 |
| 底材 | 145 个：武器 74、防具 33、饰品 38（含罗德岛制式 9） |
| 面板 | 武器每点效能给主属性 220；防具给生命 1300、防御 80；饰品给攻击 / 法术合计 110 |
| 词条 | 白 0 条、蓝 1 条、金 2 条；数值按稀有度三段波动 |
| 前缀 | 每件 1 条，有概率 2 条 |
| 掉落 | 每个敌人最多掉 1 件装备，武器 : 防具 : 饰品 = 6 : 1 : 1 |
| 套装 | 6 套，每套 3 件 |
| Boss 装备 | 每个 Boss 9 件 |

## 二、总原则

1. **总预算不变，摊到 8 件上**。一身同层装备给的面板总量，和现在 3 件给的一样。复利数值改造的校准（几刀打死、一击掉多少血）因此不用重做。
2. **单件更保守**。每件只占一部分预算，刷到一件好的，不会一下子变强很多。
3. **每个部位有自己的倾向**。面板一样都是防御或输出，但词条池偏向不同的属性，配装才有取舍。
4. **词条总量和现在持平**（用户 2026-10-21）。8 件 × 每件的词条条数，是现在的约 2.7 倍，所以单条词条要缩小，使一身装备的词条总量与现在 3 件相同。

## 三、面板

| 部位 | 面板 | 份额 | 每点效能 | 背包占格 |
|---|---|---|---|---|
| 武器 | 主属性（攻击或法术） | 100% | 220 | 2×1（不变） |
| 胸 | 生命、防御 | 32% | 生命 416、防御 25.6 | 2×3 |
| 腿 | 生命、防御 | 22% | 生命 286、防御 17.6 | 2×2 |
| 头 | 生命、防御 | 18% | 生命 234、防御 14.4 | 2×2 |
| 手 | 生命、防御 | 14% | 生命 182、防御 11.2 | 2×2 |
| 脚 | 生命、防御 | 14% | 生命 182、防御 11.2 | 2×2 |
| 项链 | 攻击 / 法术（按件随机比例） | 60% | 合计 66 | 1×1 |
| 戒指 | 攻击 / 法术（按件随机比例） | 40% | 合计 44 | 1×1 |

- 五件防具合计正好是现在一件防具的 100%，项链和戒指合计是现在一件饰品的 100%。
- 饰品的体力回复照这个份额分到项链和戒指。
- 背包：一身装备从 2 + 4 + 1 = 7 格，变成 2 + 6 + 4 × 4 + 1 + 1 = 26 格。最大背包 12×8 = 96 格，带一身备用装备会占掉四分之一，这正好是"背包取舍"的压力。如果嫌挤，可以把腿、手、脚改成 2×1 或 1×2。

## 四、词条

**条数**：不变，白 0 条、蓝 1 条、金 2 条。

**单条数值 × 部位系数**：

| 部位 | 系数 | 理由 |
|---|---|---|
| 武器 | 1.00 | 不变，输出的主来源 |
| 胸 | 0.37 | 大件 |
| 项链 | 0.33 | 大件饰品 |
| 腿 | 0.30 | |
| 头 | 0.26 | |
| 手 | 0.26 | |
| 戒指 | 0.26 | |
| 脚 | 0.22 | |

除武器外，七个部位的系数合计 2.00，正好顶替现在防具和饰品两件的 1 + 1；加上武器的 1.00，一身合计 3.00，与现在持平。

**词条池（部位倾向）**：标 ★ 的是新增的词条种类。

| 部位 | 词条池 |
|---|---|
| 武器 | 攻击 %、攻击 +、法术 +、攻速、暴击、暴伤 |
| 胸 | 生命 %、生命 +、防御 +、法抗 |
| 腿 | 生命 %、防御 +、★闪避 |
| 头 | 法抗、法术 %、★技能冷却 |
| 手 | 攻速、暴击、攻击 % |
| 脚 | 移速、★体力回复 %、★闪避体力消耗 |
| 项链 | ★技能伤害、法术 %、攻击 %、生命 + |
| 戒指 | 攻击 +、法术 +、暴击、暴伤 |

- 新增的五种词条（闪避、技能冷却、技能伤害、体力回复 %、闪避消耗）都对应角色属性表里已有的键，不用新造属性。
- 固定值词条（攻击 +、法术 +、生命 +、防御 +）同样 × 部位系数，再按每档 ×1.30 成长。

## 五、前缀

- 现有 150 条前缀按"武器 / 防具 / 饰品"分类：防具前缀能出在五个防具部位上，饰品前缀能出在项链和戒指上。
- **纯属性前缀**（例如"攻击 +7%"）的数值 × 部位系数，同上表。
- **带特效的前缀**（例如击杀回血、条件触发类）不缩小，但只出在武器、胸、项链这三个"大件"上。缩小以后特效会变得没有感觉，所以改成限制出现的部位，避免一身叠 8 个特效。
- 双前缀的概率不变。

## 六、掉落

- **部位权重**：武器 3，胸 1，腿 1，头 1，手 1，脚 1，项链 0.6，戒指 0.6。
  - 武器占 33%，原来是 75%。
  - 每个防具部位约 11%，和原来"防具"整体的 12.5% 差不多，所以每个防具部位的换装节奏和原来的防具相同。
- **总掉率不变**（用户 2026-10-21）。原来凑一身只要 3 件，现在要 8 件，按件数算凑齐一身大约是原来的 2.7 倍时间。初期会有空槽，这时罗德岛制式装（8 件）兜底。
- 每个敌人"最多掉 1 件装备"这条不变。

| 部位 | 可从现有底材归过去的 | 缺口（每个地区按 4 个底材算，矿区、城市、雪原三个地区） |

| 手 | 军用止血带、纠察队手铐（共 2，勉强） | 约 10 个 |

- 不像首饰的饰品（扁壶、对讲机、钱夹、打火机这类）：照旧放进项链池，名字和描述不用改，按"随身物"理解。

## 八、套装与 Boss 装备

- **套装**：6 套、每套 3 件，各件改指定部位，比如"武器 + 胸 + 项链"或"头 + 手 + 脚"，套装效果不变。套装效果里的固定防御 +40，改为按套装件的档位和部位系数成长。
- **Boss 装备**：每个 Boss 9 件，改为覆盖 8 个部位、外加 1 件武器。
- **特殊装备**：照旧占用普通部位的槽，各自标明部位。

## 九、其他

- **装备需求**：按部位分列。胸和腿沿用"重型"列；头、手、脚用"轻型"列；项链和戒指用"饰品"列；武器不变。
- **整备台**（重铸、校准、精调）：规则不变，作用在单件上。
- **投保**：按件计价。8 件价值合计和原来 3 件差不多，因为装备价值另有算法，不跟效能走。
- **旧存档**（用户 2026-10-21：改成修改后对应的数值）：旧防具变成胸甲，旧饰品变成项链，面板、词条和前缀都按新部位的份额和系数缩小，与新掉的同部位装备一致。
