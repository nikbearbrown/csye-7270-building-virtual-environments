## 0. 现状与本案定位

| 已有 | 内容 | 位置 |
|---|---|---|
| 品质 | 普通 / 精良 / 稀有，给 0 / 1 / 2 条**随机词缀**（无名字的属性行），档位 Ⅰ/Ⅱ/Ⅲ | `LootTables.roll_equipment`、`FieldCatalog.AFFIX_POOLS` |
| 固有词条 | 底材自带，`tier = -2`，不占词缀条数 | `GearCatalog.apply` |
| 剑气强化 | 武器精良以上 25% 概率，占一条词缀 | 同上（本案 §6 改为"技能强化"） |
| 特殊 / 专属 / 套装 | 固定效果，独立身份 | `SpecialGear`、装备扩充策划案 |

**缺的是"名字"**：现在同一底材的两把刀只差几行数字，看名字分不出好坏。本案加一层**前缀**：有名字的属性包，写进物品名（"破损的断镐战斧"），可正可负，像泰拉瑞亚那样一眼看出好坏。

本案不改品质、固有词条、随机词缀的规则，前缀是叠在上面的第四层。

## 2. 规则

### 2.1 名字与颜色

```
单前缀：前缀的 · 底材名            例：致命的·断镐战斧
双前缀：前缀的 · 前缀的 · 底材名    例：致命的·狂暴的·断镐战斧
属性  = 基础效能 + 固有词条 + 前缀 + 随机词缀
```

- 双前缀时档位高的在前，同档按抽到的先后。
- 前缀字数 ≤3（不含"的"）。名字最长 4+1+4+1+底材 5 = 15 字。
- 单前缀也用"·"，与双前缀统一，也方便分段上色。
- **颜色**：物品颜色（格子边框、底材名、地面掉落）照旧跟品质，前缀不改它。每个前缀（含它的"的"）用自己档位的颜色，"·"用暗灰：

| 档位 | 颜色 | 色值 |
|---|---|---|
| −2 | 灰 | `#7d858c`（比普通品质的 `#c9d3db` 暗） |
| −1 | 白 | `#eef1f3` |
| 0 | 绿 | `#6fcf7f` |
| +1 | 蓝 | `#5aa9ff` |
| +2 | 黄 | `#f3b04a` |

- 提示栏：前缀的属性行放在固有词条下、随机词缀上，格式"前缀 · 攻击力 +6%"，"前缀"二字用该前缀的颜色。双前缀分两组列出。不写档位、不写说明。

### 2.2 档位

| 档位 | 预算（单位见 §2.4） | 出现率 |
|---|---|---|
| −2 | ≤ −1.3 | 15% |
| −1 | −1.3 ~ −0.6 | 20% |
| 0（交换） | −0.3 ~ 0.6 | 30% |
| +1 | 0.6 ~ 1.3 | 30% |
| +2 | ≥ 1.3 | 5% |

三个槽位都出 −2 ~ +2。一共五档，没有单独的极品档；v1.0 的四个极品前缀（传奇的、王庭的、不朽的、完美的，预算 ≥2.2）并入 +2，表里标作 **+2 顶级**。

### 2.3 掉落

| 项 | 规则 |
|---|---|
| 哪些装备 | 所有普通底材、特殊装备、专属装备、罗德岛制式装备（整备时抽）；**套装不出** |
| 必带 | 每件至少一个前缀，与品质无关 |
| 档位 | 按 §2.2 出现率抽档位，再在该档合格前缀里抽 |
| 档位内权重 | 每个前缀权重 1；地区前缀在本地区 ×3（其他地区 ×1，不降） |
| +2 顶级 | 在 +2 档里，每个顶级前缀权重 0.25；第 3 区段前不进池 |
| 双前缀 | 整体 20%，不分品质；第二个前缀独立再抽，档位概率与第一个相同（15/20/30/30/5） |
| 双前缀限制 | 不能同名；至多一个顶级前缀；至多一个地区前缀；同组互斥（§2.6） |
| 商店 | 坎诺特、可露希尔卖的装备照常带前缀 |

### 2.4 预算单位

1 单位 = 一条Ⅱ档随机词缀。只用于设计时对齐强度，**游戏里不显示**（用户：不要战力概念）。

| 属性 | 1 单位 | | 属性 | 1 单位 |
|---|---|---|---|---|
| 攻击力 | +8% | | 攻击无视防御（破甲） | 10% |
| 攻速 | +10 | | 吸血 | 3% |
| 暴击率 | +5% | | 物理闪避 | 5% |
| 暴击伤害 | +20% | | 对精英伤害 | +12% |
| 移速 | +8% | | **技能伤害（新）** | +25% |
| 生命上限 | +8% | | **技能冷却（新）** | −12% |
| 防御 | +40 | | 闪避冷却 | −12% |
| 法抗 | +8 | | 体力回复 | +15% |
| 法术攻击力 | +10% | | 受到治疗 | +15% |
| **攻击范围（新）** | +10% | | 赤金获取 | +15% |
| 受到伤害（代价） | +5% = −1 | | 威胁累积 | −15% |
| | | | 污染累积 | −20% |
| **法术闪避** | 5% | | **近战闪避（新）** | 6% |
| **远程闪避（新）** | 8% | | **整体减伤（新）** | 6% |

近战闪避覆盖大多数敌人，所以比物理闪避便宜一点；远程敌人少，远程闪避更便宜。整体减伤 6% 约等于生命 +8% 的有效生命。

### 2.5 价值与重铸

- 价值 × (1 + 0.25 × 前缀档位之和)，顶级前缀按 +4 计，最低 ×0.3。双前缀两个档位相加。坎诺特 / 可露希尔收购按此计。
- **重铸只在基地**：工坊花龙门币（= 物品价值 × 1/3 换算），整组前缀按 §2.3 重新抽（含双前缀概率、含原来的前缀）；必带，不能去掉；不动品质和随机词缀。
- 局内（营地、坎诺特、可露希尔）不能重铸。
- 投保 / 送回的装备保留前缀和全部数值。
- 数值的刷新（校准 / 精调）见 §2.8，同样只在基地。

### 2.6 互斥组（双前缀用）

| 组 | 成员 |
|---|---|
| 价值 | 走私的、仿制的 |
| 攻击范围 | 所有形制前缀、传奇的 |
| 污染 | 源石化的、活性的、抑制的、污损的 |
| 威胁 | 潜伏的、信使的 |
| 每层随机 | 诡意的（不与任何前缀同出） |

### 2.7 闪避与减伤（§0.3）

| 属性 | 键 | 对什么生效 |
|---|---|---|
| 物理闪避 | `evasion`（已有） | 物理伤害 |
| 法术闪避 | `evasion_arts`（已有） | 法术伤害 |
| 近战闪避 | `evasion_melee`（新） | 近战敌人的攻击，不论物理法术 |
| 远程闪避 | `evasion_ranged`（新） | 远程敌人的攻击，不论物理法术 |
| 整体减伤 | `dmg_reduce`（新） | 所有受到的伤害 |

- **一次攻击的闪避率** = 伤害类型闪避（物理或法术）+ 攻击方式闪避（近战或远程），相加后上限 60%（雪牝的护手生效时 75%，同现有上限）。例：物理闪避 10% + 近战闪避 8%，被近战杂兵打时 18%。
- **近战 / 远程**按攻击者分：保持距离的敌人（射弹、抛投、地面法术，`Enemy.keeps_distance`）算远程，其余算近战。现有 `Enemy.ranged` 只包括射弹，墙眼仍按它算，本案不改。
- 没有攻击者的伤害（地面危害、原矿失血）只吃伤害类型闪避；真实伤害不能闪避。
- **整体减伤**在防御 / 法抗之后结算，和防暴盾的 25%、墙眼的远程减伤相加，共同上限 80%（`CombatStats.REDUCTION_CAP`）。负值（代价）按受到伤害增加算。
- 闪避负值没有意义（下限 0），所以闪避类前缀没有负面档；负面用整体减伤。

### 2.8 数值上下限与刷新（§0.4）

本案和以前各表里写的数值都是**中值**。实际掉落时，每一行各自在范围内均匀抽一个数。

| 数值 | 范围（相对中值） | 说明 |
|---|---|---|
| 基础效能（武器攻击力、防具生命和防御、饰品法攻） | 90% ~ 110% | 取代现在的 `1 + 深度×0.3 + randf()`：中值改为 `1.5 + 深度×0.3`，再乘底材系数和品质 |
| 固有词条 | 80% ~ 120% | 原为固定值 |
| 前缀的每一行 | 80% ~ 120% | 双行、三行前缀每行各抽，互不相关 |
| 随机词缀 Ⅰ / Ⅱ / Ⅲ | 60~80% / 90~110% / 120~140% | 原为固定 70% / 100% / 130%，平均值不变 |
| 技能强化 | 80% ~ 120%（20% ~ 30%） | 原为固定 25% |
| 特殊装备的代价、专属与套装效果 | 不波动 | 固定身份 |

- 代价行（负值）同样按 80% ~ 120% 波动；对玩家来说，代价小算好。
- 档位只看前缀本身，不随抽到的数改变。
- 取整：攻速、防御、法抗取整数；百分比 ≥10 取整数，<10 保留一位小数（例：暴击率 +2.7%）。
- 提示栏：平时只显示抽到的值；按住 Alt 显示范围，沿用现有 `describe_detailed` 的写法"（范围 a ~ b）"。不写说明。
- 价值随数值浮动：价值 × (0.8 + 0.4 × 全部数值行的平均位置)，位置 0 = 下限、1 = 上限，乘在 §2.5 的档位倍率上。

**刷新**（只在基地工坊，和重铸并列三项）：

| 操作 | 效果 | 花费（待调） |
|---|---|---|
| 重铸 | 整组前缀重抽（含数值），§2.5 | 龙门币 |
| 校准 | 这件装备**所有数值行**在各自范围内重抽，种类、档位、前缀都不变 | 龙门币 + 研磨石 ×1 |
| 精调 | 只重抽**指定的一行**，其他不动 | 龙门币 + 改量装置 ×1；同一件每精调一次，下次龙门币 +50% |

- 三项都不能把数值刷出范围，也不改品质。
- 旧存档：已有的固定值都落在新范围中间，原样保留；补抽的前缀按本节抽数值。

## 4. 明日方舟特色前缀

原则：
- 名字取泰拉的国家、势力、源石与天灾概念；**不用干员名、不用集成战略藏品名**（"叙拉古""锈蚀"等已被藏品用，避开）。
- 多数是**交换型或条件型**，名字就是流派标签。
- 地区前缀在本地区权重 ×3。矿 = 切尔诺伯格（乌萨斯 / 整合运动），城 = 龙门（炎国），雪 = 萨米（谢拉格）。
- 不带自身伤害（燃烧、爆裂等属于特殊装备）。条件效果只改属性。

## 6. 技能类词条（§0.1-2）

剑气是拉普兰德的技能，阿米娅没有剑气（她的技能是绝影），所以"剑气伤害"类词条对阿米娅是废条。改为两个通用技能属性，按干员落到各自技能上：

| 新属性键 | 名称 | 拉普兰德 | 阿米娅 | 上限 |
|---|---|---|---|---|
| `skill_pct` | 技能伤害 | 剑气伤害（与现有 `wave_pct` 相加） | 绝影每一刀与终结的伤害 | — |
| `skill_cd_pct` | 技能冷却 | 每次命中积累的剑气充能 ÷ (1 − 值) | 绝影冷却 × (1 − 值) | 50% |

改动的词条：

| 词条 | v1.0 | v1.1 |
|---|---|---|

## 8. 和现有系统的关系

- **随机词缀不变**：前缀是名字 + 属性包，随机词缀仍是无名属性行。同属性叠加。
- **固有词条不变**。
- **特殊装备**：带前缀；它的攻击效果和代价不变。前缀无自带伤害。
- **专属装备**：带前缀，品质仍固定稀有。
- **套装**：不带前缀。
- **藏品**：前缀不复用藏品名；单个前缀 ≤ 2.8 单位，双前缀理论最高（两个都是 +2，其一为顶级）约 4.7 单位，极少出现。
