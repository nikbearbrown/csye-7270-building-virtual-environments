# 部位词条数值表 v1.0

2026-10-21。用户：不再用部位系数打折，每个部位直接写自己的词条数值。接 `装备部位拆分与数值案_v1_0.md` §四，并取代那里的"单条数值 × 部位系数"。固有属性见 `底材固有属性表_v1_0.md`。

## 一、规则

1. **每个部位一张数值表**，表里写的就是玩家看到的数（蓝色中值，第Ⅰ档）。金色是 120–140%。固定值（攻击 +、法术 +、生命 +、防御 +）每档 ×1.30。
2. **属性分两类**：
   - **战斗属性**：攻击、法术、攻速、暴击、暴伤、技能伤害、技能冷却、生命、防御、法抗、闪避。这一类决定几刀打死、一击掉多少血，所以总量要守住。一身装备的期望总量和现在一样：武器 2 条满额，其余七件合计 4 条满额。
   - **功能属性**：移速、体力回复、闪避体力消耗。这一类不进战斗预算，按手感定。
3. **鞋两类都出**（用户 2026-10-21）：功能属性按手感给足；战斗属性（防御 +、生命 +）照鞋的预算 0.22 给。
4. **同一部位内，招牌属性更大**：只在这个部位出的属性（腿的闪避、头的技能冷却、项链的技能伤害）比共享属性大；部位的平均值不变。

## 二、数值表

"满额"指原来一条词条的大小（`AFFIX_AMOUNTS`）。

| 部位 | 词条（蓝色中值，第Ⅰ档） | 战斗属性平均占满额 |
|---|---|---|
| 武器 | 攻击 +8%、攻击 +95、法术 +95、攻速 +10%、暴击 +5%、暴伤 +20%（不变） | 1.00 |
| 胸 | 生命 +3.2%、生命 +156、防御 +16、法抗 +2.2 | 0.37 |
| 项链 | **技能伤害 +11%**、法术 +2.7%、攻击 +2.2%、生命 +129 | 0.33 |
| 腿 | 生命 +2.1%、防御 +10、**闪避 +3%** | 0.30 |
| 头 | 法抗 +1.8、法术 +2.1%、**技能冷却 −5.1%** | 0.26 |
| 手 | 攻速 +2.6%、暴击 +1.3%、攻击 +2.1% | 0.26 |
| 戒指 | 攻击 +25、法术 +25、暴击 +1.3%、暴伤 +5.2% | 0.26 |

七件非武器的战斗预算合计：0.37 + 0.33 + 0.30 + 0.26 × 3 + 0.22 = 2.00，与现在持平。鞋有时会出功能属性，所以实际的战斗期望略低于 2.00，由功能属性补上。

## 三、和现在比

一身装备能叠到的上限（所有能出这条属性的部位，各取一条蓝色中值相加）：

| 属性 | 3 件时 | 现在（打折） | 本案 |
|---|---|---|---|
| 攻击 % | 16% | 12.7% | 12.3% |
| 攻击 + / 法术 + | 190 | 120 | 120 |
| 法术 % | 10% | 5.9% | 4.8% |
| 攻速 | 20% | 12.6% | 12.6% |
| 暴击 | 5% | 7.6% | 7.6% |
| 暴伤 | 40% | 25% | 25% |
| 生命 % | 16% | 5.4% | 5.3% |
| 生命 + | 780 | 273 | 371 |
| 防御 + | 40 | 27 | 35 |
| 法抗 | 16 | 5.0 | 4.0 |
| 闪避 | — | 2.4% | 3% |
| 技能冷却 | — | −3.9% | −5.1% |
| 技能伤害 | — | 8.3% | 11% |
| 移速 | 8% | 1.8% | 6% |
| 体力回复 | — | 6.6% | 25% |
| 闪避体力消耗 | — | −5.5% | −20% |

- **变化最大的是鞋**：三条功能属性从几乎没有变成有感觉。
- **招牌属性**（闪避、技能冷却、技能伤害）比现在大约三到五成。
- **共享的战斗属性基本不变**。
- **单属性能叠的上限比 3 件时低**：比如生命 % 从 16% 变成 5.3%。原因是属性种类从 11 种变成 17 种，同样多的总量要分给更多属性。期望总量没变，变的是"把一种属性堆到很高"的空间。如果想留出这种空间，办法是让更多部位能出同一种属性（扩大词条池），而不是放大数值。

## 四、前缀和固有属性

- **纯属性前缀**（150 条里的那些）沿用"按部位缩放"。逐条为 8 个部位写表太多，所以前缀的缩放比例取第二节的"战斗属性平均占满额"。玩家看到的仍是缩放后的数。
- **固有属性**不再乘任何系数，直接写落到身上的数，见 `底材固有属性表_v1_0.md`。

## 五、要改的地方

- `game/field_catalog.gd`：新增 `SLOT_AFFIX_AMOUNTS[部位][属性]`，`roll_affix` 改为查这张表；`AFFIX_AMOUNTS` 只留给武器和旧存档。脚的词条池加防御 +、生命 +。
- `game/gear_slots.gd`：`AFFIX` 只用于前缀缩放，值不变。
- 旧存档：头、手、腿、脚、项链、戒指上已有的词条，按新表的同属性数值重算，保持原来的随机位置。
- 测试：七件非武器的战斗预算合计为 2.00；每个部位的词条都在表里。

## 六、实现记录（2026-10-21）

- `FieldCatalog.SLOT_AFFIX_AMOUNTS` 是第二节的表；`FieldCatalog.slot_ratio` 把部位大小折成满额的比例存进词条的 `scale`，所以范围、校准和精调照旧。
- 脚的词条池加了防御 +、生命 +。
- `GearSlots.AFFIX` 现在只用于纯属性前缀的缩放。
- 测试（`tests/test_gear.gd`）：战斗预算合计 2.00、每个部位的词条池都有表、鞋的金色词条在 120–140%、同地区同部位同层的底材固有属性不重复、装备掉率生效。
