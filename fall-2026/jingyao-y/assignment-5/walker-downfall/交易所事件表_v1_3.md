## 1. 字段说明

| 字段 | 含义 |
|---|---|
| 类型 | 突发 / 传闻 / 公告 / 黑天鹅（规则见策划案 §6.1、§5.5） |
| 影响 | 写法是"市场 · 类别 ×倍率"；"汇率 ↑"表示赤金变贵，龙门币走弱 |
| 时长 | 现实时间 |
| 权重 | 同类型里被抽中的相对概率。黑天鹅的总体频率完全随机，权重只决定是哪一种 |
| 依据 | P / P² / 原，并写页面名 |

新闻正文都用"PRTS 快讯："开头，约 20 字以内；`{}` 里是运行时填的内容。

## 14. 事件关联（v1.3）

**原则**：基础的出现频率仍然完全随机（突发和传闻按泊松过程出现，黑天鹅平均 3 周一次）。在此之上，事件之间有两种关联：

| 关联 | 规则 |
|---|---|
| **引出**（→） | 事件发生后，按概率在一段随机时间后引出另一个事件。可以设成只在传闻被证实（✓）或被辟谣（✗）时才引出。后续事件继承前一事件选定的地区或势力。后续是公告的，写进财经日历；其他的不预告 |
| **加权**（↑ / ↓） | 事件发生后的一段时间里，另一事件被随机抽中的概率乘上一个倍数，小于 1 就是压低 |

- 后续事件的新闻会标出起因，例如"矿石病新变种通报：龙门 · ← 天灾直击：龙门"。
- 加权对黑天鹅也起作用：没有预兆的黑天鹅，发生时按当时的权重决定是哪一种。
- 数据在 `game/market/market_links.gd`。规模：235 条关联，125 个事件会引出后续或改变别人的概率，200 个事件中有 171 个处在故事线里，共 23 条故事线。
