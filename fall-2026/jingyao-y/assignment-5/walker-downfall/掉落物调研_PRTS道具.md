补充：
- T1/T2 的用途文本全是「可用于多种强化场合，也常作为制造站合成项目的原料」这一类，区别只在开头：源岩「从地表开采出的岩石」，破损装置/装置「收缴来的……机械装置」，代糖「机械化制作的廉价天然糖替代产物」。
- 「收缴来的」这个说法说明装置线在原作设定里就是从敌人身上缴获的。这是做敌人掉落最直接的依据。
- 加工站副产物（固源岩页面）：加工时有 10% 概率出副产物，可能是源岩、代糖、酯原料、异铁碎片、双酮或破损装置。适合用作「打开时随机多给一份」的规则参考。

| 拳刃武士 | 打手（普通，近战，物理） | 「经过特殊训练的作战人员」，出拳极快、连续打击。PRTS 上**没有**「拳刃」「武术家」「拳手」这几个敌人页面，打手是最接近的 |
| 冰原战士 | 冰原战士（普通，近战） | 「擅长冰原作战的战士」，长期生活在冰原上，意志和体魄都很强 |
| 冰原猎人 | 冰原猎人（普通，远程） | 生活在冰原上的猎人，善于找出猎物群里最薄弱的一个 |
| （可选扩展） | 冰原术师（普通，远程法术） | 隐居山上的术师，把冰雪融进了法术 |

| 精英重击者 | 武装人员（精英，近战） | 来路不明，「使用巨大的镐器进行攻击」，防护很高。有镐器，和矿区很搭 |
| （首领参考） | 碎骨（领袖） | 整合运动突击部队干部，带源石爆破物和发射器 |

**关于萨米**：冰原战士、猎人、术师从描述看（「隐居在山上」）更像谢拉格/喀兰一带的冰原势力，不能确定是萨米敌人（未核对）。雪怪小队来自乌萨斯西北冻原。PRTS 上**没有**「萨米猎人」「萨米战士」页面。萨米的正式敌人多出现在集成战略「探索者的银凇止境」中，属于领袖级或特殊敌人，如「萨米的意志」「寒灾」「霜牡」「雪牝」，不适合做普通杂兵。建议：萨米林线用冰原战士、冰原猎人当杂兵原型，地区设定挂在萨米，不在名称里写「萨米」。

**推荐掉落**（分层：常见 = T1/★1–2，少见 = T2–T3/★2–3，稀有 = T3–T4/★3–4）：

### 4.1 暴徒
- 常见：**破损装置** ★1。描述里写它「曾被拼装在敌人的武器和防具上」，暴徒用的正是手工武器。
- 常见：**代糖** ★1。街头杂兵身上的廉价口粮，「也许可以吃」。
- 少见：**装置** ★2。
- 稀有：**全新装置** ★3。
- 理由：装置线的用途写的是「收缴来的」机械装置，最适合人形敌人掉落。

### 4.2 弩手
- 常见：**异铁碎片** ★1。弩机和箭头是金属件，碎片是金属加工的副产物。
- 常见：**破损装置** ★1。弩机机构。
- 少见：**异铁** ★2。
- 稀有：**研磨石** ★3。用途是「用于加工武器零件」，符合弩手保养箭头的设定。

### 4.3 弩手组长
- 常见：**异铁** ★2
- 少见：**装置** ★2，**异铁组** ★3
- 稀有：**研磨石** ★3 或 **化合切削液** ★3（金属加工用润滑液）
- 理由：比弩手高一阶，同一条线。描述里提到「武器和护具」，所以可以加一点装置。

### 4.4 源石虫
- 常见：**源岩** ★1。源石挥发后留下的岩石，对应虫壳和残渣。
- 少见：**固源岩** ★2。微孔结构能吸附源石气体分解物。
- 稀有：**晶体元件** ★3。用「源石晶体外壳」制作，和虫子背上的源石结晶对应。
- 变种：冰爆源石虫额外掉 **转质盐组** ★3（结晶，未核对设定关联），高能源石虫额外掉 **RMA70-12** ★3（和源石技艺相关的矿物）。
- 理由：源石虫是感染生物，掉源石类矿物最符合直觉。至纯源石或源石碎片太贵重（★5–6），不建议放进普通掉落。

### 4.5 拳刃武士（打手原型，龙门下城区）
- 常见：**代糖** ★1，**糖** ★2。下城区街头补给，写成「流水线员工偷吃」的梗。
- 少见：**酯原料** ★1 / **聚酸酯** ★2。缠手带、护具。聚酸酯是「缓释药物中的常用成分」，可以写成跌打药。
- 稀有：**扭转醇** ★3。工作间「醉醺醺」的酒气，适合下城区酒馆和帮派风味。
- 理由：近身格斗型敌人不带机械武器，所以用有机和化工线，和金属线的弩手区分开。

### 4.6 冰原战士
- 常见：**双酮** ★1。粘结和固化用，可写成修补冰原装备的胶。
- 少见：**酮凝集** ★2，**轻锰矿** ★3。冻土层里的金属矿物。
- 稀有：**褐素纤维** ★3。高强度纤维束，对应御寒和护甲用的纤维。
- 理由：区分近战和远程。战士偏护具和材料，猎人偏狩猎工具。

### 4.7 冰原猎人
- 常见：**异铁碎片** ★1。箭头或猎具碎片。
- 少见：**研磨石** ★3（磨箭头）。
- 稀有：**凝胶** ★3。耐高低温，适合极寒环境；或者掉 **轻锰矿** ★3。
- 冰原术师（可选）：**RMA70-12** ★3（和源石技艺相关）、**晶体元件** ★3。

### 4.8 精英重击者（武装人员原型）
- 保底：**固源岩组** ★3。它用镐器作战，和矿区对应。
- 少见：**轻锰矿** ★3，**全新装置** ★3
- 稀有：**改量装置** ★4（「大量私自改造」）或 **提纯源岩** ★4
- 极稀有：**D32钢** ★5（「重新订立武器材料的标准」），可以和武器箱的稀有档共用一个掉落池。
- 理由：精英敌人保证掉 T3，并加入 T4 和 T5 的小概率。

### 4.9 按地区汇总材料主题（便于统一视觉）
- 切尔诺伯格坍塌矿区：源岩线、轻锰矿、RMA70-12、研磨石，加上整合运动装备掉的装置线和异铁线。
- 龙门下城区废墟：糖线、酯线、扭转醇、化合切削液、半自然溶剂（城市化工和地下作坊）。
- 萨米冻土林线：双酮/酮线、褐素纤维、凝胶、转质盐组、环烃聚质（极寒材料和透明耐候材料）。

## 六、武器

**结论**：明日方舟没有独立的「武器道具」体系。干员武器不能单独获取，不是道具。可以参考的内容有三类：(a) PRTS 敌人描述里提到的制式装备；(b) 描述里明确跟武器有关的养成材料；(c) 集成战略的收藏品。不涉及任何具体人物。

### 6.1 敌人描述中出现的装备（已核对）
| 器物（类型） | 出处 | 可做的掉落武器原型 |
|---|---|---|
| 缴获或非法渠道得来的武器、制式面具和服装 | 弩手组长（整合运动） | 整合运动制式弩、制式面具（装备栏） |
| 弩 | 弩手 / 弩手组长 | 轻弩、连弩（组长级） |
| 手工武器（未核对，来自搜索摘要） | 暴徒 | 简易棍棒、改装砍刀 |
| 「巨大的镐器」 | 武装人员 | 重型矿镐（精英掉落 / 武器箱稀有档） |
| 「源石爆破物及其发射器」 | 碎骨（领袖） | 源石爆破筒（只适合首领掉落，作为参考） |
| 刀（「冻原之上最老练的刀子手」） | 雪怪小队破冰者 | 破冰刀 / 冰原短刀 |
| 远程猎具 | 冰原猎人 | 猎弓或猎弩（具体器物未写明，未核对） |
| 拳（「极为快速的出拳」） | 打手 | 拳套、指虎类近战武器 |

### 6.2 和武器直接相关的养成材料（可作为武器强化或升级材料）
- **研磨石 / 五水研磨石**：用途写着「用于加工武器零件」和「用于精加工武器零件」。
- **D32钢**：「将重新订立武器材料的标准」，适合作为最高档武器的锻造材料。
- **双极纳米片**：提升「作战武器和设备对源石的敏感性」，可用于源石技艺类武器。
- **晶体电子单元**：「源石施术单元」的制造离不开它，可用于法杖或施术单元类武器。
- **破损装置**：「曾被拼装在敌人的武器和防具上」，可作为拆解武器后得到的材料。
- **化合切削液**：金属加工必备试剂。

### 6.3 干员武器类型（只引用类型，不对应具体干员）
按职业对应常见武器类型：近卫（刀、剑、斧、锤、长柄武器）；狙击（弩、弓、铳）；重装（盾加近战武器）；术师（源石施术单元、法杖）；先锋（长枪、旗帜）；特种（钩索、匕首）。PRTS 用「源石施术单元」这个说法（见晶体电子单元描述）。**具体武器名称和职业的对应关系没有在 PRTS 逐条核对，未核对。**

### 6.4 集成战略收藏品中的武器类条目（全部未核对）

- 刻俄柏的灰蕈迷境收藏品（摘要所得）：锉刀、废铁陷阱、防割断纤维背心、古旧的蒸汽甲胄（页面存在）、损坏的左轮弹巢（页面存在，名称有出入）、锈蚀银枪、齿轮式外骨骼、破片地雷、血腥链锯、《打架手册》、萨米大"蜡烛"。
