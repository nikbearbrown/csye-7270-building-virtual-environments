# 干员属性计算公式

2026-10-21，按当前代码整理（`entities/player.gd`、`game/combat_stats.gd`、`game/operators.gd`、`entities/enemy.gd`、`game/game_manager.gd`）。

记号：
- **G** = 1.04^(层 − 1)，每层的复利成长。
- **档位系数** = 1.48^(档 − 1)，档 = (层 − 1) / 10 + 1，向下取整。
- **加法池**：同一个键的所有来源直接相加，再进公式。

## 一、属性表（加法池）

每次换装、加点、拿藏品时重算。下面这些来源全部加进同一张表，同名的键直接相加：

| 来源 | 内容 |
|---|---|
| 装备面板 | 武器：主属性 = 220 × 效能。<br>防具五件：生命 = 1300 × 效能 × 份额，防御 = 80 × 效能 × 份额。<br>项链、戒指：攻击 / 法术合计 = 110 × 效能 × 份额，按这件的攻法比例分。 |
| 装备固有属性 | 底材固有属性表，按稀有度三段波动；固定值每档 ×1.30。 |
| 装备随机词条 | 部位词条数值表，按稀有度三段波动；固定值每档 ×1.30。 |
| 装备前缀 | 表值 × 0.8–1.2 的随机数 × 部位系数（武器 1.0，胸 0.37 …… 脚 0.22）；防御另乘每档 ×1.30。 |
| 特殊装备效果 | 套装、Boss 件的常驻属性（`gear_fx.static_sheet`）。 |
| 藏品 | 局内藏品的属性（`RelicCatalog.stat_sheet`）。 |
| 诡意的 | 每层随机一种属性。 |
| 属性点 | 超出起始值的点数 × 每点收益：<br>体魄：生命 +0.35%、防御 +0.35%、回复 +0.17<br>技巧：攻击 +0.28%、暴击 +0.07%、暴伤 +0.35%<br>敏捷：攻速 +0.2、体力回复 +3.5%、移速 +0.07%<br>源石技艺：法术 +0.38%、法术伤害 +0.17%、法抗 +0.1 |
| 模组 | 干员模组的属性。 |
| 精英 2 | 法抗 +5。 |

**科研部不直接改干员属性。** 它改的是局外和地图：赤金 ×1.2、威胁累积 ×0.85、特色计量 ×0.9 / ×0.8、掉落阶梯 +1、波动段内随机的指数 ×0.85（档内好结果更常见）、密室 ×1.5、替补干员分到的经验。

## 二、面板属性

| 属性 | 公式 |
|---|---|
| **生命上限** | (600 + 生命固定 + 临时增益) × (1 + 生命% + 干员特性生命% + 精英击杀叠层 + 登天斧 / 路线加成) × **干员生命系数** |
| 当前可用生命 | 生命上限 × (1 − 伤病 / 污染惩罚) |
| **攻击力** | (150 + 攻击固定) × max(0.1, 1 + 攻击% + **条件攻击%**) |
| **法术攻击力** | (150 + 法术固定) × max(0.1, 1 + 法术% + **条件攻击%**) |
| **防御** | (50 + 防御固定) × max(0, 1 + 防御% + 条件防御%) × max(0.1, 1 + **敌方破甲**) × **干员防御系数** |
| **法抗** | min(80, 10 + 法抗 + **干员法抗** + 条件法抗) |
| **攻速** | clamp(100 + 攻速, 40, 300) × **寒冷** × max(0.2, 1 + **敌方减攻速**) |
| 出手间隔 | 基础间隔 × (1 + 间隔%) ÷ (攻速 / 100) |
| **暴击率** | clamp(暴击, 0, 100%)，再加特殊装备对该目标的加成、影步 |
| **暴击伤害** | 1.5 + 暴伤 |
| **移速** | 5 × max(0.3, 1 + 移速%) × 特殊装备 × 干员特性 × **寒冷** × max(0.2, 1 + **敌方减速**) |
| **物理闪避** | min(60%, 闪避 + 干员特性 + 剑舞 50%)，再加近战闪避或远程闪避（看攻击者） |
| 法术闪避 | min(60%, 法术闪避 + 剑舞 + 夜跑 15%) |
| 吸血 | min(30%, 吸血) |
| 技能伤害 | 1 + 剑气伤害% + 技能伤害% |
| 技能冷却 | clamp(1 + 技能冷却%, 0.5, 2.0) × 冷却或充能 |

**干员系数**（`Operators.STAT_MULT`，乘在最外层，装备再好差距也不变）：

| 干员 | 生命 | 防御 | 法抗 + |
|---|---|---|---|
| 拉普兰德 | 1.00 | 1.00 | 15 |
| 阿米娅（剑） | 1.07 | 1.02 | 20 |
| 赫拉格 | 1.38 | 0.95 | 0 |
| 星熊 | 1.38 | 1.59 | 0 |
| 德克萨斯 | 0.90 | 0.96 | 0 |
| 早露 | 0.85 | 0.60 | 0 |
| 提丰 | 0.83 | 0.59 | 0 |
| 林 | 0.92 | 0.80 | 15 |
| 灵知 | 0.82 | 0.60 | 20 |

攻击没有干员系数，输出差别靠出手间隔、连击和技能倍率。

**条件攻击%**（攻击和法术共用，`power_bonus`）。下面这些全部相加：
- **藏品**：满血攻击 × 血量比例、蓄势攻击、连击叠层、剑气爆发、闪避后攻击、剑气叠层、独战攻击。
- **前缀**：暴动的（周围敌人数）、家族的（血量 90% 以上）、游击的（闪避后）。
- **其他**：格挡架势 +40%、祭坛每层 +5%、登天斧 / 路线加成。
- **技能树**：狼魂、青色怒火（绝影中翻倍）、绝影击杀叠层。
- **干员特性和特殊装备**的攻击%。

**条件防御%**：
- **藏品**：古堡的子嗣（停留后 +120%）、满血防御 +20%。
- **其他**：格挡架势 +40%、祭坛每层 +5%。
- **干员和装备**：青色怒火、干员特性、特殊装备。

## 三、打出去的伤害

```
原始 = 攻击力（法术招式用法术攻击力）
     × 招式倍率（连击段、技能、剑气……；技能另乘 技能伤害）
     × 伤害加成（1 + 伤害% + 临时增益）
     × 特殊装备（冻结遗物 ×1.4、萨卢佐纹章 ×1.3）× 复仇（下一击 1 + 复仇%）
     × 目标倍率（残血 1 + 残血伤害% × 已损血量比例；精英 1 + 对精英伤害%；特殊装备）
     × 暴击时 暴击伤害
     × (1 + 法术伤害% 或 物理伤害%)
     × max(0.1, 1 + 敌方削弱)

敌人受到：
  物理 = 原始 × K / (K + 敌防御 × (1 − 破甲状态) × (1 − 无视防御))，K = 600 × G
  法术 = 原始 × max(1 − min(敌法抗 − 减法抗状态 [+ 屏障 50], 80) / 100, 10%)
  真实 = 原始
  再 × (1 + 脆弱)；正面格挡的敌人从正面打 × (1 − 格挡比例)
```

命中以后：吸血按实际伤害回血；附带的特效（横扫 50%、源石刃 18% 法术、盾击 150% 防御……）另算一次伤害，不触发吸血。

## 四、受到的伤害

依次判定：

1. 无敌时间 → 不受伤。
2. 闪避判定：物理用物理闪避，法术用法术闪避，真实伤害不能闪避 → 闪开就不受伤。
3. 干员特性格挡、格挡次数 → 挡下就不受伤。
4. 特殊装备的受击效果。
5. 减伤：
   - 物理 × K / (K + 防御)，K = 600 × G
   - 法术 × max(1 − 法抗 / 100, 10%)
   - 真实不减（陷阱就是真实伤害）
6. × (1 − min(80%, 防暴盾 25% + 整体减伤 − 受远程伤害增加))
7. × max(0, 1 + 受到伤害% + **敌方易伤**)
8. 干员特性再减（比如星熊）。
9. 护盾先吸收。
10. 致命时依次看：急救药剂、干员特性、复还之手；血量低于 30% 时看临界护盾（每层一次）。

## 五、回复

```
每秒回复 = [ 生命上限 × 0.1%（自回，不吃加成）
           + (回复 × 档位系数 + 生命上限 × 回复上限%) × (1 + 回复%) ]
         × 污染回复系数
         − 生命上限 × (污染流失 + 寒冷流失)
```

寒冷到一定程度时自回停止。药剂是固定值 × 档位，不吃加成，只有干员特性能改。击杀回血是固定值 × 档位系数。

## 六、敌方给干员的减益（hex，相加）

| 键 | 来源 | 作用 |
|---|---|---|
| def | Boss 破甲（可叠，到离开为止） | 防御 × (1 + 值) |
| aspd | Boss 威压（二阶段，靠近时） | 攻速 × (1 + 值) |
| move | Boss 区域、诅咒 | 移速 × (1 + 值) |
| atk | Boss 诅咒、区域 | 打出的伤害 × (1 + 值) |
| taken | Boss 诅咒、区域 | 受到伤害 × (1 + 值) |
| stamina | Boss、药剂 | 体力回复 |

药剂也会挂正面或负面的 hex，比如副作用。

地图特色：
- **寒冷**：降低移速和攻速，流失生命，到一定程度停止自回。
- **污染**：降低生命上限（和伤病一起算）、降低回复，到高位流失生命。

## 七、敌人这一侧

```
敌人生命 = 基础 × G × (雪原 ×1.45) × 藏品"敌人生命"系数 × 精英 / Boss / 赏金倍率
敌人攻击 = 基础 × G × 精英 / Boss 倍率
巡逻队（威胁值触发） = 再 × 本层威胁强度（层内指数变强，下层继承 30%）
阶段：残血转阶段攻击 ×1.6，歼灭阶段 ×1.5
```

威胁累积速度 = 自然累计 × (1 + 哨兵加成 × 已警戒哨兵数) × 行情系数 × 科研系数 × 药剂系数。
