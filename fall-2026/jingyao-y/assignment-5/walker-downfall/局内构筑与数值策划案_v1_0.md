## 1. 调研结论（摘要）

完整内容见两份调研文档，这里只列直接决定本案的结论。

**集成战略（PRTS 核对）**
1. 白板藏品三档递进：同一效果按 约 1 : 1.7 : 2.3 分低/中/高稀有（生命 +20/35/50%，近战攻击 +15/25/35%）。
2. 同层百分比**相加**而非相乘（急救药箱 +35% 与止血剂 +20% 叠成 +55%）。这是藏品叠多了也不爆炸的原因，本作照搬（§3.2）。
3. 攻速是对 100 基准的平加（"攻击速度+X"），攻击间隔 = 基础间隔 / (攻速/100)。本作照搬。
4. 伤害公式：物理 `max(ATK−DEF, 5%·ATK)`，法术 `ATK·(1−RES/100)`，真实无视两者。
5. 代价型统一写成"X，但 Y"；部署、阻挡、技力类效果要转译成"进入区段 / 近身敌人数 / 剑气充能"，编队类转译不了。
6. 套装：诸王的冠冕、魔王的祭器等"集齐 3 件同系列"会升级效果。（本作曾据此做体系共鸣与桥梁，2026-10-04 按用户要求取消。）

**同类游戏**
1. RoR2：纯数值线性叠加，概率类给上限；触发产生的伤害不再触发同类效果（proc 系数），否则会无限连锁。
2. Hades：候选池向已选的神倾斜，一局会自然收敛；Duo 祝福要求同时持有两位神的前置。（本作的桥梁与构筑引导已随羁绊系统取消。）
3. 杀戮尖塔：同局不重复；Boss 遗物用"指向构筑之外系统的代价"让某些构筑免疫代价——本作大量代价指向药瓶、点金、安全袋、污染。
4. 枪火重生 / Dead Cells：流派 = 一种"状态货币"（元素、颜色）；条件增伤的大小和条件难度成正比。
5. 稀有度权重约 60/30/10；连续几次没出主流派要保底。
6. 防御：平减公式直观，但敌人攻击一涨就失衡，需要（a）保底比例（b）敌人攻击与玩家防御同步增长。本作保留明日方舟平减（与世界观一致、"破甲"有意义），用 10% 保底和警戒/深度增长来约束（§4.2）。

## 2. 设计目标

1. **一局拿得够**：一次 6 区段的合同拿到 10–15 件藏品，接近集成战略一局的量级。
2. **藏品之间自然配合**：没有套装规则，配合来自效果本身（闪避率 × 闪避后增益、剑气充能 × 剑气后增益、满血 × 满血加成……），至少 8 种明显不同的打法（§11）。
3. **属性有意义**：攻击 vs 防御、物理 vs 法术、攻速 vs 暴击，每一组都存在"这个敌人该用哪一个"的答案。
4. **数字看得见**：飘字、敌人血条、属性面板，让玩家读得出防御和法抗在起作用。
5. **地区性格保留**：矿区多出防御与生命类藏品，龙门多出攻击、防御与攻速类，萨米多出剑气与攻击类（§8.4）。

### 3.2 属性来源与叠加

`最终值 = (基础 + 固定加成) × (1 + 所有百分比加成之和)`，百分比加成在同一层相加（集成战略规则）。
来源三处：装备基础效能（§7）、装备词缀（§7.2）、藏品（§10）。条件性加成（低血、满血、计时窗口、叠层）在出手时实时加入同一层。

## 4. 伤害结算

### 4.1 玩家出手

```
原始 = 攻击力 × 连斩倍率 × 通用倍率 × 目标倍率 × 暴击系数
实际 = 物理：max(原始 − 目标防御×(1−破甲), 原始×10%)
       法术：原始 × (1 + 法术增伤) × max(1 − 目标法抗/100, 10%)
```

- 连斩倍率：第一、二段 100%，第三段 130%。
- 剑气：法术攻击力 × 150% × 剑气倍率，穿透，射程 9。
- 攻击力里的条件加成（同一层相加）：古乔治营养原浆、"噤声"、轰鸣之手、绿叶菜罐头 / 叙拉古人的愤怒、《光耀卡西米尔》/《归来》、《拳经三问》、荣耀绶带、霜牡的肩甲、圆石祭坛、登天斧、统帅肖像。
- 通用倍率：伤害增幅、赏善郎（一次性 ×2）、冻土下的旧物；物理 / 法术伤害增幅在命中时乘入（锈蚀刀片、制式防暴用具……）。
- 目标倍率：溃决之手（随目标失血至多 +50%）、对精英伤害。斩杀（扼喉之手 30%、溃决之手 20%）只对普通敌人。
- 暴击系数：暴击时 = 暴击伤害（暴击只来自装备词缀）。
- **乘区约定**：所有藏品增益都在防御结算之前。和明日方舟一样，这让"攻击力"和"破甲"在打高防敌人时收益更高，形成"物理打软、法术打硬"的选择。

### 4.2 敌人出手

```
原始 = 敌人攻击力 × (1 + 警戒/160)
实际 = 物理：max(原始 − 我方防御, 原始×10%)；法术：原始 × (1 − 我方法抗/100)
     → 物理闪避判定 → 防蚀胸针抵挡 → 各类减伤（上限 80%）→ 受伤增幅 → 护盾吸收 → 致死保护 → 扣血
```

- 保底 10% 而不是原作 5%：动作游戏里每一下都要"看得见"。
- 普通敌人全是物理攻击；精英重击是法术（策划案 §5：精英与法术攻击显示红圈，二者在此合一）。所以**防御对付杂兵，法抗对付精英**。

### 4.3 生命与治疗

- 药瓶（与基地药房一致）：标准急救剂 960，缓释凝胶 6 秒共 1680，抑制喷剂 480（=原 4/7/2 按 2400 等比放大）。
- 原矿失血：每块 60/秒（=原 0.25/10 等比）。
- 所有治疗乘以治疗效果（heal_pct，活玫瑰 / 苍白花冠）。

### 4.4 触发规则（防连锁）

| 伤害 | 触发吸血 | 触发其他效果 |
|---|---|---|
| 普攻本体、剑气 | 是 | 是 |
| 附加伤害（特殊装备的源石刃、盾击、横扫、残影、尖刺） | 否 | 否 |
| 灼烧、源石爆裂 | 否 | 否；源石爆裂不会引发源石爆裂 |
| 月下刃的额外剑气、双生狼牙的两道剑气 | 是 | 不会再触发月下刃 |

## 8. 藏品系统

### 8.1 一件藏品

一件集成战略藏品：PRTS 原名 + 稀有度（低 / 中 / 高，对应原作三档）+ **本作效果** + **集成战略原效果**（卡片上一并显示，便于对照）。
部署、技力、阻挡、编队类原效果按调研 §3.5 的规则转译：部署 → 进入区段、技力 → 剑气充能、阻挡 → 近身敌人数、"目标生命" → 拉普兰德自己的生命。
藏品之间没有套装或体系加成。

### 8.2 来源（每区段最多 3 件）

| 来源 | 条件 | 稀有度权重 低/中/高 |
|---|---|---|
| 强化装置 | 每区段一个，两名守卫 | 60 / 30 / 10 |
| 战斗缴获 | 每击败一个敌人掷一次：首领（悬赏目标、据点头目）必掉，精英 5%，普通敌人 0.8%，在它倒下处出现藏品箱（用户 2026-10-13 调低；原为本区段威胁值累计到 8） | 65 / 30 / 5 |
| 密室藏品 | 触发全部机关、击败密室守卫者后解封 | 25 / 50 / 25 |

三种都是"靠近按 E 打开三选一"，每个箱子的选项第一次打开时生成、之后不变（关掉再开不会刷新）。
"稍后选择"可以先离开。深入后上一区段没拿的全部作废（单向推进）。

### 8.3 出货规则

1. **三个选项尽量来自三类不同的藏品**（攻击 / 剑气与法术 / 攻速与节奏 / 防御与闪避 / 生命与回复 / 经济与选择；分类只用于出货，界面不显示）。
2. 权重 = 来源稀有度权重 × 地区类别权重。
3. 同局不重复；池中可选少于 3 件时装置休眠（原规则）。
4. **刷新**：花待交付报酬刷新当前选项，第 1 次 25，之后每次 +25（锈蚀的铁锤减半）。待交付报酬只有撤离才入账，所以刷新是"赌我会撤离成功"。
5. **罗德岛战术电台**：之后所有选择多一个选项。

### 8.4 地区倾向

| 地区 | 加权类别（×） |
|---|---|
| 切尔诺伯格 · 坍塌矿区 | 防御与闪避 2.5、生命与回复 2 |

| 萨米 · 冻土林线 | 剑气与法术 2.5、攻击 1.5 |

- 三选一卡片：稀有度色边框、稀有度、名称、本作效果、集成战略原效果；下方是本次已有藏品。
- HUD：攻 / 法 / 防 / 抗 / 攻速 / 暴击 一行，藏品件数一行，护盾数值。
- 背包界面（I）：完整属性面板 + 藏品列表（按稀有度着色的小方块，悬停看效果）。
- 飘字：白=物理，紫=法术，金=暴击（带 !），绿=治疗，红=受伤，蓝=护盾吸收/抵挡，灰=闪避；敌人受伤后显示血条。

### 10.7 特殊装备（9 件，自带伤害的攻击效果）

特殊装备是有名字的装备：固定一条**特殊效果**（自带伤害），另带 1 条普通随机词缀，部分带固定代价；名称与边框为橙红色。它遵守全部装备规则——占格、可点金、可投保、撤离带回、跨合同使用。三个装备槽各只能装一件，所以"带哪几种攻击效果"本身就是取舍。剑气是拉普兰德自带的招牌机制（2026-10-04 拍板，§0）。特殊装备的效果都挂在通用触发点上（命中、击杀、闪避、受击、招牌发动时），以后换角色也能用；剑气类藏品照旧负责把剑气打得更好。

## 12. 验证

1. 数值验算：`tests/balance_tables.py` 按 §4 公式计算 §6.1 的三张表。
2. 自动化测试：`tests/test_builds.gd`（117 项）验证藏品表（全部为 PRTS 调研表中的藏品）、出货规则、来源与刷新、各类藏品效果与特殊装备；原有 v1 / 战斗 / 敌人 / 医疗 / 拉普兰德 / 界面套件按新数值更新，`tests/run_all.ps1 -Visual` 全部通过。
3. AI 试玩：`tests/sim_builds.gd` 让只会躲前摇、不会闪避的 AiDriver 每个地区打 150 秒（游戏时间）。
   - 间隔 0.42 秒时：龙门第 3 区段撤离（6 件构筑物），萨米第 3 区段存活（5 件），矿区第 2 区段阵亡。
   - 放慢到 0.7 秒、攻击力不变后：矿区第 1 区段阵亡，龙门第 2 区段阵亡（3 件），萨米第 2 区段存活（2 件）。击杀用时约为原来的 1.7 倍，敌人出手次数相应增加，整体明显变难；是否配套下调敌人攻击或生命，待真人试玩后定。
   - 改为集成战略藏品、取消共鸣后（2026-10-04）：矿区第 2 区段阵亡（3 件），龙门第 2 区段阵亡（2 件），萨米第 3 区段存活（4 件），与改版前同一攻速下的结果相当。
   藏品获取约每区段 1.5–2 件。
4. 待真人试玩：藏品强度排序、刷新价格、战斗缴获掉率（首领 100% / 精英 5% / 普通 0.8%）、密室稀有度权重。
