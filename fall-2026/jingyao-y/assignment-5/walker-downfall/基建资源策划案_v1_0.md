# 基建资源策划案 v1.0：通用物资

依据：`基建资源调研_塔科夫与鸭科夫.md`。在 PRTS 基建材料（碳、碳素、加固建材、家具零件、赤金）之外，加入塔科夫、鸭科夫式的日常物资，
让兴趣点按“主题容器出主题物资”分工，建设配方变成“基础五金 + 主题物资 + PRTS 材料”。

## 1. 物资表（22 种）

本作折中处理：小件按星级堆叠；基础五金堆叠上限放宽到 30；整机和重物不堆叠，并占多格。

## 2. 兴趣点分工

参照塔科夫的容器对照：工具箱出五金、工具和电子，PC 机箱只出电子，医疗箱只出医疗。

| 兴趣点 | 必出 | 概率出 |
|---|---|---|
| 建材堆 | 碳 2–4；螺栓/螺母/钉子 3–6；金属板或木板 1–3 | 碳素、加固建材、软管 35%、密封泡沫 12% |
| 物资仓 | 家具零件 1–2；胶带 2–4；灯泡或蓄电池 1–3 | 电源线 35%、软管 25%、车用蓄电池 4%、赤金 5% |
| 冰原营地 | 碳 2–3；木板 2–4；固体燃料 3–6 | 帆布 40%、蓄电池 25%、碳素组 20% |
| 源石矿脉 | 源岩、固源岩（不变） | 金属板 30%、燃料罐 5% |
| 保险柜 | 资金 | 赤金 35%、电路板 25% |
| 工具箱 | 饰品（不变） | 五金 2–5（60%）、电线 30%、扳手 15%、工具套装 3% |
| **电子柜**（新） | 电线 2–5；继电器或电路板 1 | 电源线 40%、电路板 30%、微型电机 6% |
| **医疗柜**（新） | 医用耗材包 1–2；胶带 1–3 | 帆布 30%、糖 25% |

两个新兴趣点的区域权重：电子柜 城 2 / 矿 1 / 雪 0.5；医疗柜 城 1 / 矿 0.5 / 雪 1。两者都算基建点，计入每区段至少 2 个基建点的保底。
敌人掉落不变，仍是各自的专属养成材料。

## 3. 建设配方

规律沿用塔科夫和鸭科夫：基础五金为主，加一件主题物资，等级越高越需要整机和稀有材料。

| 建设 | 资金 | 材料 |
|---|---|---|
| 货架 2–3 | 60/90 | 螺栓×4 + 金属板×2 |
| 货架 4–6 | 140 | 碳×3 + 螺栓×6 + 基础加固建材×1 |
| 货架 7–9 | 200 | 碳素×3 + 金属板×4 + 进阶加固建材×1 |
| 搬运无人机 | 150 | 微型电机×1 + 电路板×2 + 蓄电池×2 + 家具零件×2 |
| 背包扩容 1 | 120 | 帆布×3 + 胶带×2 + 碳×2 |
| 背包扩容 2 | 260 | 帆布×5 + 密封泡沫×2 + 家具零件×3 |
| 安全袋扩容 1 | 150 | 金属板×4 + 继电器×1 + 赤金×1 |
| 安全袋扩容 2 | 320 | 碳素组×1 + 电路板×2 + 赤金×2 |

## 5. 表现

- 物品描述的前缀标明来源：“PRTS ★N” 或 “通用物资 ★N”。
- 悬停提示显示类别（建材、电子等）。
- 不堆叠的物资（车用蓄电池、燃料罐、工具套装）照常占多格，没有 ×N 角标。
