# 界面美术与布局策划案 v2.0：罗德岛舰内风格

2026-10-21。本案接替 `界面策划案_v1_0.md` 的 §2（视觉语言）和 §4（界面清单）。v1 里的规则继续有效：不写说明文字、不要战力、橙色只给源石、敌人血条照恐怖黎明分档、快捷栏与按键。

用户要求：

> 设计整体 ui 美术风格和各 ui 界面布局，符合现在罗德岛内饰的风格，该拆开的 ui 拆开，人物穿戴的装备界面分布同恐怖黎明。

用户补充（同日）：

> 武器、头、胸、手、腿、脚、项链、戒指（分开后每个装备的数值是不是就可以更保守了）

- 原型：`art/ui_mockup_v2/index.html`，所有界面都按 1280×720 画。
- 依据：
  - 基地现状：`基地建模改造案_v1.md` 和 Sol 交付的 R1–R10 材质，取色见 §1.1。
  - 现有界面：逐一盘点了 `ui/*.gd`，结果写在 §3 的“现状”列。
  - 恐怖黎明装备栏：按原版截图核对，见 §4.1。
- 本案只做设计，不改代码。待拍板的事项见 §8。

## 1. 美术风格：“舰内终端”

v1 的底色是 `#161616` 中性黑，加上方舟客户端的写法（白板页签、宽体英文水印、黄色竖条）。它的问题是和现在的基地对不上。基地已经改成建模，用的是蓝灰舰板、全息青灯带和警示黄边线。玩家走到整备台前按 E，弹出来的却是一张纯黑网页，两者不像同一艘船上的东西。

v2 的原则：**界面就是舰上那台终端的屏幕。** 方舟客户端的写法照旧保留，因为“舟味”靠的是这些写法。底板、边框、灯带和部门标识则改用罗德岛舰内的材质语言。

### 1.3 形状：舱壁切角

罗德岛的舱门和舱壁都是 45° 切角（见大厅气闸门和整备区柜体）。界面沿用这个形状：

- **窗口与大面板**：左上角和右下角各切 10 px，另外两个角是直角。外框 1 px `SEAM`，上边和左边换成 `SEAM_HI`，看起来像受顶灯照的钢板。
- **卡片和按钮**：只切右下角，切 6 px。
- **物品格**：不切角。物品格继续用方舟仓库格（底部稀有度光、色条、黑框数量）。
- **标题栏**（窗口和站点通用，高 44）：
  - 最左边是 6×44 的部门色竖块，上端 10 px 切成警示斜角。
  - 中文标题用 900 字重，后面跟拉宽的英文小字。
  - 底边是一条 2 px 的灯带，用部门色，向两端渐隐。舰内墙上的灯带也是这个样子。
- **铆钉**：只在窗口四角画，每角一颗 3×3 的 `SEAM_HI` 点。别的地方都不画。
- **水印**：v1 的宽体英文水印保留，透明度 6%。旁边加罗德岛 L 标志（`art/kit/textures/base_rhodes_logo.png`，即三角里的车塔），透明度同样是 6%。
- **斜纹**只用在两处：
  - 黄黑斜纹：锁定（声望不够、未研究）和危险确认（放弃合同、丢弃）。
  - 红色斜纹：精英前摇，同 v1。

### 1.4 底纹（每种皮肤一种）

底纹透明度不超过 5%，只看得出质感，不影响读字。

| 皮肤 | 底纹 | 用在 |

同 v1 §2.3：中文用 Noto Sans SC，英文和数字用 Saira。字体文件是否打包仍待拍板，见 v1 §8 第 5 条。交易所和账房的数字改用等宽数位。

### 1.7 物品格与空槽

- 物品格和 v1 一样，格子仍为 40 px，图标 1:1，`test_item_icons` 会检查。
- 纸娃娃的空槽改照恐怖黎明：画一个部位剪影，用 `SEAM_HI`、透明度 35%。剪影共 8 张，即头、胸、手、腿、脚、项链、戒指、武器，交给 Sol 出图，见 §7。
- 已装备的槽：外框换成该物品的档位色，底部有稀有度光。

## 2. 窗口与外壳

### 2.1 局内窗口（便携终端）

局内窗口沿用 v1 §2.5 的刷宝游戏停靠窗，外观换成 §1.3：

- 标题栏 44 高，依次是：部门色竖块、中英标题、页签、快捷键角标（白底黑字小牌）和 ✕。
- 背后的战场压暗 35%，HUD 照常显示。
- 同一时间只开一个窗口。按另一个窗口的快捷键，直接切过去。

### 2.2 基地站点（舰载终端外壳）

基地站点替换 v1 的 `BaseScreens.shell()`。

| 区块 | 位置 | 内容 |
|---|---|---|
| 顶栏 | 0,0 起，1280×60 | 返回 ‹ / 首页 ⌂（切角方块）、部门色竖块、中英标题、页签、右侧货币牌 |
| 灯带 | y=60 | 2 px 部门色，两端渐隐 |
| 内容区 | 16,76 起，1248×600 | 每个站点各自的布局（§5） |
| 底栏 | y=692，高 28 | 左边是罗德岛 L 标和 “RHODES ISLAND · 部门英文名”，右边是本站的快捷键提示牌（只放键帽和动作名） |
| 水印 | 右下角 | 部门英文名加 L 标，透明度 6% |

站点页签的规则：

- 页签只用来切换**同一件事的不同视图**。例如交易所的行情和持仓，或者仓库的“全部”和“武器”。
- 不同的事拆成不同的站点，或者拆成同一站点下各自独立的界面（见 §3）。
- 每个页签都要有自己的布局，不能是同一个面板随条件显示或隐藏几块。

## 4. 局内：装备与干员

### 4.1 I · 装备与背包（恐怖黎明纸娃娃）

**恐怖黎明原版的装备区**按截图核对（1.1 版客户端，1920×1080），排法如下：

```
 [主手 ]  [换武器][  头  ][护身符]  [副手 ]
 [ 高 ]   [戒指1 ]        [戒指2 ]  [ 高 ]
 [胸甲 ]       人物模型              [护肩 ]
 [ 高 ]                              [手套 ]
 [腿甲 ]                             [靴子 ]
 [ 高 ]   [圣物 ][  腰带  ][勋章  ]
```

- 左列是三个高槽：主手、胸甲、腿甲。
- 右列从上往下是副手、护肩、手套、靴子。
- 头在上方正中，两侧小槽是换武器键、护身符和两枚戒指。
- 底下一排是圣物、腰带、勋章。
- 人物模型站在中间。

| 腿 | 左列下 · 腿甲 | 88×112 | 2×3 |
| 头 | 上方正中 | 80×80 | 2×2 |

恐怖黎明有、本作没有的位置这样处理：

## 8. 待拍板

1. **8 槽怎么改装备系统**（用户已经定了槽位，下面是本案对数值的建议）。用户问“分开后每个装备的数值是不是就可以更保守了”。**可以，而且应该。** 总预算基本不变，分摊到各个部位：

   | 来源 | 现在 | 拆分后的建议 |
   |---|---|---|
   | 防具（`ARMOR_HP_PER_POWER` 1300、`DEF` 80） | 1 件全拿 | 胸 32%、腿 22%、头 18%、手 14%、脚 14%。五件加起来 100%，与现在的一件防具相同 |
   | 饰品（`TRINKET_MAIN_PER_POWER` 110） | 1 件全拿 | 项链 60%、戒指 40% |
   | 武器 | 1 件 | 不变 |
   | 随机词缀 | 3 件 × 按品质 1–3 条 | 8 件 × 同样条数，所以总条数约为现在的 2.7 倍。为让总量只比现在高约 20%，每条词缀的数值乘 0.45（武器的词缀不乘） |
   | 部位倾向 | 无 | 每个部位的词缀池偏向一类属性：手偏攻速和暴击；脚偏移速和体力；头偏法抗和技力；腿偏生命和闪避；胸偏生命和防御；戒指偏攻击和法攻；项链偏技能 |

   好处有两个。一是单件装备的数值变小，刷到一件好的不至于一下子翻倍，这和复利数值改造（`复利数值改造清单.md`）的方向一致。二是配装多了取舍。

   要动的东西：
   - 代码：`Item.Category` 拆成 8 个部位；`gear_catalog`、`prefix_catalog`、`special_gear`、`loot_tables`、`CombatStats.power_stats` 都要改。
   - 存档：旧档里的防具和饰品要迁移。
   - 美术：每个地区的头、手、腿、脚、戒指都要新底材图标。
   - 先例：特殊装备照旧占用普通槽，这条不变（`special_gear.gd`）。

   **这是装备系统的改造，比本案的界面改动大。** 建议另起一份“装备部位拆分案”，先定底材数量和数值，界面这边先按 8 槽做。

4. **开箱时 I 窗口右移、收起属性栏**（§4.3），还是保持现在“箱子顶掉属性栏”的做法？
