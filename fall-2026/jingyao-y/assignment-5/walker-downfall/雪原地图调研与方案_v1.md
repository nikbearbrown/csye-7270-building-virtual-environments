# 雪原地图调研与方案 v1（萨米·冻土林线）

2026-10-12。用户要求：「看雪图怎么做，恐怖黎明也有雪图，可供参考」。矿区已经有台地、光照、地形套件和兴趣点，本文把同一套框架用到雪原。

## 1. 调研

| 来源 | 要点 |
|---|---|
| 《恐怖黎明》霜幕高地（Fangs of Asterkarn，第 8 幕） | 积雪覆盖的山地；有瀑布，也有冰窟。库恩人营地以篝火为中心，旁边放着传送门。兴趣点有库恩祭坛（献祭打开宝箱）、被亵渎的神龛、巨鸟巢、废弃藏物点、地窖入口。评测提到：茂密森林过渡到冰封山口，废弃村落埋在深雪里，冰窟里有温泉的暖色区域。[官方 Wiki](https://grimdawn.miraheze.org/wiki/Frostveil_Highlands)、[评测](https://devplaymedia.com/2026/07/30/blood-in-the-snow-a-review-of-grim-dawn-fangs-of-asterkarn/) |
| 《暗黑破坏神 IV》碎峰岭 | 整体用冷冽的调色板，聚落用温暖的土色调，形成「喘息」的反差。建筑用当地松木板和桦木瓦。夜间用雾、柔和阴影和反弹光让光线变软。接近聚落时，沿途防御工事逐步增多，以此引导玩家。[Fextralife 转述季度更新](https://fextralife.com/diablo-iv-latest-quarterly-update-focuses-on-the-environmental-art/)、[ArtStation 涅韦斯克与针叶林](https://shong1123.artstation.com/projects/Za41g1) |
| 《明日方舟》萨米 | 北部是冰原和永久冻土；部族以「族树」为中心，精神领袖是雪祀；生活物件有林地炭火炉、北地屋舍取暖处。[萌娘百科：萨米](https://mobile.moegirl.org.cn/%E8%90%A8%E7%B1%B3(%E6%98%8E%E6%97%A5%E6%96%B9%E8%88%9F))、[B 站 Wiki：冬夜的护卫](https://wiki.biligame.com/arknights/%E2%80%9C%E5%86%AC%E5%A4%9C%E7%9A%84%E6%8A%A4%E5%8D%AB%E2%80%9D) |

归纳出四条原则：
1. **雪是一层覆盖，不是另一种地面**：朝上的面积雪，侧面露出岩石，地形的高差靠这种黑白对比来读。
2. **冷暖反差是主光**：环境光冷白偏蓝；火盆、营地是暖色的「喘息点」。目的地用冷光，与暖色区分开。
3. **人迹有引导性**：路标木柱、篝火营地沿路分布，越接近目的地越密。
4. **天气不能挡视线**：只下轻雪，不加暴风雪，也不加大面积雾。

## 2. 本轮实现

| 项 | 内容 |
|---|---|
| 雪覆盖 | 崖面和岩面着色器按法线朝上的程度混入积雪（`snow_cover` 参数，雪原为 1）；崖边、岩层台阶、岩顶都会积雪 |
| 光照 | 雪原环境光改为 (0.80, 0.86, 1.0)；房间放炭火盆，用暖光；深入入口放雪祀图腾，用冷光 |
| 沿路标记 | 萨米路标木柱：顶端挂兽角和布条，柱身挂一盏灯，沿通道一侧摆放 |
| 崖面点缀 | 崖脚放积雪堆和倒木；崖顶挂冰棱 |
| 兴趣点 | 「冰原营地」建模：帐篷、铺盖卷、木箱、熄灭的火堆 |
| 天气 | 飘雪粒子跟随镜头，密度低，雪片小 |

## 3. 待拍板
