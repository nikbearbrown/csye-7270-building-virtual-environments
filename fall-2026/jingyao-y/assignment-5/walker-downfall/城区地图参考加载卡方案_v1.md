# 城区地图参考加载卡方案 v1：龙门、叙拉古

2026-10-21。用户反馈：

> 两个城区地区剪影挺符合我脑海里对相应地图效果的，局内地图能不能参考

- **参考图**：Sol 的 UD 加载卡 `art/ui/key/load_city.png`、`load_siracusa.png`。
- **对照的现状**：`evidence/f4-city-entry.png`、`f4-siracusa-entry.png`，即场景渲染统一改造 S3 之后的画面。
- 本案只出方案，不改代码。

**能参考，但要先换算。**
- 加载卡是站在街上平视的画面，局内镜头是 50–70° 的俯视。
- 能直接搬过来的是三样：颜色和光、标志性的物件、街道的“压迫感”。
- 透视构图搬不过来。俯视下的“压迫感”只能靠楼更高、头顶有东西横跨街道、北侧的墙面露出来来做。

## 1. 龙门下城区

| | 加载卡里有的 | 现在的局内 | 改法 |
|---|---|---|---|
| 色调 | 冷蓝灰的湿冷夜，墙面压暗；暖色只出现在窗户、红灯笼和少量招牌上 | 地面很亮；粉紫色霓虹铺了大片；绿雨棚很抢眼 | 环境光改成冷蓝灰（ambient 约 0.62, 0.68, 0.82）；霓虹只留招牌本身发光，不再大面积染地；绿雨棚降低饱和度；地面加一层潮湿的反光（roughness 降低） |
| 楼 | 6–10 层的筒子楼贴着街排开，楼面上是密密的窗格，阳台、空调外机、晾衣竿 | 楼矮，从上往下看几乎只能看到屋顶 | 沿街的楼抬到 3–4 层视觉高度；朝南的立面能看到；立面上加一排排窗户，随机亮暖黄色；挂空调外机和晾衣竿 |
| 头顶横跨的东西 | 一座带歇山顶的**牌楼连廊**横跨街道；楼和楼之间拉满电线 | 没有 | 新模型：**牌楼连廊**，每张地图 1–2 座，横跨主街，它就是这张图的地标。另外每隔几栋楼拉一组电线束和晾衣绳；它们投下阴影，但不挡角色（照之前定的“不虚化，直接遮挡”，只有比角色高的东西才放在头顶） |
| 远景 | 雾里耸着上城区的高楼 | 没有 | 地图北缘以外放一排低多边形的高楼剪影，蒙一层雾，镜头抬到 50° 时能看到 |
| 光源 | 一扇扇窗户、红灯笼、零星的竖招牌 | 路灯的光池加大片霓虹 | 光源换成“窗光 + 灯笼”：红灯笼挂在门口和连廊下，暖色点光源，范围小；路灯减少 |

## 2. 叙拉古旧城区

| | 加载卡里有的 | 现在的局内 | 改法 |
|---|---|---|---|
| 时间和色调 | 黄昏转夜，天空冷灰蓝；墙是暖砂岩和灰泥；窗户透暖光 | 亮白的日光，屋顶是高饱和的橙红，石板路发亮 | 环境光压暗、偏冷（ambient 约 0.58, 0.62, 0.76）；屋顶瓦片改成褪色的陶土色，降低饱和度、加脏旧；石板路压暗一档 |
| 地标 | 一座方形**钟楼**，顶上有拱窗 | 没有 | 新模型：**钟楼**，每张地图 1 座，放在广场边上，是最高的建筑，远处也看得见。镜头转动时可以用它来认方向 |
| 街道 | **石拱门洞**从楼底下穿过去；街上空挂着一串串灯；晾衣绳；墙上爬着常春藤 | 楼与楼之间是开阔的空地 | 新模型：**拱门过街楼**，路从楼底下穿过，是一个短隧道，进去以后变暗。街道上空拉**串灯**，暖色小点光源，成串拉开；加晾衣绳；墙角种爬藤 |
| 楼 | 2–4 层的灰泥楼，石砌转角，小阳台上摆着盆栽 | 楼体是平的，看不出层次 | 立面加石砌转角、窗套和小阳台，阳台上加盆栽；楼高错落 |
| 远景 | 海湾、远处山城的剪影 | 没有 | 地图边缘以外放一片海和山城的剪影 |

## 3. 实现路径

和现有流程一致：

- **模型**：在 Blender 里通过 MCP 建，加进城区和叙拉古的地形套件，不用无头脚本。新模型有：
  - 龙门：牌楼连廊、电线束和晾衣绳、空调外机、远景高楼
  - 叙拉古：钟楼、拱门过街楼、串灯、爬藤、阳台
- **光照**：改 `world/field_light.gd` 里 `city` 和 `siracusa` 两套预设。窗光和灯笼走现有的点光源系统。
- **材质**：屋顶瓦片和地面压暗、降低饱和度，在现有贴图上调色即可。如果要重画，再出给 Sol 的需求。
- **对照验收**：改完后截同一个机位的图，和加载卡并排放在一张图里看。要比的是三件事：色调和氛围对不对，地标认不认得出，街道有没有“压迫感”。
