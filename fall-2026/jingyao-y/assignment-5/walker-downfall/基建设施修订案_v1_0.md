# 基建设施修订案 v1.0

2026-10-21 用户拍板：

- 取消罗德岛内的声望设定。
- 原来按声望 R1–R4 解锁的内容，全部改成基建玩法：升级相应设施后解锁。
- 基建升级项整合到同一个页面。

本案取代《基地玩法策划案_v1_0》§2 的声望与 R1–R4 解锁表（附录 A 里的声望阈值也作废）。交易所里各势力的"关系 R0–R5"不是声望，保持不变。

## 一、去掉的东西

- **数据**：`BaseState.prestige`、`BaseCatalog.PRESTIGE_RANKS`、`RANK_UNLOCKS`、`rank_of()`、`add_prestige()`、`unseen_unlocks`。
- **订单**：订单不再给声望，只给龙门币。
- **撤离**：撤离不再加声望（原来 +2）。
- **合同**：回收、搜索合同不再写"声望 +3"。
- **Boss**：首次击破 Boss 不再给声望。`boss_falls` 照旧记录击破。
- **叙拉古**：在叙拉古驻留伤员不再给声望。
- **界面**：
  - 顶栏、仓管台、出库区、科研部、交易所的声望标签都已删掉。
  - 出库区顶部的声望进度条删掉。
  - 大厅的"声望提升"横幅删掉。
  - 可露希尔商店的身份栏改成"商店 LvN"。

几条细则：

- **对应关系**：原来的 R*n* 门槛一律换成相应设施的 Lv*n*+1。这样新存档的节奏和原来一样。
- **货架、扩容、无人机**：它们本身的价格和材料不变，设施等级只管能不能建。
  - 货架：`RACK_LEVELS = [1,2,2,3,3,3,4,4,4]`。
  - 背包：`PACK_LEVELS = [1,2,3]`。
  - 安全袋：`SAFE_LEVELS = [1,3,4]`。
  - 无人机：仓储部 Lv2。
- **药剂与随队物资**：门槛写在各条目的 `"store"` 字段，表示需要的可露希尔商店等级。营地柜台也只从已解锁的特供里抽。
- **免费刷新订单**：仓储部 Lv4 才有。旧存档里的刷新次数，读档时也要满足这个等级才保留。
- **科研节点**：科研节点自己的基建前置不变，比如每区 3 个货架、无人机、营地升级、安全袋扩容二。

## 三、基建页面

页面名为"基建"（站点 `construction`，`BaseScreens.construction`）。

**入口**：
- 大厅右下角的快捷按钮新加"基建"，排在"合同""菜单"前面。
- 站点总览里加一行"基建"：显示"可升级 N"，有能买的项目时亮黄色"!"。
- 仓管台在买下总控面板之前，直接打开基建页。

**布局**：
- **左列：6 个设施条**。每条显示：
  - 设施名和"Lv 当前 / 最高"；
  - 下一级解锁什么；
  - 龙门币和材料，缺的材料标红；
  - 按钮：可以升级时显示"升级"，否则直接显示原因，比如"龙门币不足""缺少……"。
- **右列：项目**。依次是：
  - 仓库总控面板、搬运无人机；
  - 背包扩容、安全袋扩容、营地升级；
  - 武器、防具、饰品、材料四个区的货架（显示已建 / 9）。

**变动**：
- 仓管台去掉"升级"页签，只剩全部、武器、防具、饰品、材料。
- 各区地面框前面的"扩建货架"按钮保留，方便就地扩建。

页面只放数据和按钮，不写规则说明，见 `feedback-no-explanatory-ui`。

## 四、旧存档

没有 `facilities` 字段的存档，先按旧声望算出原来的 R 级，再把每个设施补到能打开原来那些内容的等级：

- 仓储部 = 1 + min(R, 3)；
- 整备部 = 1 + min(R, 3)；
- 商店 = 1 + R；
- 加工部：R ≥ 3 时为 Lv2；
- 科研部：R ≥ 4 时为 Lv2；R ≥ 2，或者已经有研究完成的，为 Lv1；
- 交易所 = 1 + R。

另外取已建内容所需等级的最大值：已建的货架、已买的无人机、已扩的背包和安全袋。这样老玩家不会丢掉已经解锁的东西。
