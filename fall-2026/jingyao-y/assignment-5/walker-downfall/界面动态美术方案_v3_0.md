# 界面动态美术方案 v3.0：陆行舰终端

2026-10-21。用户反馈：

> 我想要游戏 ui，那种动态的、带美术的、有主题的、有统一风格的

v2.0（`界面美术与布局策划案_v2_0.md`）里的布局、拆分清单（S1–S11）和 8 槽纸娃娃继续有效。本案只换掉它的“外观与动效”部分：v2 的原型仍是平面线框，读起来像网页。v3 要做成游戏界面：有原画、有材质、有动效、有一个贯穿全部界面的主题。

- **原型**：`art/ui_mockup_v3/index.html`，Artifact https://claude.ai/artifact/DwanKMpH8ZcBsTywz4JLzs
  - 共 9 个场景，流程可以连着点：标题 → 整备台 → 出发准备 → 行动开始 → 局内，局内按 I 或 C 打开窗口。
  - 本地查看：在该目录运行 `python -m http.server`。
- **给 Sol 的需求**：`art/_to_sol/UI_kit_brief_v1.md`（§4 是摘要）。

---

## 1. 主题：陆行舰终端

所有界面都是罗德岛号上某台终端的屏幕。玩家打开的是**舰上的设备**，不是网页。

主题靠三层东西撑起来，每个界面这三层都要有：

| 层 | 内容 | 来源 |
|---|---|---|
| **材质** | 面板底是 R1 舰板贴图压暗后的颜色；顶角贴一条 R4 警示条；标题和加载画面用 R9 荒野远景 | 基地 Sol 材质，已有 |
| **原画** | 干员立绘、NPC 立绘、标题主视觉、加载卡 | 现在先用 Sol 的待机图和 NPC 立绘占位；正式图见 §4 |
| **动效** | 打开时扫描线展开、标题字符解码、数字滚动、浮尘粒子、场景之间斜切过场 | 代码实现，见 §3 |

**统一的规则**：

- 每个面板都有同一套部件：舱壁切角、受光边、四角的全息青角标、左上角的警示条、标题栏下的发光细线、右上角的设备序号（如 `RI-PRTS / 0047`）。
- 部门之间靠**主色和标志物**区分，不另换一套风格：
  - 舰桥：全息青
  - 后勤：蓝
  - 可露希尔：霓虹粉，挂一块 OPEN 灯牌
  - 医疗：白舱加青绿十字
- 每个干员有一个代表色，用在立绘背后的一团静态柔光和底部色条上。拉普兰德是技力黄。
- 屏幕最上层压一层 3 px 扫描线（透明度 2.5%），统一成“显示器”的质感。

## 2. 每个场景的美术与动效

| 场景 | 美术 | 动效 |
|---|---|---|
| 标题 | R9 荒野远景，慢慢平移；右侧是罗德岛标志 | “DOWNFALL”字符解码；底部坐标和时间实时跳动；“开始唤醒”按钮上斜纹流动，箭头左右摆动 |
| 整备台 | 背景是建模后的加工区实景，模糊并压暗；纸娃娃中间立着干员像，脚下一圈淡淡的地面阴影 | 三块面板依次扫描展开；立像静止；悬停装备时，四角角标收拢，并弹出对比卡 |
| 出发准备 | 背景是舰桥实景；两栏：干员头像排、装备和背包 \| 部署目标 | “开始行动”按钮的效果同标题按钮 |
| 行动开始 | 黑底，蓝色上下两条光带 | 光带横向展开；“行动开始”四个字解码；层编号牌从右侧滑入；进度条走满后自动进入局内 |
| 局内 HUD | 战场画面 | 顶栏从左边滑入，小地图从右边滑入；小地图上有雷达扫描；伤害数字弹出（暴击用黄色大字）；剑气格蓄满后发光 |
| I 装备·背包 | 同整备台 | 窗口打开时，一道发光扫描线从上往下扫过，经过的地方亮一下；数值从 0 滚到实际值 |
| C 干员 | 左栏是大立绘，背后一团干员色的静态柔光，背后是干员英文名的巨大描边字（本作不分职业和星级，用户 2026-10-21） | 同上 |
| 可露希尔商店 | 舰板底叠暖粉色调；霓虹 OPEN 灯牌；可露希尔立绘；货架卡顶上一条粉色灯带 | 灯牌闪烁；货架卡依次升起；悬停时价签歪一下，货架卡外框亮起粉光 |
| 药房（白舱） | R3 医疗舰板贴图提亮；白色药剂卡；青绿十字 | 药剂卡依次升起 |

**场景之间的过场**：左边一块带黄边、右边一块带青边的黑色斜切板，同时向中间合拢；合拢后中间显示罗德岛标志，换场景，然后两块板向两边拉开，共约 0.9 秒。局内的 I、C 窗口开关不走这个过场，直接扫描展开。

**减少动效**：设置 → 界面里加一项“界面动效：完整 / 精简”。系统选“减少动态效果”时自动用精简：只保留扫描展开，并缩短到 0.15 秒。

## 3. Godot 实现方案

| 效果 | 做法 |
|---|---|
| 面板底板 | `NinePatchRect`。Sol 交九宫格之前，先用 `StyleBoxTexture`，贴 R1 舰板并用 `modulate` 压暗；切角用 `ui_chamfer.gdshader` 按 UV 裁掉 |
| 受光边、角标、警示条、标题细线 | 面板组件 `ui/components/terminal_panel.gd` 在 `_draw()` 里画；警示条用 R4 贴图 |
| 扫描展开 | `ui_reveal.gdshader`：`uniform float progress`，裁掉 progress 线以下的部分，线上那一行加亮并发光；用 Tween 在 0.5 秒内把 progress 从 0 推到 1，曲线用 `EASE_OUT`、`TRANS_EXPO` |
| 背景全息（旋转全息环、R6 屏幕纹理滚动、全息台呼吸光、标志闪烁、立绘发光描边） | **全部删掉**（用户 2026-10-21：“背景全息效果太廉价了，要么优化要么删掉”）。立绘背后只留一团静态的径向柔光，颜色取干员色或部门色，透明度不超过 16%。Sol 交的 `holo_ring_*.png` 不再使用 |
| 字符解码 | `DecodeLabel`（继承 Label）：每帧随机替换还没“解开”的字，共 0.3–0.5 秒 |
| 数字滚动 | Tween 驱动 `display_value`，0.7 秒，`EASE_OUT`、`TRANS_CUBIC` |
| 浮尘粒子 | `GPUParticles2D` 放在 UI 的 CanvasLayer 里，70 颗，其中 30% 是全息青色 |
| 斜切过场 | 常驻的 `TransitionLayer`（CanvasLayer 100），两个 `Polygon2D` 用 Tween 合拢和拉开；`GameManager.change_screen()` 统一走这里 |
| 伤害数字 | 沿用现有 HUD 的飘字；暴击改成黄色、放大 1.3 倍，弹出时有一个过冲 |
| 立绘 | **不加任何动态效果**（用户 2026-10-21：“不要立绘的动态效果”）：不浮动、不滑入、不缩放，静止显示 |

性能：所有着色器都是全屏以下的小面积。粒子在暂停时照常跑，因为 UI 层的 `process_mode` 设成 `ALWAYS`。

测试：
- 截图测试要等动效结束，或者在测试时把“界面动效”设成精简（`test_ui_v1` 等会受影响）。
- 新增 `test_ui_motion`：检查打开窗口 0.6 秒后，`progress` 等于 1；过场结束后，`TransitionLayer` 不再挡住点击。

## 4. 需要 Sol 出的美术

完整需求在 `art/_to_sol/UI_kit_brief_v1.md`，下面是摘要。所有角色类都照“新角色先出原画”的流程：先交粗描边平涂原画，通过后再出游戏用的尺寸。

| 批次 | 内容 | 用在 |
|---|---|---|
| **UA** 干员立绘 | 9 名可出战干员，正常人体比例（不是 Q 版）的全身像素画，原生尺寸 120×240；纸娃娃里按 1 倍显示，C 窗口里按 2 倍显示，头像从同一张图裁；透明底；每人一个代表色（用户 2026-10-21：“干员、npc立绘可以用正常比例的像素画”） | C 干员、纸娃娃中间、出发准备和整备台的头像、人事部 |
| **UB** NPC 立绘 | 可露希尔、坎诺特、罗德岛小队，同 UA 的规格；罗德岛小队只画一名不具名的罗德岛干员（用户 2026-10-21）；另加 4 名局内地区游商，即势力据点的商人：鼠王的下城区、整合运动残党、乌萨斯西北矿场、萨米林地部族 | 商店、账房、坎诺特、小队事件、势力据点 |
| **UC** 终端界面件 | 面板九宫格（舰板、玻璃两种）、标题栏板、按钮四态、装备槽框、提示卡框、全息环三件套、8 张部位剪影、6 个部门标识 | 所有界面 |
| **UD** 主视觉 | 标题画面一张（罗德岛号在荒野上行驶，1280×720 像素画）；加载卡 4 张（每个地区一张） | 标题、行动开始 |
| **UE** HUD 小图标 | 菜单键（装备、干员、藏品、地图、合同）、货币（龙门币、赤金）、污染图标 | HUD、货币牌 |

**交付前**：先用代码画的版本和现有占位图把整个系统做出来，原型就是这么做的。交付后直接替换贴图，布局和动效都不用动。

## 5. 分期（接在 v2 §9 之后）

| 期 | 内容 |
|---|---|
| M1 | `TerminalPanel` 组件、扫描展开、`TransitionLayer`、`DecodeLabel`、数字滚动；所有现有窗口改用 `TerminalPanel` |
| M2 | 浮尘粒子；标题和行动开始过场。不做背景全息。不做任何流光、扫光（用户 2026-10-21：“不要流光效果”） |
| M3 | 局内 HUD 的动效（顶栏和小地图滑入、雷达、暴击数字） |
| M4 | 接入 Sol 的 UC、UE；然后是 UA、UB、UD（角色先过原画） |

v2 的 V1–V6（拆分和布局）与 M1–M4 可以交叉做：每拆完一个界面，就直接用 `TerminalPanel` 来做。


## 6. 实现记录（2026-10-21，M1 + V1 外壳）

用户：“写完策划案开始实现 ui 的代码”。

**已做**

- **`ui/terminal.gd`**（新增 `Terminal`），提供下面这些部件：
  - `panel_style("plate"|"glass")`：用 Sol 的 UC 九宫格，边距 16，中间平铺，最近邻采样。
  - `frame()`：四角的全息青角标，顶边外侧一截 R4 警示条，标题栏下面一条发光线。
  - `reveal()`：扫描线展开。一块深色幕布从上往下收起，前沿有一道亮线，用时 0.5 秒。
  - `type_in()`：标题逐字出现。改的是 `visible_ratio`，文本本身一直完整，所以测试照样能读到。
  - `wipe()` / `wipe_open()`：斜切过场。左黄、右青两块斜板，合拢时中间显示罗德岛标志。
  - 以上效果都画在最上层，鼠标穿透，所以动画进行中点击和动画结束后完全一样。
- **色板**（`ui/ak.gd`）：中性黑整体换成舰板蓝灰，新增 `HOLO` 和 `HAZARD`。`ui/*.gd` 里写死的 35 处中性灰按同样的亮度换成蓝灰。
- **基地站点外壳**（`BaseScreens.shell`）：
  - 背景铺一层压暗的 R1 舰板。
  - 标题栏左边加部门色竖块，标题栏下面加部门色发光线。
  - 底栏放罗德岛标志和“RHODES ISLAND · 部门英文名”。
  - 部门色由 `Terminal.STATION_DEPT` 决定。
- **扫描展开的时机**：新打开一个屏幕时才播（`FieldMenu.stage_begin` 按屏幕和站点记一个键），同一屏幕内重建（点击、切页签）不再播。从战场打开站点时先播 `wipe_open`。
- **局内窗口**：干员 · 背包窗、藏品 R、合同 J 换成 Sol 的舰板九宫格，并加上 `frame`。新打开时播扫描展开。玻璃面板会透出下面的快捷栏，所以局内窗口都改用不透明的舰板。
- **设置**：设置 → 界面里新增“界面动效：精简 / 完整”，存在 `ui_motion`，选精简时上面所有动效都不播。i18n 用 overrides 加 extract 加 merge 补齐，`test_i18n` 通过。
- **截图脚本**：`tests/capture_gui.gd` 截图时关掉动效，截的是静止画面。

**测试**：`run_all -Jobs 12` 共 54 套，其中 51 套通过。另外 3 套（`test_combat`、`test_v1`、`test_heal_orbs`）单独重跑都通过，判断是并行负载下的偶发失败（跑测试时同时在截图）。

**还没做**（照 v2 §9、v3 §5 的分期）：
- 拆分 S1–S11。其中 I 和 C 拆开、整备台四个界面、可露希尔拆分、塔科夫式商人三栏都还没做。
- 8 槽纸娃娃：要先改装备系统。
- 数字滚动：怕影响测试读数，暂时没做。
- 浮尘粒子和局内 HUD 的动效（M2、M3）。
