# 交易所交易包修订案 v1.0：大类交易包、散件代售、装备装包

2026-10-23 · 用户提出：交易所只做大类交易，买卖的都是打包好的交易包；包可以换成具体物品；加工部负责把散件打成包、用于交割。另外在可露希尔页面上加各地散件交易，可露希尔和各地商店也卖装备。

本案修订 `势力与交易所策划案_v0_7.md`（下称 v0.7）。没提到的部分照 v0.7 不变。

## 1. 三层市场

| 市场 | 在哪 | 交易什么 | 计价 | 盯盘 |
|---|---|---|---|---|
| **交易所**（喀兰贸易终端） | 舰桥大厅工位；营地只能换汇和交割 | 标准交易包 × 9 家势力：现货、挂单、远期、差价合约 | 势力的计价货币 | 有 K 线和快讯 |
| **散件市场**（可露希尔代售） | 可露希尔页面的"代售"页，基地和营地都有 | 罗德岛当前锚地的散件、特产和当地装备 | 龙门用龙门币，其余用赤金 | 只有当前价，没有 K 线 |
| **势力据点** | 局内兴趣点 | 照 v0.7 §12；另外也收该势力爱收的包 | 势力的计价货币 | 没有 |

三层之间的关系：散件价格跟着交易所里对应包的指数走（§5.2），所以三者是连动的。加工部的打包和拆包就是三层之间的桥：在局内捡到散件，可以在散件市场直接卖掉，也可以打成包拿到交易所卖，或者用来交割。两条路哪条更赚，要看当时的行情。

## 2. 标准交易包

### 2.1 包的种类（12 种；作物包 2026-10-23 加）

一个大类对应一种包。v0.7 的"贸易品"类取消，原来的 4 种补给箱并入对应的包（§7.3）。

| 包 | 大类 | 面值（点） | 可拆 | 说明 |
|---|---|---|---|---|
| 源石包 | originium | 120 | 是 | |
| 医疗包 | medical | 100 | 是 | 食堂补给也算医疗类，可以装，但拆包清单里没有它们 |
| 作物包 | crop | 100 | **否** | 用户 2026-10-23：农业部作物单列。只有龙门商会 0.90、莱茵生命 0.90、鼠王 0.95 在终端收，没人卖；到手每点约 79–82，和直接交付（80）相当 |
| 建材包 | build | 100 | 是 | |
| 电子包 | electronic | 120 | 是 | |
| 燃料包 | fuel | 100 | 是 | |
| 寒地物资包 | cold | 100 | 是 | |
| 养成材料包 | elite | 300 | 是 | T1–T5 精英材料都按价值算，高阶材料几件就能装满 |
| 违禁品包 | contraband | 200 | **否**（§11 第 2 条） | 只有鼠王的下城区和整合运动残党收 |
| 武器包 | weapon | 400 | **否** | §3.3 |
| 防具包 | armor | 400 | **否** | §3.3 |
| 饰品包 | trinket | 400 | **否** | §3.3 |

- **点** = `Item.value`。1 点对应 100 龙门币的交付价（`Economy.LMD_PER_VALUE`），所以建材包的基准价就是 4000 龙门币。
- 面值是初值，按 §9 的模拟再调。
- **物品形态**：2×2，可以叠放，堆叠上限 5。放进背包时占格子；仓库货架按数量计。
- 包没有品质和前缀，同一种包完全一样。这是它能在交易所里标准化交易的前提。

### 2.2 包的价格

v0.7 §4 的公式不变，只是把"基准价"换成包的基准价：

```
包基准价 = 面值 × 100 龙门币           （赤金势力 ÷ 1000，同 v0.7 §4）
卖出价 = 包基准价 × 势力偏好 × 包的行情指数 × 卖压 × (1 − 手续费)
买入价 = 包基准价 × 势力偏好 × 包的行情指数 × (1 + 价差)
```

行情指数原来就是按"势力 × 大类"维护的（`MarketState`），所以价格模型基本不用动。区别是现在每个盘口只有一种标的。

## 3. 打包（加工部）

### 3.1 规则

- 在加工部的"打包"页，选一种包，再从仓库里选本类的散件装进去。
- 装入的散件**价值累计 ≥ 面值**，就可以打成一包。
- **超出面值的部分作废**，不找零。所以要凑得刚好，才不浪费。
- 每包收 100 龙门币，耗时 1 分钟（现实时间），走加工部队列（v0.7 §2）。做好后进暂存区。
- 一次可以连打多包：系统按选中顺序依次凑满，最后不够一包的散件留在原处。

### 3.2 能装什么

- 本大类的所有散件都能装，**包括各地特产**，例如未封装源石原矿可以装进违禁品包，冻土旧物可以装进寒地物资包。
- **势力特供**（`source == "special"`）不能装：它们本来就不进市场。
- 赤金和药剂不能装。

### 3.3 装备包（单向）

- 武器、防具、饰品各自装包，按装备的 `Item.value` 累计。`value` 已经算进了品质、前缀和数值波动（`PrefixCatalog`），所以好装备一件就能顶好几件差装备。
- 不能装的装备：
  - 正穿在身上的；
  - 投保中的（保全系统，见保全系统修订）；
  - 锁定的。
- 套装和 Boss 装备可以装，也按价值算。
- **装备包不能拆**，也不能换回装备。它只能：
  - 卖给爱收这一类的势力；
  - 交割远期合约。
- 交易所上**没有**装备包的买入盘口（`SELL_ONLY` 改为三种装备包和违禁品包）。只能做"交货合约"，不能做"收货合约"。差价合约不涉及实物，照常可以做。

装备包的意义：局内捡到大量用不上的装备，原来只能逐件按 0.8 倍交付价回收，或者卖给坎诺特。现在可以攒够价值打包，在行情好的时候卖给卡西米尔或喀兰。

### 3.4 一键打包（快捷键）

- 新按键 **"一键打包（基地）"**，默认 **P**，可在按键设置里改（`Keybinds`，分组"界面"）。
- 在基地的仓库界面按下，会弹出一个小窗（加工部打包页的右栏已经有同样的表单，所以那里按 P 不弹窗，用户 2026-10-23）：
  - **包的种类**：默认选中鼠标指着的物品所属的那一类；没指着物品时，默认选上次用过的那一类。可以在小窗里改。
  - **几个包**：用 − / + 和滑条选 1 到"最多能打几包"，旁边有"全部"按钮。"最多能打几包"按仓库里本类可装的散件总价值算。
  - 显示：会用掉几件散件、溢出几点、要付多少龙门币。
  - 按"打包"或回车确认，Esc 取消。
- **自动挑货**：
  - 只挑 §3.2 允许装的东西。锁定的、投保中的、正穿在身上的、势力特供，都不会被挑中。
  - 从价值低的挑起，每一包都尽量凑得刚好：凑到快满时，从剩下的散件里找一件能刚好补满、溢出最少的放进去。
  - **装备包另有限制**：一键打包不挑最高一档的装备，也不挑套装和 Boss 装备。这些装备只能在打包页里手动放进去，防止一按就把好东西打进单向的包。
- 确认后，这些包排进加工部队列（每包 100 龙门币、1 分钟，和手动打包一样）。龙门币不够时，"打包"按钮灰掉，按钮上显示"龙门币不足"。
- 打包页里手动挑货的方式照旧保留。

## 4. 拆包（自选）

- 地点：**基地仓储部总控台**，新增"拆包"页。局内不能拆包。
- 选一个包，界面列出本类可选的散件和每件的点数，玩家用 + / − 自选，点数用完为止。
- **每件的点数 = `Item.value` × 1.1**。多出的 10% 是拆包损耗，这样"打包再拆包"不能刷钱：一来一回至少亏 10%，再加上打包费。
- **拆包清单不包括**：各地特产、势力特供、作物和食堂补给、装备。特产只能在当地的散件市场买到（§5）。
- **余点**：选不满时，剩下的点数留在这一类的"余点"里，下次拆同类包时自动并入。余点只显示一个数字。
- 拆出来的物品进暂存区。

## 5. 散件市场（委托可露希尔代售）

### 5.1 位置和设定

- 可露希尔页面的页签增加 **"代售"**：
  - 基地：商店、**代售**、出售赤金、换汇、贷款、随队物资；
  - 营地：商店、**代售**、寄存、出售赤金、换汇、交割、补给、处理。
- 代售页沿用 `TraderScreen` 的三栏：左边是可露希尔，中间是货架，右边是背包。
- **开哪个地区的市场，看罗德岛号停在哪里**（`VoyageState.docked_at()`，沙盘航行 §2 的 7 个锚地）。不能切换地区；想买别处的东西，就要先航行过去。
- **航行途中基地不开**：代售页签灰掉，标"航行中"。
- **营地开当前地图的市场**（用户 2026-10-23 第四轮）：营地的代售页开的是当前地图对应的锚地（坍塌矿区 → 切尔诺伯格，龙门城区 → 龙门，冻土林线 → 萨米，沃尔西尼旧城区 → 叙拉古），和罗德岛停在哪里无关，航行中也开。
- 设定：可露希尔替罗德岛在停靠地找人买卖。所以人像始终是可露希尔，左栏的身份标签写锚地，例如"代售 · 萨米"。
- **即时成交**，收**代售佣金 6%**。佣金随商店等级下降，最低 3%。
- 在基地买到的货进收货区；在营地买到的货直接进背包。

### 5.2 价格

```
散件卖出价 = 基准价 × 地区偏好 × 对应包的综合指数 × (1 − 佣金)
散件买入价 = 基准价 × 地区偏好 × 对应包的综合指数 × (1 + 价差 + 佣金)
```

- **综合指数**：锚地境内的势力（`VoyageCatalog.ANCHOR_FACTIONS`）里，收这一类的那几家的包指数，按盘口深度加权平均。境内没有人收这一类时（例如叙拉古境内没有交易所势力），改用全部势力的加权平均。散件价格因此会跟着交易所的包价一起涨跌，但波动更平缓。
- **地区偏好**：本地特产便宜卖、外地货贵；每个锚地对各大类的偏好表另附（§10 第 1 条）。
- **价差**：龙门 4%，切尔诺伯格 8%，萨米 8%（照 v0.7 的以物易物价差），叙拉古 6%，哥伦比亚 4%，谢拉格 5%，卡西米尔 3%。
- **计价**：龙门用龙门币，其余六地用赤金。在营地交易时用背包里的赤金，取整规则同 v0.7 2026-10-18 的规定（买入向上取整，卖出向下取整）。在基地交易时用赤金账户。
- 卖出不计入交易所的卖压。

### 5.3 货架

每个锚地的货架分三块：

| 内容 | 来源 | 补货 |
|---|---|---|
| **散件** | 境内势力的货单（v0.7 各势力"卖什么"的材料清单，本案 §6 从交易所移过来）；有地图的锚地再加上该地图掉落表里的常见材料 | 每个现实小时补货，存量有限 |
| **特产** | 当地独有的物品：切尔诺伯格是未封装源石原矿，龙门是近卫局暴动盾，萨米是冻土旧物和林地草药，叙拉古是萨卢佐家族的旧徽记；哥伦比亚、谢拉格、卡西米尔用境内势力货单里的特色物品（例如卡西米尔的骑士工坊专利授权） | 每个现实小时补 1–2 件 |
| **装备** | **只卖当地的装备**：该地图的区域装备（区域装备策划案：四区近战、远程、法杖） | 每个现实小时刷新 3–6 件 |

锚地和地图的对应：切尔诺伯格 → 坍塌矿区，龙门 → 龙门城区，萨米 → 冻土林线，叙拉古 → 沃尔西尼旧城区。**哥伦比亚、谢拉格、卡西米尔没有地图，也就没有当地装备，所以不卖装备**（§10 第 3 条）。

**可露希尔自己的"商店"页不卖装备**，只卖药剂，和现在一样。

**装备上架的规则**：

- 等级跟着掉落阶梯：按玩家在该地图到过的最深层取档（掉落系统 2026-10-18 的阶梯，只升不降）。没下过这张地图的，按最浅一档。
- 品质**不出最高一档**（五档色的最高档只能靠掉落和 Boss 得到）。前缀照常随机。
- 价格 = 交付价 × 2.5。这样商店里的装备明显贵过回收价，买装备是补缺用的，不能代替下地。
- 收回装备照常：按装备的出售价，扣佣金。

### 5.4 收什么

- 收所有能进市场的散件、特产和装备。
- **不收包**：包要到交易所去卖。
- 势力特供、药剂、赤金不收。（赤金走"出售赤金"页。）

## 6. 交易所的改动

| 项 | v0.7 | 本案 |
|---|---|---|
| 行情列表 | "商品 @ 势力" | "**包 @ 势力**"。第一行仍是龙门币 / 赤金。页签不变 |
| 现货 | 买卖具体材料 | 买卖包。买到的包进收货区 |
| 挂单 | 按材料 | 按包 |
| 远期合约 | 交割具体材料 | 交割包。装备包和违禁品包只能做交货合约 |
| 差价合约 | 标的为材料价 | 标的为包的指数 |
| 限时收购 / 抛售 | 按类别 | 不变（原来就是按类别），成交单位改为包 |
| 势力"卖什么" | 具体材料清单 | 改为卖哪几种包。原来的材料清单移到局内据点和散件市场 |
| 企鹅物流 | 运材料 | 运包 |
| 买入额度、价差、手续费、杠杆、违约 | — | 全部不变 |

**事件和事件网不用改**：事件本来就是按势力和类别作用的。只有标题里点名了某种具体材料的事件，例如"限时高价收购冻土旧物"，改为作用于对应的包（寒地物资包），标题不变。

## 7. 和现有系统的关系

### 7.1 不变的

- **直接交付**：保留，0.8 倍交付价，龙门币。散件、装备都可以直接交付。包不能直接交付。
- **订单**、**加工部订单**、**大宗订单**（沙盘航行）：不变。大宗订单的货箱是另一套东西，和交易包无关。
- **坎诺特**：不变。
- **势力据点**：照旧卖散件、收散件，另外收该势力爱收的包。

### 7.2 改动的

- **加工部**：v0.7 §2.2 的四种固定配方取消，改为 §3 的按价值打包。
- **仓储部**：总控台增加"拆包"页（§4）。
- **可露希尔**：增加"代售"页（§5），按罗德岛所在锚地开市场；"商店"页不变。
- **沙盘航行**：航行多了一个理由，就是去别处买当地的特产和装备。

### 7.3 旧存档迁移

读档时处理一次：

| 旧东西 | 怎么处理 |
|---|---|
| 工业补给箱 / 电子元件箱 / 野外生活包 / 医疗补给箱 | 分别换成建材包 / 电子包 / 寒地物资包 / 医疗包，各 1 个 |
| 未平仓的材料远期合约 | 按当前价平仓：退还保证金，结清浮动盈亏，不扣关系，不算违约 |
| 未平仓的材料差价合约 | 同上，按当前价平仓 |
| 未成交的材料挂单 | 撤单，退还挂单费 |
| 自选列表里的材料 | 换成对应的包，去重 |

### 和正文的差别

1. **面值调高**：材料单价是 ★1 4 点、★2 8 点、★3 18 点，§2.1 的初值太小（一个建材包只要 5 个螺栓）。现在是：建材、医疗、燃料、寒地物资 100，源石、电子 120，养成材料 300，违禁品 200，武器、防具、饰品 400。
2. **违禁品包不能拆**：违禁品类里只有特产（未封装源石原矿），而特产不在拆包清单里，所以拆了也没东西可选。
3. **没有"锁定"**：游戏里没有锁定物品的功能，所以 §3.2、§3.4 的"锁定的不挑"不适用。
4. **一键挑货更省**：每一包都用动态规划找溢出最小的组合，便宜的优先；不是正文写的"凑到快满再补一件"。测试里和穷举最优解对比，误差为 0。
5. **"最多能打几包"**按可装总价值 ÷ 面值算。实际挑货时如果凑不出这么多包，就只打凑得出的那几包。
6. **基地代售买到的东西进背包**（三栏界面是拖进背包的），背包满了才进收货区。
7. **特产**：有地图的锚地是当地的专属物品；哥伦比亚、谢拉格、卡西米尔是当地势力的势力特供，要够关系才能买，价格是该势力的买入价加佣金。
8. **补货**：每个现实小时整架刷新。
9. **商店装备的等级**按该地图到过的最深营地取档（没去过按第 1 层）。
10. 特产格子没有单独描边；整页的强调色换成地区颜色。
11. 旧存档里大宗订单的货单如果写的是旧补给箱，不迁移（之后的新订单不会再出现补给箱和包）。
12. 违禁品包不继承"脏"：污染只在局内，而包主要在基地流转，所以这一条暂时没做。
