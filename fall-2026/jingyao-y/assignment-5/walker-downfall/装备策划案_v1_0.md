## 1. 现状与问题

- 每个地区每个槽位只有一个名字（矿区=矿工护甲、防尘面罩……），外加 6 个敌人专属武器名。同一地区刷十件防具，名字全一样，区别只在词缀。
- 同名装备之间没有底子上的差别，玩家没有理由偏好"某一种刀"。
- 物品在背包里是带稀有度边框的文字按钮，没有图标；地面掉落是程序生成的球、箱子几何体。

目标：每个地区每个槽位有 **4–5 种底材**，靠**固有词条**和**战力系数**区分手感；底材分浅 / 中 / 深三层，随深度解锁；每种底材一张像素图标。

## 2. 底材规则

### 2.1 底材 = 名称 + 层级 + 战力系数 + 固有词条

```
最终战力 = 现有战力公式 × 底材系数
词条     = 固有词条（底材自带，不随品质变化，不占词缀条数）
         + 随机词缀（数量照旧由品质决定，池子照旧按槽位）
```

- **固有词条**数值约等于同词条Ⅰ档随机词缀的一半，只用现有 `ItemModifier.Stat`，不新增属性：

| 固有词条 | 数值 | | 固有词条 | 数值 |
|---|---|---|---|---|
| 攻击力 | +4% | | 生命上限 | +4% |
| 攻击速度 | +5% | | 防御 | +20 |
| 暴击率 | +3% | | 法术抗性 | +4 |
| 暴击伤害 | +10% | | 法术攻击力 | +5% |
| 移动速度 | +4% / −4%（重型代价） | | | |

- 固有词条可以和随机词缀同属性，**叠加**，不重掷。
- 提示栏里固有词条放在基础属性下、随机词缀上，灰白色、无档位标记，前面加"固有"二字。
- **底材系数**：浅层 0.95–1.00，中层 1.05，深层 1.10–1.15。深层底材往往带一个代价（移速 −4%）。

### 2.2 层级与深度

| 层级 | 最早出现 | 说明 |
|---|---|---|
| 浅 | 第 1 区段 | 敌人随身装备、地区常见货 |
| 中 | 第 3 区段 | 与Ⅲ档词缀同时开放（掉落案 §5），第一个固定撤离段开始见到 |
| 深 | 第 5 区段 | 第二个撤离段前；精英、密室、守卫兴趣点可提前 2 区段出 |

抽取：符合深度的底材里，**最高一层权重 2，其余各层权重 1**，越往深越常见新底材，旧底材也不会消失。

### 2.3 来源映射（替换 `_gear_name`）

| 来源 | 武器 | 防具 / 饰品 |
|---|---|---|
| 普通敌人 | **自己的随身武器**（沿用 `ENEMY_WEAPON`），没有时抽地区表 | 抽地区表 |
| 精英 | 本地区**深层**武器（取代所有地区统一掉镐柄战刃） | 抽地区表，深层权重 ×2 |
| 武器箱 / 护具箱 / 工具箱 | 抽地区表 | 抽地区表 |
| 密室 | 抽地区表，只抽中、深层 | 同左 |

- 名称一律"品质 · 底材名"（如"精良 · 纠察队佩刀"），不加随机前后缀。
- 敌人随身武器（改 `ENEMY_WEAPON`）：暴徒→改装砍刀，弩手、弩手组长→制式短刀，打手→指刃，冰原战士→破冰刀，冰原猎人→猎刀，源石虫不掉武器；精英按上表。远程形制进池后，弩手→整合运动手弩，弩手组长→组长连弩，冰原猎人→冰原猎铳（§2.4）。
- 存档兼容：旧装备没有 `base_id` 时按名称回填；旧名"镐柄战刃"映射到"断镐战斧"，旧名"冰原猎刀"映射到"角柄猎刀"（§4.3，避免和敌人掉的"猎刀"同名），旧名"外勤战刃 / 防护甲胄 / 战术挂饰"映射到各地区浅层基准底材。

### 2.4 角色与武器的分工（用户 2026-10-04 拍板：剑气归角色，远程先不进池）

**角色决定"怎么打"，武器决定"打出来附带什么"。** 两层叠加，互不替换。

| 层 | 管什么 | 拉普兰德 |
|---|---|---|
| 角色 | 普攻动作与打法、**招牌机制**、攻击特效的主体；可用的武器形制由职业决定 | 近卫：双刀三段连斩；招牌＝**剑气**（命中 3 次蓄满，下一刀放出穿透剑气，角色自带）；可用形制 刃 / 重 / 拳 |
| 武器 | ① 形制：在角色动作上调参数；② 特殊效果：挂在通用触发点上；③ 特效：只在角色特效上叠一层颜色、拖尾或粒子，不改形状 | — |

**通用触发点**：命中时、击杀时、闪避时、受击时、**招牌发动时**、**空闲时**（连续 N 秒未攻击或未受伤；2026-10-11 用户拍板新增，见 `装备扩充策划案_v1_0.md` §1）。特殊装备的效果都写成"某触发点 + 效果"，任何角色都能用。例如月下刃写成"招牌发动时，暴击则追加一次 50% 招牌"，在拉普兰德身上就是追加一道剑气。

**形制**（基准：刃、攻击间隔 0.7 秒、ATK 600）

| 形制 | 职业 | 本案底材 | 间隔 | 单次伤害 | 范围 | 状态 |
|---|---|---|---|---|---|---|
| 刃 | 近卫 | 各种刀、佩刀、环首刀 | ×1.0 | ×1.0 | ×1.0 | 进池 |
| 重 | 近卫、重装 | 断镐战斧 | ×1.3 | ×1.35 | ×1.2 | 进池 |
| 拳 | 近卫 | 指刃 | ×0.75 | ×0.8 | ×0.8 | 进池 |
| 弩 | 狙击 | 整合运动手弩、组长连弩 | ×1.4 | ×1.3 | 射程约 10 | **暂不进池** |
| 铳 | 狙击 | 冰原猎铳 | ×1.8 | ×1.9 | 射程约 14 | **暂不进池** |

- 角色装不上本职业以外的形制。拖到装备槽时显示红色，提示"拉普兰德无法使用"。
- 弩、铳的底材、名称、图标设计都保留在 §4 表里，等以后出现狙击干员再进池。进池前**不出图**。
- 剑气是角色的东西，所以普通武器上原来"剑气（精良以上 25%）"那条词缀改成**"剑气强化：剑气伤害 +25%"**，出现条件不变。特殊装备里三把剑气武器去掉"剑气"这一条，只保留各自的追加效果（局内构筑案 §10.7 同步修改）。

## 6. 美术规范

### 6.1 尺寸（v1.1 修订：原生分辨率翻倍，1:1 显示）

> v1.0 定的"每格 18 像素、2× 放大"太粗：刀身只剩 4–6 像素高，饰品只有十来个像素，画不出材质和形状。E 批 v1 的问题一半出在这里（见 §6.6）。

背包格 `CELL = 40`，物品格是 `w×40−2` 见方、2 像素稀有度边框，内部每格约 36 像素。图标按**每格 36 原生像素**画，**1:1 显示**，不放大。

| 类型 | 格子 | 原生画布 | 主体最小占比 |
|---|---|---|---|
| 武器 | 2×1 | 72×32 | 宽 ≥ 90%，刃身最厚处 ≥ 8 像素 |
| 防具 | 2×2 | 72×72 | 宽、高都 ≥ 85% |
| 饰品 | 1×1 | 32×32 | 宽或高 ≥ 85% |
| 未封装源石原矿 | 1×2 | 32×72 | 高 ≥ 90% |

装备槽（左侧人物栏）复用同一张图。§5 表里的画布尺寸同样按此翻倍。

### 6.2 画法（v1.1 修订）

1. **必须是画出来的**：由出图模型绘制，再按色板量化到原生尺寸。**不接受用代码拼多边形、直线生成图标**（E 批 v1 就是脚本生成的）。脚本只用于缩放、量化、校验和拼接预览。源图的细节超过画布容量时（如 32 像素宽的未封装源石原矿），不要硬缩：在 8× 画布上按原生像素格重画（每个 8×8 块一种颜色），把源图当参考。
2. **朝向**：近战武器柄在左、刃尖在右，**允许向右上倾斜 0–12°**；弩与铳侧视横放，枪托 / 弩托在左、射口朝右，弩臂竖向展开占满 32 像素高；防具、饰品正面、居中，细长的饰品（骨笛、鼓槌）可以斜放以填满方格。不要透视。
3. **描边**：外轮廓 1 像素，用 `#0b0c0d`（近黑），保证在任何稀有度底色上都分得开；朝光的左上边可以把描边换成该材质的中间色（选择性描边）。内部不描边。
4. **体积**：每种材质 **4–5 级色阶**，暗部偏冷、亮部偏暖；金属刃必须有一条贯通的刃口高光和一处镜面亮点；布料、皮毛要有褶皱暗部。不允许大面积单色平涂（单色连续区不超过主体面积的 25%）。
5. **可读性**：主体亮度不能整体压在暗部。每件至少 15% 像素亮度 ≥ 60%；藏青、深灰类物件（龙门警用件）必须加亮边或浅色部件把轮廓托出来。
6. **二值透明**：无半透明、无抗锯齿、无投影、无外发光。
7. **不写字**：不画可读文字、数字、品牌、真实国徽。
8. **剪影测试**：同地区同槽位涂黑后能互相区分。武器靠刃形（直 / 弯 / 宽头 / 凿尖 / 带钩）和柄形（环首 / 角柄 / 长柄 / 指虎）；防具靠领口、肩和下摆；饰品靠外轮廓。
9. **自发光**：同前，另交同尺寸 `*_emit.png`。
10. **稀有度不改图**：同前。

### 10.8 制式保底修订（用户 2026-10-23，已实现，取代 §10.7 的发放、制作和外贸）

用户说：“干员白板容易死”，所以要“罗德岛制式装备数值变保守，不给前缀、不可交易、不可拆解，每局整备台可免费选择一套，防止死档”。拍板的三点是：撤离时收回；制式换代保留，从白到蓝再到金；数值固定。

- **领取**：整备台新增第三页“制式”。每个部位列出当前干员能用的制式底材（武器按职业形制过滤），点一下就穿上。身上原有的自己装备回到货架（货架满了就放背包），原有的制式件直接替换掉。“补齐空槽”给每个空槽穿上第一个选项，“交还制式”把身上的制式件全部交回。领取不花钱，也不限次数。
- **数值固定**：一律Ⅰ阶，基础效能取品质带的中值，只带底材固有属性（取标称值），没有随机词缀，也没有前缀。用户 2026-10-23 又说“再保守一些，当前数值减20%”，所以基础效能和固有属性再整体乘 0.8（`GearCatalog.RHODES_SCALE`）。饰品对用法杖的干员全部给法术，其他干员全部给攻击。品质由 `BaseState.rhodes_rarity` 决定：工程部Ⅱ 升蓝，工程部Ⅳ 升金。升级时身上正穿着的制式件会马上换成新品质。
- **绑定到合同**（`GearCatalog.bound`）：
  - 卖不掉：交付、订单、坎诺特、据点、交易所、可露希尔代售都不收。
  - 也不能打包（也就是拆解）、投保、让罗德岛小队送回。
  - 整备台不能对它重铸、校准、精调或定向重铸。
  - 物品卡上不显示交付价。
  - 在基地，制式件只能穿在身上：卸下、存回仓库或换上别的装备时，它就交回去，不会进仓库或背包。在局内可以卸进背包，或者丢在地上。
- **收回**：合同结束时，不管是撤离还是倒下，身上、背包、安全袋里的制式件全部收回，结算原因记为“制式收回”。
- **作废**：入职发放和换代补发（`issue_kits`、`kitted`、`kit_issued`）都删掉了；加工部的 19 条制式配方也删了，改名为 `Workshop.RETIRED_GEAR`，只用来退款：旧存档里排着的制式加工任务完成时，会退回材料和龙门币。旧存档读入时，货架、暂存区、货箱、手上和投保队列里的制式件都会清掉（`BaseState.purge_bound`），身上穿着的按新规则重做。
- **测试**：`tests/test_rhodes_issue.gd`（20 项）覆盖领取、绑定、撤离和死亡收回、旧存档和旧任务；`test_gear` 覆盖固定数值、换代和不进任何市场。截图是 `evidence/gui-base-issue.png`。

## 12. 各地区的远程和法杖武器（用户 2026-10-18：“还得补各地区远程和法杖武器”）

§2.4 当时把弩和铳定为“等有狙击干员再进池”。现在已经有狙击（早露、提丰）和术师（林、寒檀），所以远程和法杖进池，并加上法杖这一形制。

### 12.1 形制与职业

| 形制 | 间隔 | 伤害 | 射程 | 职业 |
|---|---|---|---|---|
| 弩 | ×1.0 | ×1.0 | ×1.0 | 狙击 |
| 弓 | ×0.85 | ×0.85 | ×1.1 | 狙击 |
| 铳 | ×1.4 | ×1.5 | ×1.2 | 狙击 |
| 法杖 | ×1.0 | ×1.0 | ×1.0 | 术师 |

- **作用对象**：远程形制和法杖调的是干员自己的射击或施法（kit 的间隔、伤害、射程），不改动作。弩和法杖是基准，和空手一样，区别只在武器本身的数值和固有词条。
- **职业可用形制**（`GearCatalog.CLASS_FORMS`）：

  | 职业 | 可用形制 |
  |---|---|
  | 近卫 | 刃 / 重 / 拳 / 长柄 |
  | 先锋 | 刃 / 拳 / 长柄 |
  | 重装 | 重 / 刃 / 长柄 |
  | 狙击 | 弩 / 弓 / 铳 |
  | 术师 | 法杖 |

- **装备不了的武器**：
  - 装备时拒绝，提示“早露无法使用刃”。
  - 换出战干员时，或读档时，如果手上的武器新干员用不了，就放回仓库并提示。仓库满了就放收货区。
- **远程武器的操作**：装远程武器时，点地面是走过去，不对空挥（沿用原来的规则）。（2026-10-20 起所有武器点地面都是走过去。）
