# 干员寻访策划案 v0.1

2026-10-16。只是策划案，还没有实现。§8 是待拍板，§9 是用户拍板。

用户需求（2026-10-16）：
- 博士开局只能选阿米娅。
- 其他干员要去各地区寻访才能获得。
- 到 PRTS 上找机制和技能适合本作的干员，或者改造后能适合的干员。

## 2. 寻访流程（推荐方案）

一句话：**在地区里找到她的踪迹 → 接她的寻访合同 → 在那一层找到她、帮她解围 → 撤离后入职。**

### 2.1 踪迹

- 每名可寻访干员属于一个地区。她的踪迹只在那个地区出现。
- 踪迹是计数器，不是物品，不占格子，阵亡也不丢。做法和作战记录一样，存在 `BaseState.recruit_clues[id]`。
- 踪迹来源按干员各自设定（§4 每人一行），全部挂在现有事件上：击杀精英或队长、打开密室、和兴趣点交互、遇到罗德岛小队。
- 默认要集齐 **3 条**才能接寻访合同。
- 拿到第 1 条时，PRTS 播报一句，例如"PRTS：博士，矿区里有人在找阿撒兹勒的旧址。"之后人事部终端上出现她的剪影。

### 2.2 寻访合同

- 踪迹集满后，调度台对应地区多出一张**寻访合同卡**，排在 3 张普通卡之外。它不随结算刷新，完成之前一直在。
- 主目标是"在第 N 层找到她并撤离"。N = 起点 +4 到 +6，从营地出发时往后顺延，和"深入"合同相同。
- 那一层必定生成她的**寻访点**。她用待机图站着，四周有一队敌人：1 名精英、普通敌人若干，按地区配。
- 清掉这队敌人后，走到她身边按 E，她就随行。随行只是剧情状态，她不跟着走，也不参与战斗，这样不用写友军 AI。然后撤离。
- 撤离成功：她**入职**，从精英 0、1 级开始，出发卡和训练界面出现她。
- 阵亡：合同卡保留，踪迹不扣，下次再来。

### 2.3 入职之后

- 她出现在基地的干员站位上（基地美术 v2.0 §2.4、§6 预留）。按"交互只提示 E"的规则，不挂名字。
- 人事部终端：大厅的空工位启用。终端只列名册：头像、地区、踪迹 n/3、状态（未发现 / 追踪中 / 可寻访 / 已入职）。不写说明文字。

### 2.4 为什么这样做

- **地区差异**：去哪个地区就能找到哪些人。这条符合总策划案"世界观必须承载机制"。
- **目标感**：寻访合同就是"局内节奏与目标"B1 合同卡的第五种类型，复用现成的追踪栏、J 面板和结算行。
- **成本低**：寻访点只需要她的待机图，入职以后本来也要画这张图。没有护送，也没有友军 AI。

### 2.5 备选方案（未推荐）

| 方案 | 做法 | 为什么没选 |
|---|---|---|
| B. 人事部直接招 | 在人事部花龙门币和招聘许可签约，许可从地区掉落（PRTS 有"招聘许可"道具） | 少了"去那个地区找到她"的体验，像商店 |
| C. 决斗 | 寻访点上和她本人打一场，赢了入职 | 要给每名干员写一套敌人 AI，并用她的攻击图当敌人，成本翻倍。可以留给精英 2 以后的"切磋" |
| D. 势力门槛 | 在 B 或 A 上再加一条：对应势力关系达到 R1/R2（例如拉普兰德要企鹅物流 R1） | 可以作为 A 的附加条件，见 §8 第 5 条 |

## 3. 候选干员总表（PRTS 核对）

核对方式：
- 名单取自 PRTS 分类页，干员页逐页核对。
- 星级按页面源码的稀有度字段核对（字段从 0 数起，5 = 6★）。
- 技能数值取专精 3 或最高等级。PRTS 表格的"初始 / 消耗 / 持续"列有时对不齐，**录入数值前要逐项复查**。

适配度是指放进本作动作玩法有多合适：高 / 中 / 低。

## 4. 推荐干员的转译方案

总原则：
- 塔防里的阻挡、部署、技力、费用都不存在。技能统一转成**普攻连招、空格主动技（冷却）、签名被动、精英 2 三选一变形**这四个槽，与现有两人的树结构相同。
- 签名机制必须和拉普兰德、阿米娅明显不同：拉普兰德是命中蓄力放剑气，阿米娅是空格隐身弹射。
- 下表"原样"指机制照搬、数值按本作缩放，"改造"指机制改了。

### 4.1 赫拉格（切尔诺伯格）· 武者 · 刃

PRTS：
- 武者特性：不能被治疗，每次攻击回复生命（精英 2 为 70）。
- 天赋「月盈星亏」：获得坚忍；攻速随损失的生命提升，损失 50% 时达到最高 +130。
- 技能：新月（下一击 175%，打两次）/ 弦月（攻 +80%，二连击，物理闪避 75%，13 秒）/ 满月（攻 +100%，范围 +2，最多 3 个目标，15 秒）。

| 槽 | 方案 | 来源 |
|---|---|---|
| 普攻 | 刃，三段，每次命中回复生命 | 原样 |
| 签名被动 | **饮刃**：药剂和自动回血对他无效，只靠命中回血；生命越低攻速越高 | 原样 |
| 空格 | **月相**：每按一次切到下一相，并开启对应强化：新月（下一刀重斩）→ 弦月（数秒二连击加闪避）→ 满月（数秒扩大范围横扫 3 个目标） | 改造：三个技能合成一个循环键 |
| 精英 2 三选一 | 满月常驻 / 坚忍延长 / 弦月闪避后反击 | — |

- **和地区的关系**："承伤与持续作战"正是他的机制。他和污染、自动回血系统有直接冲突，这是特色，不是问题（见 §8 第 7 条）。
- 寻访点：阿撒兹勒诊所废墟。踪迹来源：矿区击杀整合运动精英。

### 4.2 早露（切尔诺伯格）· 攻城手 · 弩

PRTS：
- 攻城手：远程物理，优先攻击重量最重的敌人。
- 天赋「深入骨髓」：攻击重量 ≥3 的敌人时无视 60% 防御，并追加 60% 物理伤害。
- 技能 3「雪崩击」：向最多 4 个最重的敌人射束缚叉枪，目标被束缚，每秒挨一次打，持续 8 秒。

| 槽 | 方案 | 来源 |
|---|---|---|
| 普攻 | 弩，单发重箭，按住蓄力穿甲；边走边射会减速 | 改造 |
| 签名被动 | **越重越疼**：对精英、首领和重甲敌人破防，并追加伤害 | 原样 |
| 空格 | **雪崩击**：向鼠标方向扇形射出 4 枚叉枪，钉住目标后持续结算伤害 | 原样 |
| 精英 2 三选一 | 分裂射击 / 叉枪把目标拉近 / 钉地后爆裂 | — |

- 解锁弩：装备策划案 §2.4 已经设计了远程的规则，只是一直没上线。
- 寻访点：切城中学的残楼。

### 4.3 怒潮凛冬（切尔诺伯格）· 撼地者 · 重

PRTS：
- 撼地者：攻击时，目标周围的敌人受到 50% 物理溅射。
- 天赋「汹涌怒火」：溅射伤害提高，并在高台上再震一次地面。
- 技能 3「无可抵挡」：攻 +100%，向前方连砸 5 次，每次 240% 并束缚 2 秒。

| 槽 | 方案 | 来源 |
|---|---|---|
| 普攻 | 重，三段锤击，每次落点溅射 | 原样 |
| 签名被动 | **震地**：溅射命中累计到阈值后震一次地，让敌人停顿并减速；站在崖边或台地边缘时再加强（"高台"转成台地地图的崖边） | 改造 |
| 空格 | **无可抵挡**：原地向前连砸 5 次，带束缚 | 原样 |
| 精英 2 三选一 | 连砸改成冲锋 / 防御姿态 / 战吼 | — |

- 问题：和赫拉格同一地区、同为近战。首批只选一人（§8 第 3 条）。

### 4.4 星熊（龙门）· 铁卫 · 盾

- 技能：战意（防 +80%、攻 +40%）/ 荆棘（被动：防 +30%，受击时反伤攻击力的 100%）/ 力之锯（攻 +140%、防 +90%，盾牌切割前方一格的所有敌人）。

### 4.5 陈（龙门）· 剑豪 · 刃

PRTS：
- 剑豪：每次普攻打两次。
- 技能：鞘击（320% 并晕眩 1.5 秒）/ 赤霄·拔刀（前方最多 7 人，各 500% 物理 + 500% 法术）/ 赤霄·绝影（锁定连斩 10 次，期间无敌）。
