### 1.2 三个家族的配色

士兵、弩手、术师、恫吓者、角头按家族换色。**只换点缀色（特征色）**，体型、衣服、武器不变，三家共用一套美术（用户 2026-10-16 拍板："只换特征色"）。

| 家族 | 旗帜（`siracusa_dressing.gd` BANNER_COLOURS） | 敌人点缀色（亮/暗） | 画在哪 |
|---|---|---|---|
| 萨卢佐 | 酒红 `#751a24` | `#9a2a3a` / `#5e1620` | 帽带、领带、口袋巾 |
| 罗塞蒂 | 深蓝 `#1f3366` | `#3560b0` / `#1f3366` | 同上 |
| 贝洛内 | 旧赭 `#856b33` | `#b08a40` / `#6e5528` | 同上 |

- 敌人身上的点缀色比旗帜亮一档。西装是炭灰色，旗帜原色画在上面看不出来，尤其罗塞蒂的深蓝。
- 做法：Sol 只画萨卢佐一套，点缀色严格只用两个值（`#9a2a3a`、`#5e1620`）；罗塞蒂、贝洛内两套由 Claude 在烘焙后**换这两个颜色**生成。烘焙是 16 色量化，所以要在 Sol 的检查里确认这两个颜色在烘焙后仍是独立的两色。
- 恫吓者的点缀加在**马甲**上（大面积，否则 33 px 的大块头上看不出），术师加在**兜帽内衬**和领带上，角头加在**帽带**和领结上。
- 灭迹人和轿车**不分家族**：灭迹人是无名杀手，轿车是一辆黑车。
- 敌人属于哪一家，按它刷出的位置在哪家地盘（`district_at`）决定。

## 二、沿用的规则

新敌人案 §一 1–9 条全部照用，重点重复一下：
- 普通敌人的物理攻击不画地面预警，靠蓄力姿势读招；精英和法术攻击画透明红色预警，同心圆从中心往外扩散作倒计时。
- 不可打断的攻击：预警外圈加白边，蓄力帧身体外亮一圈。
- 敌方武器轨迹一律锈红色。
- 蓄力要夸张：武器伸出轮廓至少 4 px，或身高变化至少 3 px。

### 本案新增

1. **隐身的画法（灭迹人）**：隐身不是"看不见"，是"看不清"。
   - 远处（> 6 m）：完全透明，只有在**雨天**它踩过的湿石板上留下一串一闪而过的水花（每 0.4 s 一处，2×1 px 白点）。阴天没有水花。
   - 近处（≤ 6 m）：显出一个约 15% 不透明度的扭曲轮廓，轮廓边缘每 0.1 s 抖 1 px。
   - 玩家不能点选它，单体攻击打不到；范围攻击能打中，打中就现身。
   - 隐身由代码做（透明度加扭曲着色器），**Sol 不画隐身帧**，只画现身后的动作。
2. **家族换色**：同一种敌人三家只有点缀色不同，见 §1.2。
3. **血债靠杀人涨**（用户 2026-10-16 拍板："血债杀人涨"，选的是 §六第 1 条 A）：照 PRTS，杀士兵、杀恫吓者、角头身边倒人、术师煽动都会让血债上涨，数值见 §四.1。自然累计保留，但减半，作为底数。**这改写了叙拉古方案 §8 的"血债全层一条，规则同威胁值（自然累计）"**；血债仍然全层一条，不分家族。

## 三、逐个敌人

**数值**：前摇、间隔、收招、判定是本案的建议，参照现有同类敌人；伤害倍率以普通敌人的一击为 1.0，同新敌人案。STATS 按 PRTS 的相对强弱换算，见 §四。

### 1. 家族士兵 ·「匕首突刺」（普通 · 物理 · 无预警）

PRTS：家族基层成员，听命行事，从不过问。

| 项 | 内容 |
|---|---|
| 外观 | 软呢帽压低，帽檐的阴影盖住眼睛；炭灰西装、白衬衫、背带、家族色领带和帽带；右手一把细长匕首，刃朝前；身后一条灰白狼尾 |
| 动作 | 匕首垂在身侧 → 起手：压帽檐，身体侧过来 → **蓄力：上身前倾、匕首收到腰侧，刃尖朝前，另一只手按住帽子** → 一步前冲直刺 → 收刀，手回到身侧 |
| 身体信号 | 收刀到腰、身体前倾就是要刺；出手前刀尖闪白 |
| 判定 | 窄长带，宽 0.8，长 2.4；冲 0.8 |
| 出手特效 | 一道锈红色直线刀光，0.08 s |
| 音效 | 短促的破风声 |
| 数值 | 前摇 0.7，间隔 1.2，收招 0.25；伤害 **0.8** |
| 应对 | 主力杂兵，成群来；横移躲直刺，反击窗口短 |

### 2. 家族恫吓者 ·「双拳砸」（普通 · 物理 · 无预警）

PRTS：家族训练的大力士，强壮的身材相当唬人。

| 项 | 内容 |
|---|---|
| 外观 | 比士兵高一头、宽一倍：银灰背头、狼耳、八字胡；浅蓝灰外套敞开，家族色马甲、深色领结；空手，拳头画得特别大 |
| 动作 | 两拳垂在身前 → 起手：十指交扣 → **蓄力：交扣的双拳举过头顶，身体后仰，胸口挺出**（身高变化 ≥ 3 px）→ 双拳砸在身前地上 → 慢慢直起身 |
| 身体信号 | 双拳举过头就是要砸；它慢，蓄力时间长 |
| 判定 | 前方 100° 扇形，半径 2.2；命中击退 1.5 |
| 挡穿透（用户 2026-10-16 拍板，取代 PRTS 的嘲讽） | **不做嘲讽。穿透类攻击打到他就停下，不再穿过他继续飞**：拉普兰德的穿透剑气、远程武器的穿透箭等都一样。他身后的敌人因此受保护。不穿透的攻击照常打到谁算谁。没有特殊表现，靠站位读：他走得慢，常挡在弩手、术师和玩家之间。除此之外就是一个慢、硬、打得重的前排 |
| 出手特效 | 砸地点一圈灰色冲击尘，0.25 s |
| 音效 | 一声低吼 → 沉闷的砸地声 |
| 数值 | 前摇 1.1，间隔 2.0，收招 0.6；伤害 **1.2**；移速是士兵的 0.6 倍 |
| 应对 | 绕开它先打后排；或者等它砸完、慢慢直起身的那 0.6 s 打 |

### 3. 家族弩手 ·「枪弩连射」（普通 · 物理 · 无预警；清算时刻变法术）

PRTS：家族配的弩难称精良，紧急时用上不知从哪学来的简单法术。清算时刻下攻击变为法术伤害。

| 项 | 内容 |
|---|---|
| 外观 | 软呢帽配黑色宽帽带（帽带下方再加一道家族色细带）；灰褐长发；深褐灰西装；一把枪型弩：木枪托、黑机匣，枪口一对短弩臂 |
| 动作 | 弩斜挎在胸前 → 起手：弩托抵肩 → **蓄力：身体侧过来，弩举平，枪口指向目标，弩臂张开**（伸出轮廓 ≥ 4 px）→ 后坐一下 → 弩放回胸前 |
| 身体信号 | 弩举平就是要射；出手前弩臂一闪 |
| 判定 | 两发弩箭，间隔 0.15 s，沿同一方向；射程 11 |
| 清算时刻 | 弩箭变成法术伤害，弩箭由代码染成淡紫并带 1 px 拖尾。Sol 不画 |
| 出手特效 | 枪口一团 2×2 的灰白尘 |
| 音效 | 两声"嗒嗒"的弩机声 |
| 数值 | 前摇 1.0，间隔 2.0，收招 0.3；每发伤害 **0.6** |
| 应对 | 两发同一方向，横移就躲开；它血少，突脸很快 |

### 4. 家族术师 ·「双发术弹」+「煽动」（普通 · 法术 · 术弹无预警）

PRTS：同时攻击两个目标；可以停止攻击，持续施法使血债增加。

| 项 | 内容 |
|---|---|
| 外观 | 浅钢蓝兜帽，帽上立着一对狼耳，兜帽内衬是家族色；脸是一片空白的浅色（照 PRTS，不画五官）；马甲、家族色领带；戴深色手套，没有法杖 |
| 术弹动作 | 双手在胸前 → **蓄力：两手分开向两侧张开，两掌各亮一团淡橙光** → 两手同时向前推 → 收手 |
| 术弹信号 | 两掌亮光就是要打 |

#### 7.1 路障的生成器约束（可达性）

路障只是暂时挡路，**任何装置、撤离点、兴趣点都不能被永久封死**。生成器放轿车时必须同时满足：

| # | 约束 | 为什么 |
|---|---|---|
| 1 | **只放在主路（trunk）上**，一段从小广场（arena 圆）通往更深一个主路节点的连线；营地层（每 10 层）不放；入口后第一段和出口前最后一段不放 | 主路是玩家必经的路；不挡入口和出口本身 |
| 2 | 这段连线必须是**割边**：去掉它，地图就分成"近侧"（含本层入口）和"远侧"两块。若有环路（loop、rejoin 支路）能绕过，就换一段；整层找不到就**这一层不放轿车** | "必须清掉"只有在绕不过去时才成立 |
| 3 | **近侧必须包含本层入口和起点**，车头朝近侧（朝广场） | 玩家总是从车头一侧过来，车头前方 8 米内可站人、可攻击 |
| 4 | 卡口用**街具**做，不收窄地形：地形照常 ≥ 5 米宽，连通检查（`TerrainSurface.connects`）在**没有车**的地形上跑；然后沿车身两侧各摆一排叙拉古的路障件（现在 `SiracusaDressing._barricade_piece` 是酒桶堆），从车身两侧一直排到街墙，车身和路障之间的缝小于站立半径，人过不去 | 窄于约 5 米的斜巷会让连通检查失败（叙拉古方案 §9 的坑）；用街具做卡口，车一撤，路就照常连通 |
| 5 | 车身、路障件都要避开设备、缓存、路线标记（它们在布景之前放下） | 同叙拉古方案已知的坑：后放的东西不能压在先放的标记上 |
| 6 | 车的碰撞是**可移除的导航障碍**；死亡时立刻移除，残骸没有碰撞 | 打爆就通，不留第二道墙 |
| 7 | 车没有无敌、不回血、不能被拉走或推走，只要打就一定打得爆；从近侧看，它的车头和两侧都在攻击范围内 | 保证"暂时"挡路，不会变成永久封死 |
| 8 | 清算巡逻的入口只取**玩家所在的一侧**；远侧的敌人在车被打爆前不会穿过卡口 | 巡逻不会被卡在路障另一边，也不会凭空出现在玩家身后的远侧 |
| 9 | 测试：每层生成后，把车当成障碍跑一次可达性，近侧必须含入口；把车移除再跑一次，所有设备、撤离点、兴趣点、出口都必须可达 | 两次检查一起，证明"暂时挡路、绝不永久封死" |

- 每层最多 1 辆。出现概率先按 50%（满足上面条件的层里），试玩后再调。
- 首领层、营地层不放。

### 8.1 补全（2026-10-17）

原先未实现的五项已做完：
- **术师煽动**：看得见博士、在射程内、冷却好了（开局 2–5 s，之后每次结束后 10 s）就停下煽动，最多 8 s，每秒血债 +0.75（`GameManager.add_debt`）。头顶出暗红细圈（代码画），动作用第 6 行 INCITE。挨两下、被沉默、被眩晕、被噤声都会中断。**清算巡逻里的术师不煽动**（同"杀巡逻不加血债"，免得清算连锁）。
- **清算时弩手转法术**："清算时刻"= 本层还有清算巡逻的人活着（`GameManager.reckoning()`）。这期间家族弩手的弩箭是法术伤害，箭身染淡紫并带 1 px 拖尾（`EnemyProjectile.make_arts`）。
- **角头近身一掌**：出手时博士在 1.8 m 内，改用以自身为中心半径 1.6 的红圈，前摇 0.7，伤害 1.0；用 START 帧蓄力、RECOVER 帧出掌。雪茄和掌落地都是一圈橘红火花（`ember_ring`）。
- **灭迹人**：巡逻进层后不等看见就直接追博士（`Enemy.hunts`）；隐身时走向博士**侧后方** 2.5 m 的点（按她最近的移动方向算"后"，取它已经所在的那一侧），近到 3 m 现身再出手。雨天 6 m 外隐身移动时每 0.4 s 在脚下留一处水花（两个 2×1 px 白点），阴天没有。
- **汽车**：只在车头前方 8 m、左右 2 m 内有人时才发动，冲撞方向固定沿车头（不转向）；收招后用 1.5 s 沿原路倒回卡口，车头始终朝外，行走板倒放。从蓄力开始到倒回原位，车头亮两个 3×3 白灯（车头背对镜头时不画）。车不会被击退。原先车的看守半径只有 0.6 m，实际上从来不发动，这次改成单独的路障逻辑（`Enemy._tick_roadblock`）。
