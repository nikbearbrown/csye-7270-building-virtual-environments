# 基建资源调研：逃离塔科夫 × 逃离鸭科夫

> 目的：给罗德岛基地的建造/交付订单补一批「日常通用资源」（螺栓、电线、胶带……），不再只用 PRTS 基建材料（碳/碳素/家具零件/赤金等）。
> 调研日期：2026-10-04。数据来源见文末「参考」。标 **[待核实]** 的是没找到可靠一手出处、或几个来源对不上的条目。

## 一、逃离塔科夫（EFT）藏身处与以物易物物品

### 1.1 堆叠规则（已确认）

- 塔科夫里**只有子弹和货币能堆叠**，以物易物物品（螺栓、螺丝、电线等）**全都不堆叠**，一件占一组格子。这是官方「尽量写实」的设计取向。[F1][S1]
- 玩家的应对方式是用收纳容器（如 Lucky Scav Junk box、医疗箱）把大量零碎塞进少量仓库格子。[S1]
- 所以塔科夫的仓库压力来自「零件数量 × 格子数」，而藏身处升级正好就是吃这些零件。

- 极高：LEDX、实体比特币、金链、军用电子件

**可借鉴的设计规律**：
1. **每个模块都有一个「主题类别」**：卫生间吃日用品，医疗站吃医疗耗材，供暖吃易燃物，发电机/照明吃电子件。玩家一看需求就知道该去哪类容器找。
2. **低级用基础小件，高级加整机/工具**：1 级多是螺栓、螺母、胶带；2–3 级才要电动机、工具套装、电钻，而且数量 ×5–×15。
3. **「须带出（Found in raid）」**只在高级出现，用来防止直接买齐。
4. **扩仓是大头**：仓库升级要大量螺丝和钉子，外加一两件高价工具。

## 三、逃离鸭科夫（Escape from Duckov）基地与材料

### 3.1 背包模型与堆叠

- **按格子数 + 负重**，不是塔科夫那种俄罗斯方块式网格：每件物品或每组堆叠占 1 格，不管个头大小；背包起始约 10 格，总负重上限约 45kg，超重掉耐力、减速。[D5][D6]
- 仓库升级：前几级只花钱，后几级要「扩容箱 小/中/大」，扩容箱在储物柜、工具箱、敌方营地里能找到。[D6][D3]

### 3.3 材料来源

- 五金类（螺母、螺栓、钉子、金属片、木料）：**工具箱**是固定来源（数据库写金属片在各图工具箱「125% 掉率」，木料在农场镇工具箱 25% 固定掉落）；另外杂货店每次刷新限购 3 个；高级工程师、雪地机器人等敌人也小概率掉落。[D2]
- 电子类（电线、电路板）：地图散落、各类箱子随机，机器人类敌人（Spider-Bot、Snow-Bot、Rampaging Arcade）有 0.13–0.20 的掉率。[D2]
- 日用类（胶带、漂白剂）：地图随机、神秘商人出售，胶带还能从「强力胶」分解出来。[D2]
- 扩容箱：储物柜、工具箱、敌方营地。[D6]

### 3.4 稀有度配色 **[待核实]**

- 能查到的配色说明都来自**MOD 介绍页**（品质音效 / 光柱 MOD）：1 白、2 绿、3 蓝、4 紫、5 金、6 红，共 6 级。[D8] 原版游戏有物品品质底色，但官方的确切级数和配色没找到一手出处。数据库给五金材料的标签是「Tool Material」，没有直接写品质等级。

## 四、给《downfall-godot》的综合建议

### 4.1 设计原则（来自上面两款游戏）

1. **类别 = 去哪找**：每种 POI 有明确的类别倾向（塔科夫的工具箱/PC/医疗箱/保险箱，鸭科夫的工具箱出五金）。
2. **设施 = 主题物 + 五金垫底**：每项基地建设要「2 种低星通用件 + 1 件主题物」，主题物决定玩家该去哪类 POI（鸭科夫模式）；高级再加整机/工具件，数量翻倍（塔科夫模式）。
3. **堆叠按体积，不按星级一刀切**：小零件大堆叠，整机/大件不堆或少堆，并占 2 格以上（鸭科夫的堆叠梯度 + 塔科夫的格子尺寸）。我们背包本来就有 `Vector2i` 尺寸（武器 2×1、护具 2×2），可以直接沿用。
4. **跟 PRTS 材料并存**：PRTS 基建材料（碳、碳素、加固建材、赤金、源石碎片）继续当「泰拉特色」的高价值线；新加的通用资源当基础消耗线。

**偏离默认堆叠的理由**：
- ★1 五金调到 30：跟鸭科夫一样，基础五金是消耗大户（塔科夫仓库 3 要螺丝 ×15），堆叠大一些能减少背包浪费。
- 长条 / 整件物品（软管、电源线、电机、电瓶、油罐、工具套装）堆叠调小或不堆叠，并占 2 格以上：这样不会被批量刷出来，也让「带不带回去」成为一个取舍（塔科夫的设计意图）。
- 工具类整体只堆 5：参照鸭科夫扳手、螺丝刀不堆叠。

### 4.3 建议新增的 POI 类型

| POI | 名称 | 区域倾向 | 掉落类别 | 原型 |
|---|---|---|---|---|
| `electronics_cabinet` | **电子柜** | 城市 3.0、矿区 1.0 | 电子为主（电线、继电器、电路板、电机、精密镜片），少量能源 | EFT PC block + 技术物资箱 |
| `med_cabinet` | **医疗柜** | 城市 2.0、冰原 1.0 | 医疗耗材 + 现有医疗类消耗品 | EFT Medcase |
| `office_desk` | **办公桌**（可选） | 城市 2.0 | 灯泡、胶带、电池、少量电路板 / 贵重 | EFT Drawer / Jacket |

现有 POI 的分工建议：
- **建材堆**：螺栓 / 螺母 / 钉子 / 木板 / 金属板 / 软管 / 密封泡沫 + PRTS 碳系
- **源石矿脉**：金属板、燃料罐 + 源石碎片（保持泰拉特色）
- **物资仓**：全类别各来一点（相当于 EFT 运动包），中等星级为主
- **保险柜**：贵重 + 电路板 + 赤金，不出大件
- **冰原营地**：固体燃料、帆布、缝纫包、胶带、蓄电池（营地生活物资）
- **工具箱**：工具（手钳 / 扳手 / 工具套装）+ 五金 + 防锈润滑剂 + 电线（EFT 工具箱的配比：工具、建材、电子三者大致相当）
- **武器箱 / 护具箱**：基本不出基建资源；护具箱可以小概率出帆布、缝纫包
