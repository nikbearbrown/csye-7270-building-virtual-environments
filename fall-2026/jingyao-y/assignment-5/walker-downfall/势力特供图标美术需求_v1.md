# 势力特供、作物与补给图标 · 美术需求 v1（给 Sol）

Source: `势力特供策划案_v0_2.md` §二, §四, §五. 18 item icons. Each item now borrows an existing icon (see `ui/item_icons.gd`, `ItemIcons.MATERIALS`).

## Format

- Size: 32 × 32 px, transparent background. Same style as the M1/M2 material icons in `art/items/runtime/`.
- Use the thick outline and flat fill of the other material icons. Don't limit the palette or the number of colours.
- Delivery: `art/items/runtime/<id>.png`. I swap in each id in `ItemIcons.MATERIALS` once it lands; no other code changes.

## Acceptance

- Each special should be recognisable as its faction's at 32 px: Kjerag blue and snow, the rat stamp, the Ursus stencil, Sami frost and cord, the Kazimierz seal, Penguin Logistics yellow and black, the Reunion mark.
- Seeds, crops and meals: the glowing ones should glow, and the four meal tiers should rise visibly in richness.
