# 龙门城区与叙拉古地图改造案 v1.1

2026-10-21。用户要求：

> 龙门地图名字改为龙门城区，分为上城和下城，上城保持当前地图景色，下城按你说的改；叙拉古按你说的改，地标按你说的来，先写策划案，不改。

v1.1 修订（同日）：

> 不用大改，换地图内大小组件和光影、滤镜、材质就行；龙门上下层区改为每进一层随机。

- **前置方案**：`城区地图参考加载卡方案_v1.md`。
- **参考图**：`art/ui/key/load_city.png`（下城）、`load_siracusa.png`。
- **对照的现状**：`evidence/f4-city-entry.png`、`f4-siracusa-entry.png`。
- **本案只写方案，不改代码。**

### 改动范围

两张图的**地图生成一律不动**：街道走向、楼的排法、封路、台地、出口、密室、兴趣点位置都照旧。只换四样东西：

| 换什么 | 指什么 | 落在哪 |
|---|---|---|
| **组件** | 大组件 = 楼、路障、地标这类占格子的东西；小组件 = 招牌、灯笼、外机、晾衣竿、盆栽这类挂件 | 现有的组件槽位，换成新的组件表 |
| **光影** | 环境光、太阳、雾、背景色，场上点光源的颜色和密度 | `FieldLight.REGIONS`、`GameManager.FIELD_LOOK` |
| **滤镜** | 对比度、饱和度、亮度，以及一张调色渐变（`adjustment_color_correction`） | `FIELD_LOOK` 新增 `contrast`/`saturation`/`brightness`/`grade` 四项，`field_environment()` 读取 |
| **材质** | 地面、墙、屋顶的颜色、粗糙度、脏旧程度 | 现有材质换参数，或换一套贴图 |

v1 里改变地形或地图边界的内容全部取消：楼不加高、不放远景剪影、拱门过街楼不做成隧道。

## 1. 龙门城区：上城和下城

### 1.1 名字和随机

| 项目 | 现在 | 改后 |
|---|---|---|
| 地区名 | 龙门 · 下城区废墟 | **龙门城区** |
| 层名（顶栏、加载卡） | 一个 | **龙门城区 · 上城**、**龙门城区 · 下城** |
| 地区代号 | LG | 不变：LG-01 起 |
| 上城还是下城 | — | **每进一层随机**，各 50%，用这一层的种子来掷 |

规则：
- **掷的时机**：层生成之前用楼层种子掷，所以加载卡就能显示这一层是上城还是下城。同一个种子永远掷出同一个结果，重进、回放、测试都一致。
- **营地层**（每 10 层）：不掷，固定用上城的样子。营地只有撤离和可露希尔，没必要换。
- **Boss 层**：照常掷，Boss 在上城或下城出现都行。
- **调度台**：章节牌只写“龙门城区”，不提前显示上城或下城（进去之前不知道）。
- **鼠王的据点（游商）**：只在掷到下城的层出现。
- 威胁值、掉落阶梯、敌人表都按层数算，和上下城无关。

**要同步改的地方**：
- `FieldCatalog.REGIONS.city.name`
- 层生成时记下 `city_variant`（`upper`/`lower`），光影、组件表、加载卡、顶栏都读它
- 加载卡：上城用现有地图的截图，下城用 `load_city.png`
- i18n：新增“龙门城区”“上城”“下城”，用 extract 加 merge 的流程，过 `test_i18n`

### 1.2 上城：保持现在的景色

上城就是现在这张图：楼沿街排开、封路、路障、Sol 的 C1–C9 贴图、霓虹、路灯光池、绿雨棚。全部不动。

### 1.3 下城：同一张图换皮

| 方面 | 做法 |
|---|---|
| **光影**（新增 `city_lower`） | 冷蓝灰的湿冷夜，ambient 约 (0.62, 0.68, 0.82)，能量比上城低一档。玩家周围的光圈不变。路灯减到上城的三分之一，主要光源换成窗光和红灯笼：小范围的暖色点光源，挂在门口和连廊下 |
| **滤镜** | 饱和度约 0.9，对比度约 1.1，亮度略降。调色渐变：暗部偏蓝，亮部偏暖黄，让窗光和灯笼跳出来 |
| **材质** | 街面贴图压暗一档、roughness 降低，做出潮湿反光；墙面换成旧水泥和瓷砖的颜色，加水渍 |
| **霓虹** | 招牌组件照旧，但只有招牌本身发光，不再大面积染地。粉紫色基本不用，暖色集中在窗光和红灯笼上 |
| **大组件** | 楼的组件表换成下城版：同样的占地，立面换成一排排窗户，随机 30–40% 亮暖黄色。**地标：牌楼连廊**——带歇山顶的过街连廊，占一个现有的路障或跨街槽位，每张图 1–2 座，下面挂两盏红灯笼，路可以走 |
| **小组件** | 挂在楼上的东西换成空调外机、晾衣竿、红灯笼；楼与楼之间每隔 2–3 栋拉一组电线束或晾衣绳（只投阴影，高度在角色头顶以上，不挡角色、不虚化）；地上偶尔放积水贴花 |
| **敌人、掉落、兴趣点** | 和上城相同，只多一个鼠王的据点 |

## 2. 叙拉古旧城区

不分上下，整张图换皮。

| 方面 | 做法 |
|---|---|
| **光影** | 从白天改成黄昏到夜晚。`siracusa` 的 ambient 改为约 (0.58, 0.62, 0.76)，太阳压低、偏橙；墙灯和窗光是主要的暖色。雨天版 `siracusa_rain` 保留，在这个基础上再暗一档 |
| **滤镜** | 饱和度约 0.95，对比度约 1.08。调色渐变：暗部偏紫蓝，亮部偏琥珀；雨天版整体再冷一点 |
| **材质** | 屋顶瓦片从高饱和的橙红改成褪色的陶土色，加脏旧；墙换成暖砂岩和灰泥；石板路压暗一档 |
| **大组件** | 楼的组件表换成叙拉古新版：同样的占地，立面加石砌转角和窗套。**地标：钟楼**——方形钟楼，顶上有拱窗，占广场边一个楼的槽位，每张图 1 座，是全图最高的组件，镜头转动时可以用它认方向。**拱门过街楼**——楼底下开拱门，占现有的跨街槽位，不加长、不变隧道，拱下挂一盏壁灯 |
| **小组件** | 小阳台、盆栽、墙角爬藤、晾衣绳；街道上空拉串灯，暖色小点光源，每串 5–8 个 |
| **玩法** | 血债、敌人、掉落都不变 |

## 3. 地标规则（两张图共用）

- **数量**：龙门下城每图 1–2 座牌楼连廊；叙拉古每图 1 座钟楼。
- **位置**：只占现有槽位，选在主路上或主路边，离出口不能太近，免得一进图就看见出口的方向。
- **遮挡**：地标比角色高。角色走到它后面时直接被挡住，不做透视，也不做虚化（基地改造时定的规则）。连廊和拱门下面的路可以走。

## 6. 实现记录（2026-10-21，已实现）

**C1 改名与每层随机**
- `FieldCatalog.REGIONS.city.name` = 龙门城区；`FieldCatalog.place_name(region, variant)` 拼出“龙门城区 · 上城/下城”（只对龙门生效）。
- `ContinuousWorldMap.city_variant_of(seed)`：楼层种子 `^ 0x10c17` 掷 50%，层生成时写进 `city_variant`；`force_city_variant` 给测试和截图用。营地、基地不显示上下城（`GameManager.place_name()`）。
- 顶栏和 M 地图信息用 `game.place_name()`；加载画面（`SystemScreens`）上方放地区加载卡：下城 `load_city.png`，上城 `load_city_upper.png`（上城截图，按 UD 流程半尺寸最近邻、128 色、2× 放大），其他地区用各自的卡。
- i18n：上城 Upper City、下城 Lower City、龙门城区 Lungmen City（overrides.json）。

**C2 光影、滤镜、材质**
- `FieldLight.key()` 下城返回 `city_lower`；`FieldLight.REGIONS` / `GameManager.FIELD_LOOK` 新增 `city_lower`，叙拉古改成黄昏夜。
- `FIELD_LOOK` 新增滤镜项 `contrast`/`saturation`/`brightness`/`grade`，`grade` 由 `GameManager.grade_texture()` 生成逐通道渐变（`adjustment_color_correction`）。
- 地面 `FieldArt.terrain_material(region, look)`：`GROUND_LOOK` 给 `ground_gain` 和 `wet`（整体变亮滑、噪声积水更暗近镜面）。下城 0.88/1.0，叙拉古 0.72，雨天 0.68/0.7。

**C3 下城组件**（`build_city_kit.py` LOWER，通过 MCP 建）
- 6 栋外城楼的下城版 `*_lower`：同尺寸，墙压暗偏冷加水渍，窗户 35% 亮暖黄，空调、铁窗、晾衣阳台更多，雨棚褪色。`CityDressing._add` 按 `LOWER_PIECES` 换模型，占地和摆放完全不变。
- 新模型 `city_lc_skybridge`（牌楼连廊，歇山顶、红栏、斗拱、牌匾、两盏红灯笼）、`city_lc_lantern`（门口红灯笼）。
- 摆放：路灯留 1/3；霓虹去粉紫、光池缩到 3.2 m；楼前随机窗光、店门红灯笼；电线投影；街两侧都有楼的地方拉晾衣绳；连廊每图 1–2 座，优先主干道，离出口 36 m 以上。下城新加的东西都用 `look_rng`，碰撞物与上城逐米一致（测试核对）。

**C4 叙拉古组件**（`build_siracusa_kit.py`）
- 六栋房重建：褪色陶土瓦加脏、暖砂岩墙、窗套侧框、阳台和窗台盆栽、墙角爬藤、窗光 30%。家族色调收向中性。
- 新模型 `siracusa_bell_tower`（19.96 m，钟面、成对拱窗钟室、亮灯）、`siracusa_arch_house`（拱门过街楼，拱顶 4 m，拱下壁灯）。
- 钟楼每图 1 座，放在广场北缘背后的岩体上，离出口 35 m 以上；拱门过街楼每图 1–2 座，跨在巷子两侧墙之间，避开入口、宅门、标志物；巷子上空串灯（每串 5–8 盏，每隔一盏一个点光源）和晾衣绳。

**C5 验收**

- 测试：新增 `tests/test_city_variants.gd`（已加入 run_all）；2026-10-21 全量 55 套件通过。
