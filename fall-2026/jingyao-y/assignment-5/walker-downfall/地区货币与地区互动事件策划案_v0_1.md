## 1. 地区货币

### 1.1 货币清单

只用 PRTS 有名字的货币（这条沿用之前的裁定，不另起名，不出现"马克"）：

| 盘口 id | 货币 | 地区 | 基准（每 1 赤金） | 制度 | 波动 | 谁用它结算 |
|---|---|---|---|---|---|---|
| `fx` | 龙门币 | 龙门 | 1000（已有） | 有管理的浮动：偏离太远，龙门方面会入市干预 | 1.0 | 罗德岛、龙门商会、鼠王、企鹅物流 |
| `fx_col` | 哥伦比亚金券 | 哥伦比亚 | 400 | 自由浮动，流动性最好 | 1.2 | 莱茵生命（拍板 #2） |
| `fx_vic` | 维多利亚镑 | 维多利亚 | 80 | 自由浮动，受政局影响大 | 1.4 | 没有势力用它，只用来投机 |
| `fx_sar` | 萨尔贡第纳尔 | 萨尔贡 | 1500 | 挂住赤金，只能在 ±2% 区间里动；挂钩一旦守不住就是黑天鹅 | 0.3（区间内） | 没有势力用它，只用来投机 |
| `fx_lei` | 莱塔尼亚杜卡特金币 | 莱塔尼亚 | 12 | 金币，和赤金高度相关，波动低 | 0.5 | 没有势力用它，只用来投机 |

- 萨尔贡金币是实物金币，不开盘口，只在快讯里出现（例如大巴扎的成色之争）。
- PRTS 没写名字的货币（拍板 #3）照旧只在快讯里出现，写"当地货币"。它们通过快讯改变当地势力的赤金报价。
- 汇率都写作"X / 赤金"，K 线、自选、到价提醒、差价合约都和现在的 `fx` 盘一样。外汇放在行情列表顶部，单独一组。
- 交叉汇率（例如龙门币/金券）不单开盘口。直接换汇按两边价差之和的 0.75 收取，比先换成赤金再换出去略省一点。

### 1.2 外币账户（拍板 #1）

- 喀兰贸易托管，和赤金账户放在一起，记到小数点后两位。
- 只能在交易所终端（基地里，或游戏外的 A 终端）换汇。营地里的可露希尔还是只管龙门币和赤金。
- 局内用不到外币。局内照旧只认背包里的赤金。
- 倒下不会丢外币，因为它根本不会被带进局内。

### 1.3 利率与套息

每种货币有一个**政策利率**。在每个交易日开始时（本地 08:00），按持有的余额计息。

| 货币 | 初始年化 | 每日 |
|---|---|---|
| 赤金 | 0% | 0 |
| 龙门币 | 2% | ≈0.0055% |
| 金券 | 5% | ≈0.014% |
| 镑 | 4% | ≈0.011% |
| 第纳尔 | 7% | ≈0.019% |
| 杜卡特金币 | 1% | ≈0.003% |

**"挂机不能赚钱"怎么守住**：按利率平价，每种货币的漂移项加上 −(本币利率 − 赤金利率)。也就是说，高息货币平均每天正好贬掉利息那么多。光拿着不动，期望收益是 0，再扣掉换汇价差，就是负的。真正赚钱要靠判断央行会议、挂钩会不会破这些事件。高息货币还会被套息资金推高，一旦恐慌，这些资金集中撤出，就会暴跌（见 §1.4 和 F 系列事件）。这和真实市场的套息交易一样。

利率由"政策会议"公告改变（F1/F4/F8/F11/F14）。会议在日历上提前 24–72 小时公布，会前有传闻，传闻可能是假的。

### 1.4 汇率怎么动（在现有行情模型上加）

| 机制 | 规则 |
|---|---|
| 漂移 | 利率平价漂移（§1.3），加上现有的均值回归、波动聚集、肥尾、羊群效应 |
| 干预 | 龙门币偏离 1000 超过 ±12%，每小时有 15% 的概率触发"龙门方面入市干预"（就是现有的 L9，从随机抽取改为由条件触发） |
| 挂钩 | 第纳尔被夹在区间里。卖压会累计成"挂钩压力"，满了以后每次冲击都有概率击穿区间（F12 黑天鹅）。击穿后转为浮动 7–14 天，然后重新挂钩，新中枢比原来低 10–30% |
| 资本管制 | 事件效果加 `convert_fee`（该货币的换汇额外费用）和 `convert_halt`（暂停换出） |
| 联动 | 新增表 `CURRENCY_TIES`。一种货币单次跳动超过 3% 时，10–60 分钟后，与它相关的货币和盘口按"关联系数 × 跳幅 × U(0.3, 0.8)"跟着跳，正负号由表决定（§3.3） |
| 避险 | 恐慌（`panic` 态势）时，赤金和龙门币相对其他货币走强，高息货币走弱（现有规则是"恐慌时赤金涨"，这里推广到多种货币） |

### 1.5 莱茵生命改用金券（拍板 #2）

- 莱茵生命所有盘口的报价单位改成金券，卖货拿到金券，买货花金券。
- 和莱茵生命签的远期合约，保证金也用金券。
- 所以卖给莱茵生命要同时看两样：货价和金券汇率。这就是"同一笔买卖里有两层风险"。
- 加工部和仓储部的价值换算统一走 `Economy.price()`，再按实时汇率折算，单一价格入口不变。

## 2. 局内效果

### 2.1 事件可以带 `field` 效果

在现有事件字段 `threat {region, mult}` 的基础上，推广成一个列表：

```
"field": [{"region": "mine", "kind": "threat", "mult": 1.2}, {"region": "city", "kind": "post", "faction": "rat", "mult": 0.5}]
```

`region` 只有四张图：`mine`（切尔诺伯格/乌萨斯）、`city`（龙门）、`snow`（萨米）、`siracusa`（叙拉古），另外 `*` 表示全部。没有地图的地区（哥伦比亚、谢拉格、卡西米尔、维多利亚……）**只能通过和这四个地区的互动来影响局内**。这正好就是"地区之间的交互"在局内的落点。

| kind | 改什么 | 接到哪里 |
|---|---|---|
| `threat` | 威胁值起点和增速 | 已有：`market.threat_mult` → `ThreatMeter` |
| `elite` | 精英出现率 | `floor_enemies()` 生成时 |
| `enemy` | 某一类敌人的占比（`tag`：如乌萨斯正规军、整合运动、家族杀手） | 各地区敌人表，tag 要逐图对应（§6） |
| `route` | 路线图节点权重（`node`：trader/post/rest/vault/elite/relic/event） | `RouteMap._free_kind` 已有 `mult` 参数，只在**新生成**的 10 层图上生效 |
| `post` | 势力据点出现率（`mult`）和收购价（`price`） | 已有 `post_boost`，推广成倍率 |
| `kannot_buy` | 坎诺特收购价 | 坎诺特的收购页面 |
| `kannot_stock` | 坎诺特多几个货位（`add`），可指定货类 | 坎诺特生成货架时 |
| `loot` | 某类材料的掉落权重（`category`，用交易所的大类） | `LootTables` |
| `gold_drop` | 赤金掉落量 | `LootTables` |
| `feature` | 地图特色的起点（`add`）和增速（`mult`） | `FeatureMeter`（污染/血债/寒冷；龙门没有） |
| `reward` | 该地区合同的龙门币报酬 | 合同接取定价 |
| `camp_fx` | 营地可露希尔的换汇价差 | `Economy.closure_spread` |

### 2.2 什么时候生效

- **按层取快照**：进入每一层、生成地图时，读一次当前还在生效的事件效果，整层不变。路线图节点权重只在生成新的 10 层图时读取。
- 快照要写进 `RunSave` 键表，读档后继续用（局内存档规则）。
- 同一类效果相乘，再夹在 0.7–1.5 倍之间（拍板 #4）。
- 交易所的事件按现实时间持续，所以一局长线外勤会碰上事件开始和结束。这本身就是玩法：听到 PRTS 播报"乌萨斯—卡西米尔边境摩擦"，就知道下一层敌人会更硬、武器掉落会更多。

### 2.3 玩家怎么知道

界面不写说明文字：

- **局内**：某个事件对当前地区生效、或者结束时，PRTS 播报**事件标题**（已有的快讯播报加一类）。不写数字。
- **调度台**：选地区和层数的卡片上，挂上影响该地区的事件**标题**小签（只有标题），按影响方向染色（变难用红色，有好处用金色）。
- **路线图**：受影响的节点不加标记。

## 9. 杠杆：按日本的现实限制（用户 2026-10-25）

### 9.1 日本的规定

| 品种 | 个人账户的杠杆上限 | 对应的最低保证金率 | 出处 |
|---|---|---|---|
| 外汇保证金交易（FX） | 25× | 4% | 2009 年内阁府令修订，2011-08 起从 50× 降到 25× |
| 证券 CFD：股价指数 | 10× | 10% | 2009 年修订府令案 |
| 证券 CFD：个股 | 5× | 20% | 同上 |
| 证券 CFD：债券 | 50× | 2% | 同上 |
| 商品 CFD | 20× | 5% | 券商公布的商品 CFD 保证金率（MT4 商品 CFD 5%），法规原文未查到 |
| 加密资产 | 2× | 50% | 2021-05 起一律 2× |

另外两条日本的做法也照搬：
- **强制平仓（ロスカット）**：券商必须设定强制平仓线，不能让亏损无限扩大。
- **追加保证金（追証）**：保证金维持率跌到 100% 以下就要求追加，到期不补就平仓。

### 9.2 套到本作的盘口上

| 本作的标的 | 比照 | 上限 | 按关系等级解锁 |
|---|---|---|---|
| 汇率盘（`fx` 和 §1 的 4 个新外汇盘） | FX | **25×** | R0 1× / R1 5× / R2 10× / R3 15× / R4 20× / R5 25× |
| 势力综合（`comp:势力`，一家势力所有货的指数） | 股价指数 | **10×** | R0 1× / R1 2× / R2 3× / R3 5× / R4 8× / R5 10× |
| 单个货物盘（`势力:大类`） | 商品 | **20×** | R0 1× / R1 3× / R2 5× / R3 10× / R4 15× / R5 20× |
| 违禁品盘口，以及鼠王、整合运动残党的所有盘口（拍板 #7） | 加密资产 | **2×** | R0 1× / R3 2× |
| 远期合约（实物交割） | 按标的套上面同一张表 | 同上 | 同上 |

- 差价合约看发行方（喀兰贸易、卡西米尔商业联合会）的关系等级，远期合约看对手势力的关系等级（跟现在一样）。
- 本作没有个股和债券，5× 和 50× 两档不用。
- `Exchange.LEVERAGES` 不再是一个 [1, 2, 3] 的列表，改成"按标的类别 × 关系等级"查表的函数。`relations_screen.gd` 里的解锁项也要跟着改。

### 9.3 追加保证金与强制平仓（替换现在的"剩 30% 预警、亏光才平"）

用**保证金维持率**表示：（保证金 + 浮动盈亏）÷ 必要保证金。必要保证金 = 名义金额 ÷ 该标的的上限杠杆（例如 FX 是 4%）。

| 维持率 | 发生什么 |
|---|---|
| < 100% | **追证**：PRTS 播报"追加保证金"，要求在下一个交易日开始（本地 08:00）之前补足到 100%。打开了自动追加的就自动补（现有功能保留） |
| 08:00 时仍 < 100% | 按市价平仓 |
| < 50% | **立刻强制平仓**，不等追证期限 |
| 跳空击穿到 < 0 | 亏损以保证金为限（拍板 #6 的默认值）。如果选另一个选项，差额就是"不足金" |

局内照旧：只听到 PRTS 播报"追加保证金""强制平仓"，要补钱得回基地，或者用游戏外的 A 终端。

### 9.4 跟着改的费用（原来是按 3× 定的，放到 25× 会直接吃光保证金）

| 费用 | 现在 | 改成 |
|---|---|---|
| 远期开仓费 | 名义金额 × 1%/2%/3%（按杠杆递增） | 名义金额 × 0.5%，跟杠杆无关 |
| 差价合约隔夜费（货物、势力综合） | 名义金额 × 0.3% / 天 | 名义金额 × 0.02% / 天（约年化 7%，接近日本券商的"金利調整額"） |
| 差价合约隔夜费（汇率盘） | 名义金额 × 0.3% / 天 | **掉期点**：按两种货币的利率差（§1.3）逐日收付，做多高息货币还能收到钱。利率平价漂移会把这部分抵掉，所以挂机仍然不赚钱 |
| 每家发行方的名义金额上限 | 50,000 × R | 不变。杠杆高了，同样的名义金额只需要更少的保证金，上限本身仍然限制总规模 |

### 9.5 要重测的

- `test_exchange`：每类标的、每个关系等级能开的最高杠杆；追证在 08:00 到期后平仓；维持率 < 50% 立刻平仓；跳空时亏损不超过保证金；掉期点正负都对。
- `sim_exchange.gd`：25× 下挂机和随机策略仍然亏损；用 1 分钟约 1% 的波动核对，看 20×、25× 的仓位多久会被强平（预计几分钟到几十分钟，这就是"玩的就是心跳"）。
- 旧存档里的 1–3× 仓位原样保留，到期或平仓为止。
