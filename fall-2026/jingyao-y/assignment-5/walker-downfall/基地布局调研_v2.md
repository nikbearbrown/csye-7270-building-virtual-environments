# 罗德岛主基地布局调研与重新设计 v2

2026-10-18。用户：“调研相关游戏并重新设计”，范围是整个主基地的布局。前一版布局（基地建模改造案 §十六）是按用户指定的区域位置摆的，这一版按同类游戏的规律重新安排动线和分区。

## 一、调研

前一轮调研见 `基地类游戏调研.md`，涉及元气骑士、战魂铭人、挺进地牢、哈迪斯、死亡细胞、Children of Morta、夜勤人、传说法师、Escape from Duckov 九款。这一轮补充了以下几款：

| 游戏 | 枢纽的组织方式 | 对我们的启发 |
|---|---|---|
| **怪物猎人：世界** 星之港 → **冰原** 色之港 | 星之港分三层：底层是交易场和码头，第二层是工房和食堂，集会所要坐电梯上第四层。集会所里任务柜台、道具箱和补给箱挨在一起，出发用的翼龙在尽头。到了冰原，导演市原大辅说星之港很难走动，有些设施隔得太远，新据点色之港因此做得更小，厨师和铁匠也离得更近 | 常用设施要聚在一起；出发点就在接任务的地方旁边 |
| **流放之路** 藏身处 | 玩家普遍把仓库、地图装置、制作台摆成紧凑的三角，相关的 NPC 放在各自用到的设施旁，“卸货然后出发”尽量少走路（社区经验，非官方） | 每一轮“回来、整理、出发”要用到的东西，放在几步之内 |
| **命运 2** 高塔 | 中央庭院放最常用的商人、邮政官和仓库；东侧是机库，西侧是集市，专项商人和派系商人分在两翼 | 高频功能放中心，低频功能放两翼 |
| **哈迪斯** 冥王殿 | 复活池和承包人在大厅，休息室、厨房在侧面，后期解锁；从大厅的门出发 | 复活点和出口都在主厅；社交空间放在边上 |
| **终末地** 帝江号 | 控制中枢在舰桥（舰的最左端）；制造舱、培养舱、会客室各自是独立的舱室 | 指挥在舰桥，生产和人事各自成区，与我们的“舰桥大厅 + 侧舱”结构一致 |
| 枢纽设计通论 | 枢纽要反复穿行，所以好不好走是首要问题；一个中心地标分出几个小区域，可以降低复杂度；可读性来自视线、轮廓和地标 | 中轴上放一个最强的地标，其余区域围着它展开 |

## 二、归纳出的规则

1. **出发点是最强地标，并且在中轴上。** 升降梯在北墙正中，加上舰桥墙，本身就是全场最大的物件。
2. **“回来 → 整理 → 准备 → 出发”的动线要短，准备功能紧挨出口**（色之港、流放之路、哈迪斯）。从局内回来是坐升降梯，所以回来的落点就在升降梯前面。
3. **高频功能放中心，低频功能放两翼**（命运 2）。每一局都用：调度台、整备台、后勤柜台（投保）、仓储、医疗报告。不是每局都用：交易所、加工站、人事部、商店。几乎不用：休息区、简报区。
4. **一条主街把两扇侧门连起来**：仓储区在西门，医疗部在东门，这是每局回来必去的两处。主街和中轴在大厅中央相交，交叉口挂总指示牌。
5. **沿墙摆密，中间留空**，前一轮调研已有这一条。
6. **每个区域用一个能认出来的大物件代表**：行情墙、加工机、沙盘、吧台、简报屏。区域上方挂吊牌，只有颜色和图标，没有文字。

## 三、新布局（大厅 128×56 m，北为舰桥墙）

```
 北墙   [商店门]                     [ 升降梯 ]                        [人事部门]
      ┌───────────────┬───────────────────────────────────┬────────────────┐
      │ 交易所         │ 后勤柜台   ← 到达 →   整备台        │ 加工站           │
      │ 行情墙、交易台 │ （投保）     升降梯     武器架        │ 加工机、传送带    │
      │ 交易所柜台     │           调度指挥台               │ 吊车、货料        │
      │               │         （指挥桌 + 泰拉全息）       │ 集装箱靠东墙      │
 西门 ═══════════ 主 街 ════════ 总指示牌 + 地面标志 ════════ 主 街 ═══════════ 东门
 仓储区 │ 干员休息区     │                                   │ 简报区           │ 医疗部
      │ 吧台、售货机   │            全息沙盘               │ 吊屏、讲台        │
      │ 沙发、书架     │      （战略区，从调度台正对）        │ 长椅三排×两行     │
      └───────────────┴───────────────────────────────────┴────────────────┘
```

| 区域 | 内容 | 依据 |
|---|---|---|
| 出发区（北中） | 升降梯；到达点设在升降梯前面；东侧整备台加武器架，西侧后勤柜台（投保）；正南是调度指挥台 | 规则 1、2：从接合同、换装备、投保到出发，都在升降梯 10 m 以内 |
| 主街（东西向） | 从西门（仓储区）到东门（医疗部）画两道导向线，在中轴处断开；交叉口挂总指示牌，地面铺标志 | 规则 4 |
| 西北：交易所 | 行情墙、两排交易台、交易所柜台；紧挨商店门，组成“商业区” | 规则 3：低频，放在一翼 |
| 东北：加工站 | 加工机（新模型，加工站的交互点）、传送带、货料、吊车；集装箱挪到东墙，不再挡住人事部 | 规则 3、6；参照帝江号的制造舱 |
| 西南：干员休息区 | 暖色地毯、吧台、售货机、沙发组、书架 | 规则 3：社交空间放在边上（哈迪斯的休息室） |
| 南中：战略区 | 全息沙盘从东南挪到中轴南端，从调度台往南一眼就能看到 | 规则 1：中轴上的第二个地标，和舰船位置、运送、势力系统相连 |
| 东南：简报区 | 吊挂大屏、讲台、长椅三排×两行 | 填补原来沙盘的位置；以后可以作为干员入驻、任务简报的地方 |
| 北侧小房间 | 西北是商店，东北是人事部 | 不变 |

## 四、实现记录

- `BaseMap.STATION_SPOTS`：整备台 (78.5, −5)、后勤柜台 (49.5, −5)、交易所 (25.5, −19)、加工站 (104, −4.4)、人事部 (113, 7.5)。加工站是新增的站点，打开加工界面。
- `BaseMap.SPAWN_SPOTS`：到达点 (64, −4)，在升降梯前面。
- `PROP_CLEAR`：东北的旧后勤柜台和值班桌不再放置。
- `LANES`：主街导向线。`DECK_INLAY`：大厅地面标志挪到交叉口。
- 新模型：加工机、加工站吊牌（总指示牌同步加了加工站一栏）；长椅坐垫调亮，避免和深色甲板混在一起。
- 测试：`test_base_scene` 改为 12 个站点，新增“出发区”检查（整备台和后勤柜台在升降梯 18 m 以内，到达点在升降梯 4 m 以内）。48 组测试全部通过。
