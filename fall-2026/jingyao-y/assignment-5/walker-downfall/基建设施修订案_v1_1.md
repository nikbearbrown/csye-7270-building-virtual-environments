# 基建设施修订案 v1.1：基建部件、施工占位、总控台与接入

本案接续 v1.0。v1.0 的设施等级表和各项价格不变，本案补充以下几件事：

- 每个设施在基地里由哪些部件组成，这些部件放在哪里；
- 设施建成之前怎样用施工物件占位；
- 基建总控台本身要先建成才能用；建成后，每个设施还要各自"接入"总控台，才能在总控台里选中它、查看并购买它的升级项；
- 交易所也要先建成才能用，建造选项要等某个势力关系达标后才出现。

2026-10-22 用户原话：

> 设计对应的部件和在基地里的位置，升级前用一些施工物件占位，表示此处是基建内容，这个总控台也需要先升级才能用，升级总控后还需要将每个设施接进来的升级，可以在总控中选择设施后查看对应设施有哪些升级项；交易所也需要升级后才能用，在某个示例某个声望达成后解锁交易所升级选项。

坐标都是基地布局坐标（`BaseMap.to_world` 之前的 x、z），北为 z 正方向。所有站位在实现时还要逐个检查寻路有没有被堵住。

## 一、流程

```
施工点 1：基建总控台（未建成，围挡）
  └─ 在施工点按 E → 建造卡 → 建成 总控台 Lv1
        └─ 总控台：左列列出各设施，选中后右侧显示它的升级项
              ├─ 设施未接入 → 只显示"接入总控"一项（接入线槽 + 中继柜）
              └─ 设施已接入 → 显示它的等级升级和附属项目（货架、扩容、无人机……）
```

- 设施没接入时照常使用。它的升级在现场的施工终端做（§八.2）。
- 总控台建成前也能在各施工终端现场升级；"接入总控"要总控台建成后才出现。
- 接入后，总控台和大厅快捷按钮都能远程升级它。
- 交易所和科研部建成前是 Lv0。流程统一为先接入、再建成 Lv1。

## 二、施工占位套件（共用）

所有未建成的部件都用同一套施工物件占位。这样玩家一眼就能认出"这里是基建内容"。按地区区分风格的规则（`feedback-region-style-not-bans`）只用于外勤地图，基地里统一使用罗德岛工程部的黄黑警示配色。

| 物件 | 说明 | 尺寸（米） |
|---|---|---|
| `build_barrier` | 黄黑斜纹施工围挡板，一节 2 米，带底座。印 L 标志的罗德岛三角塔徽 | 2.0 × 0.3 × 1.1 |
| `build_tape` | 地面黄黑警示胶带框，按未来部件的占地拉成矩形 | 按占地 |
| `build_cone` | 路锥，放在围挡的缺口处 | 0.4 × 0.4 × 0.7 |
| `build_crate_tarp` | 盖着灰帆布的货箱，绑带，箱侧贴设施图标贴花（无文字） | 1.6 × 1.2 × 1.1 |
| `build_scaffold` | 两层脚手架，用在高部件上（总控台全息柱、交易所巨幕） | 3.0 × 1.5 × 3.4 |
| `build_lamp` | 三脚工程灯，暖色泛光 | 0.8 × 0.8 × 2.2 |
| `build_post` | 施工终端立柱，小屏亮黄灯，按 E 就站在这里 | 0.5 × 0.5 × 1.4 |

摆法：未来部件的占地先用 `build_tape` 框出来，三面立 `build_barrier`，正面留一个口放路锥和 `build_post`。占地内放 1–2 个盖布货箱，高部件再加一个脚手架。每处施工点放一盏工程灯。

建成时：围挡下沉进地板（沿用货架的地面舱口动画 `set_hatch`），部件从舱口升起，工程灯熄灭后撤走。

### 8. 交易所的解锁条件（关系示例）

交易所的"接入总控"和"建成 Lv1"两项，都要等喀兰贸易关系达到 R2（500）才出现在总控台里。没达到时，交易所那一页只显示：

> 喀兰贸易 关系 R2 · 当前 210 / 500

这里只写数据，不写规则说明。

- **为什么选喀兰贸易**：现在的交易所本来就是"喀兰贸易关系 R1 开放"（`Exchange.unlocked`），新档开局正好 150，等于开局就能交易。改成 R2 之后，玩家要先跑几次：
  - 谢拉格方向的运送合同，每次关系 +15；
  - 或者把罗德岛开到谢拉格做医疗驻留，伤员驻留对喀兰贸易是 ×1.25。
- **数据化**：门槛写成数据，`FACILITIES.exchange.gate = {"faction": "karlan", "rank": 2}`。以后别的设施也可以挂势力门槛，例如科研部挂莱茵生命。
- `Exchange.unlocked()` 改成"交易所 Lv ≥ 1"。

## 四、总控台界面

基建页搬进总控台，布局改成两栏：

- **左栏：设施列表**，从上到下依次是：
  - 基建总控
  - 仓储部
  - 整备部
  - 可露希尔商店
  - 加工部
  - 科研部
  - 交易所

  每行显示：
  - 设施名；
  - 等级 `LvN / M`；
  - 接入状态：一个小点，已接入是青色，未接入是灰色；
  - 可升级时亮黄色"!"。
- **右栏：选中设施的升级项**：
  - **未接入**：只有一张"接入总控"卡（价格、材料、按钮）。
  - **已接入**：
    - 先是"下一级"卡，内容沿用 v1.0 的设施条；
    - 然后是这个设施的附属项目卡：
      - 仓储部：总控面板、无人机、四个区的货架；
      - 整备部：背包扩容、安全袋扩容；
      - 基建总控：营地升级。
  - **交易所没达到关系门槛**：只有关系那一行。
- **入口改动**：
  - 删掉大厅右下角的"基建"快捷按钮，只能走到总控台去用。
  - 站点总览里那一行改名为"基建总控台"，状态显示"可升级 N"或"未建成"。

## 五、接入价格（暂定）

每个设施接入：5,000 + 电线×2、继电器×1。交易所接入另外加电路板×1。接入总共 6 次，约 30,000 龙门币，相对 v1.0 的设施总价（约 85 万）是小数目。

## 六、新模型清单（通过 MCP 在 Blender 里建）

模型按 `feedback-blender-via-mcp` 的流程在 Blender 里建。

- **施工套件（7 件）**：build_barrier、build_tape、build_cone、build_crate_tarp、build_scaffold、build_lamp、build_post。
- **基建部件（10 件）**：build_console（含全息舰体剖面）、cable_trunk、relay_cabinet、drone_pad、order_screen、pack_rig（两级）、secure_safe（两级）、closure_fridge、display_case（两种）、订单板三栏版。
- **沿用现有模型**：fabricator、originium_chamber、trader_desk、holo_screen_frame、trading_post、goods_shelf。
- **贴图**：黄黑斜纹用现有的 `HAZARD` 色板，帆布用 `FABRIC`。不需要等 Sol 出图；如果想要更旧、更脏的帆布，可以另外给 Sol 提一条材质需求。

## 七、旧存档

- 已有 `facilities` 或旧声望的存档：总控台算已建成，所有设施算已接入。
- 交易所：只要 `exchange` 有过成交、持仓或贷款，或者 v1.0 存档里交易所 ≥ Lv1，就算 Lv1 已建成，不受喀兰 R2 门槛限制。
- 科研部：已经有研究完成的，算 Lv1。
- 新档：总控台未建成，所有设施未接入，交易所和科研部都是 Lv0。

## 八、已拍板（用户 2026-10-22）

1. 是新建的**基建总控台**（大厅货运区南沿）。仓库总控面板仍是仓储部的项目。
2. **没接入前可以去对应位置升级**：走到该设施的施工终端（`build_post`）按 E，在现场打开它的升级页；接入总控后，在总控台里就能远程升级，不用来回跑。§一 里"未接入不能升级"作废。
3. 交易所门槛：喀兰贸易关系 R2（500）。
4. 大厅的"基建"快捷按钮：总控台建成前没有，建成后出现，打开总控台页面（远程，只能操作已接入的设施；未接入的设施在列表里显示"未接入"，选中后只有"接入总控"一项）。

## 九、实现记录（2026-10-22）

- **规则**：
  - `BaseCatalog.FACILITIES` 新增 `hub`（基建总控台，Lv0→1，8,000 + 电线×2、继电器×1、灯泡×2）。
  - 交易所改为 Lv0 起步：Lv1 价格 30,000 + 电路板×2、继电器×2，`gate = 喀兰贸易 R2`。
  - `CONNECT_COST` 5,000 + 电线×2、继电器×1，交易所另加电路板×1。
  - `BaseState.connected`、`hub_built`、`is_connected_to_hub`。
  - `GameManager.facility_refusal(id, remote)`、`gate_refusal`、`connect_refusal`、`connect_facility`、`open_build_site`。
  - `Exchange.unlocked()` 改为交易所 Lv ≥ 1；贷款额度 20,000 × max(1, 交易所等级)。
- **场景**：`world/base_works.gd`（`GameManager.works`）。
  - `POSTS` 是 7 个施工终端，作为交互点 `site_<设施>`，种类是 `build_site` 或 `hub`。
  - `PARTS` 是 31 个部件及其显示条件。
  - 未建成的部件用 `_site()` 摆出施工套件：胶带、北东西三面围挡、盖布货箱、路锥、工程灯，高部件再加脚手架。
  - 房间自带的 decor 部件（第二台制造机、研究树、源石舱、交易亭和行情巨幕、交易台）未建成时隐藏。
  - 大厅 DECOR 删掉了 (83, −8.6) 的 case 和加工部 (−3, 5) 的盆栽，这两个位置给安全袋保险柜和中继柜。
- **界面**：
  - `BaseScreens.construction(menu, title, site)`：不传 `site` 时是总控台（左栏设施列表，选中后显示右侧详情）；传 `site` 时是现场页（只显示该设施）。

  - 大厅"基建"快捷按钮在总控台建成后才显示；站点总览里那一行改名"基建总控台"。
- **模型**：在 Blender 里通过 MCP 建了 16 件，导出到 `art/kit/base_*.glb`，预览图在 `art/kit/preview/`。
