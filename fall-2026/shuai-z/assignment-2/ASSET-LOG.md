# Asset log — walker-rudy

This log has one row per generation I kept or seriously considered. IDs match STORYBOARD.md, CHARACTER-SHEET.md and CHANGE-BRIEF.md, with a take number added (CHAR-REF-07). Some IDs there have no row because nothing was generated for them: ENEMY-MUSHROOM, FX-SPORE, SFX-SPORE and SFX-BLOCK (cut with the mushroom), SFX-FALL and SFX-CHECKPOINT (cut from the sound list), and UI-TITLE (text in the engine's default font); see CHANGE-BRIEF.md's revisions. Each round's generation log quotes the prompts in full.

Files are kept as follows:
- full-size downloads stay in `_raw/`, which is not in git;
- accepted originals go to `generated/accepted/`;
- rejected outputs are kept as thumbnails in `generated/rejected/`; the sound-effect takes not chosen are drawn, with the kept ones, in `generated/rejected/SFX-takes-sheet.png` (waveform, spectrogram and SHA-256 prefix of each full take, made by `design/tools/sfx_takes_sheet.py`);
- checks at game size go to `generated/checks/`, made with `design/tools/check_against_sheet.py`.
