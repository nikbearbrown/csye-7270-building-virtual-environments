# Lanternfall, Taken Apart — the Assignment 2 film

A 4K landscape teardown of this repository's game, made with the **godot-gamedev skill + walker modifier** (Walker bookends; Verdict → Your Turn → the regular outro). Narrated by Liam, in for Bear (Kokoro `am_onyx`). Game source revision shown: **8a6f988** (`FILM-SOURCE-REVISION.txt`).

| File | What it is |
|---|---|
| `beat_sheet.json` | the film, beat by beat: narration, what is on screen, scene props, measured durations |
| `gamedev-evidence.json` | every file of `godot/` hashed and tied to a component; verbatim excerpts; each code beat paired with its hashed result clip |
| `COMPONENTS.md` | the components the film explains, and the three files it leaves out (with reasons) |
| `SHOTLIST.md` | what each beat shows and where it came from (take and frames, or file) |
| `SCRIPT.md` | the narration, beat by beat, with timings and what is on screen |
| `FACTCHECK.md` | every claim and its source; the corrections made before the final render |
| `CAPTURE.md` | how the gameplay was captured (isolated copies, driver, seeds, dry runs, rejected takes) |
| `SOURCES.md` | captures with hashes, files shown, tools, licences |
| `RIFF.md` | the judgments the narration makes and what each rests on |
| `PROMPTS.md` | the reconstructed Walker ask, the Your Turn prompt, the request that produced the film |
| `BUILD-PROMPT.md` | how to rebuild everything |
| `CHECKS-REPORT.md` | checker results, beat classification, teaching-arc checklist, visual QC |
| `capture/` | capture driver and scene, the takes' logs, dry-run tracks, recorded test output, take hashes (the AVI/MOV files themselves are not committed) |
| `tools/` | the scripts that build the sheet, the evidence beats, the evidence ledger and the shot list |
| `images/trace/` | the ART-PC-01 edit stages re-run from the logged steps |

The rendered film (`exports/landscape/…mp4`) and every intermediate video are kept out of git; the course media link, file name and SHA-256 are in the repository README.
