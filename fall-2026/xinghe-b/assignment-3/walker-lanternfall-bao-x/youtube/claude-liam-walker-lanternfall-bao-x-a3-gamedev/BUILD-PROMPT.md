# BUILD-PROMPT — how to rebuild this film

Prompt for an agent with the brutalist.art toolkit (`$ART`), this repository (`$REPO`), Godot 4.7.2 and Blender 5.2.2:

> Use the godot-gamedev skill with the walker modifier on `$REPO/godot` at source revision c0dba4c. Keep everything
> inside `$REPO/youtube/claude-liam-walker-lanternfall-bao-x-a3-gamedev/` and never edit `godot/`. Rebuild the captures
> from CAPTURE.md, then run the steps below and stop on the first failure.

## Steps (from the reel folder `$REEL`)

1. **Godot takes** — `git archive c0dba4c godot` into a scratch folder; set `window_width_override=3840` and
   `window_height_override=2160` in the copy's `project.godot`; copy `capture/capture_a3_driver.gd` and
   `capture/capture_a3_main.tscn` in; `--import` once; then
   `godot --always-on-top --path . res://capture_a3_main.tscn --write-movie $REEL/capture/take-a3-<take>.avi --fixed-fps 30 -- <take>`
   for `orbit` and `block`. Both logs must list `"stale":[]`.
2. **Blender stills** — they record a live session and cannot be regenerated byte for byte; the committed PNGs and
   their hashes are the source. CAPTURE.md says how they were taken.
3. **Recorded tests** — the suites on a fresh `git archive c0dba4c godot` copy → `capture/test-run-film-build-raw.txt`.
4. `python3 tools/make_reel.py` → `beat_sheet.json`.
5. `python3 $ART/runtime/scripts/generate_audio_kokoro.py $REEL` (Kokoro `am_onyx`), `python3 tools/level_audio.py`,
   then `python3 tools/make_reel.py` again. The outro audio is `bear-brown-1.mp3` + 1.0 s of silence → `mp3/beat-B20.wav`.
6. `python3 tools/build_media.py` → `media/<BID>.mp4` for every evidence beat.
7. `python3 $ART/runtime/scripts/remotion_scenes.py $REEL` → the Remotion beats (delete `media/<BID>.mp4` first to re-render one).
8. `python3 tools/make_evidence.py`, `python3 tools/make_shotlist.py`.
9. `$ART/art godot-gamedev --check $REEL --game $REPO/godot` — must PASS.
10. `$ART/art final $REEL --height 2160 --fps 30 --out $REEL/exports/landscape`.
11. Visual QC: sample frames of every beat, read them, log defects in `_qc/REPORT.md`.

## Rules this build kept

- Godot code panels: verbatim excerpts, labelled "Godot editor reconstruction", path and lines on screen; each is
  followed by its visible result (hashed media).
- Blender code panels: verbatim from `tools/blender/`, path and lines on screen; each followed by Blender's own window.
- Film re-runs, held frames, "not recorded live" and translations are labelled where they appear.
- No retiming of game footage. Outro: locked `ClaudeTitleOutro`, exact title, @NikBearBrown, stock jingle only.
