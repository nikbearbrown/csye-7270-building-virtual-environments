# Termite reference — Macrotermes soldiers

My pick for the termite obstacle's look: a **Macrotermes soldier**. What caught me is the **big head**; I'd never seen a termite like that, and it looks scary.

The images below are shown from Wikimedia Commons, not copied into this repository. Each is credited under its license.
